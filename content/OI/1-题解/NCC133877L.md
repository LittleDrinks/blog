## [NCC133877L. Lazy Shuffling](https://ac.nowcoder.com/acm/contest/133877/L)

读懂题目，$|f(A)-f(A')|$ 能变大，当且仅当给出的排列 $p$ 中存在逆序对。
对于 $p$ 中的每对逆序对 $(i,j)$，原本顺序的 $(a_{p_i},a_{p_j})$ 会逆序，反之亦然，此时 $|f(A)-f(A')|$ 会变化 $1$。那么想要让变化量最大，就必须保证所有的变化量都是 $+1$ 或者都是 $-1$
先特判 $p$ 完全顺序的情况
剩下存在逆序对的情况，变化量 $+/-$ 的情况是完全对称的，相当于给定若干组限制，要求 $a_{p_i}<a_{p_j}$。也可以理解为有向无环图拓扑序的数量。
状压 DP，按 $1\sim n$ 的顺序填数字，设 $S$ 表示有哪些位置已经填好，对每个位置维护一个 $msk$ 表示要求那些位置在此之前已经填好，当 $S\&msk=msk$ 时转移。
时间复杂度 $O(n2^n)$

[***AC 代码***](https://ac.nowcoder.com/acm/contest/view-submission?submissionId=84293612)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

const int MOD = 998244353;
ll add(ll x, ll y) { return (x + y) % MOD; }
ll del(ll x, ll y) { return (x - y + MOD) % MOD; }
ll mul(ll x, ll y) { return (x * y) % MOD; }

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
        --a[i];
    }

    int in = 0;
    vector<int> msk(n);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (a[j] > a[i]) {
                msk[i] |= (1 << j);
                ++in;
            }
        }
    }

    if (in == 0) {
        ll ans = 1;
        for (int i = 1; i <= n; ++i) {
            ans = mul(ans, i);
        }
        cout << ans << "\n";
        return 0;
    }

    vector<ll> dp(1 << n);
    dp[0] = 1;
    for (int S = 0; S < (1 << n); ++S) {
        for (int i = 0; i < n; ++i) {
            if ((~S >> i & 1) && ((S & msk[i]) == msk[i])) {
                dp[S|(1<<i)] = add(dp[S|(1<<i)], dp[S]);
            }
        }
    }

    cout << mul(2, dp[(1<<n)-1]) << "\n";
}
```
