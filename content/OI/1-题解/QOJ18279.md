## [QOJ18279. 粑粑博弈](https://qoj.ac/contest/3758/problem/18279)

从一些 corner case 出发，当 $k=1$ 的时候，双方都只能一个一个取，此时当和为奇数时先手必胜。
如果 $k\ge 2$ 并且当前是奇数，先手取一个石头，就是 $k=1$ 的情况，必胜
如果 $k\ge2$ 并且当前是偶数，那么先手继续取奇数个石头，就会把必胜态让给对手，所以只能取偶数个
于是我们发现，如果 $k\ge2$ 并且和为偶数，先手只能取 $2,4,6\ldots,2x$ 个，我们除以一个 $2$，把先手可以取的石头变成连续的。此时那些余数不会影响和的奇偶性，则这个游戏等价于
$$
a_i\leftarrow\left\lfloor  \frac{a_i}{2}  \right\rfloor, k\leftarrow \left\lfloor  \frac{k}{2}  \right\rfloor
$$
向下递归即可，直到 $k=1$ 先手仍无法获胜，则 Bob 赢，时间复杂度 $O(n\log n)$

[***AC 代码***](https://qoj.ac/submission/2462404)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    while (k) {
        ll s = accumulate(a.begin(), a.end(), 0LL);
        if (s % 2 == 1) {
            cout << "Alice\n";
            return;
        }
        k /= 2;
        for (int i = 0; i < n; ++i) {
            a[i] /= 2;
        }
    }
    cout << "Bob\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
}
```
