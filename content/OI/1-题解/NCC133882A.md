## [NCC133882A](https://ac.nowcoder.com/acm/contest/133882/A)

玩一下样例，发现可以拆成二进制位做，每种花费 $M$ 可以看作一种掩码唯一对应一种方案
一个思路是从高到低判断每一位需不需要填。
注意到方案之间存在一种“集合”间的单调性，如果一个方案 $M$ 可行，则对于所有满足 $M\subseteq M'$ 的 $M'$ 都可行。一种判断方法是当前位填 $0$，低位全填 $1$，如果不可行则说明当前位必须填 $1$。
于是考虑，如何判断某种方案 $M$ 可不可行？
从左到右扫描数组，维护上一个数的最小值 $P$
当前位置可以构成的最大值是 `a[i]|M`，如果 `(a[i]|M) < P` 则不可行，否则贪心构造 $\ge P$ 最小的那一个，方法是：从大到小每次把低位能改的全改成 $1$，如果还是不够才把当前位设成 $1$
时间复杂度 $O(n\log^2V)$

[***AC 代码***](https://ac.nowcoder.com/acm/contest/view-submission?submissionId=84444658)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

const int I = 33;

void solve() {
    int n;
    cin >> n;
    vector<ll> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }
    auto check = [&](ll M) {
        ll pm = 0;
        for (int j = 1; j <= n; ++j) {
            if (pm > (a[j]|M)) return false;
            ll cur = a[j]&~M;
            for (int i = I-1; i >= 0; --i) {
                if (M>>i&1) {
                    if (pm > (cur|(M&((1LL<<i)-1)))) {
                        cur |= 1LL << i;
                    }
                }
            }
            pm = cur;
        }
        return true;
    };

    ll ans = 0;
    for (int i = I-1; i >= 0; --i) {
        if (!check(ans|((1LL<<i)-1))) {
            ans |= 1LL<<i;
        }
    }
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
}
```
