## [CF2206E. Parallel Sums](https://codeforces.com/contest/2206/problem/E)

采用 0-index。
将 $i \bmod m$ 相等的 $i$ 分为一组，窗口从 $s_i$ 移动到 $s_{i+1}$，可以确定 $a_{i+m}-a_{i}$ 的值，也就是可以确定组内的差分数组。
minimax 问题最常用的手段是二分最大值 $B$。
于是题面变为：求是否存在一组 $a_0\ldots a_{m-1}$，使得区间 $[l,r]$ 的所有值都不超过 $B$
所有值不超过 $B$，等价于最大值不超过 $B$，找到 $[l,r]$ 区间内每一组 $d$ 的最大值，形式化地，需要满足：
$$
\sum_{i=0}^{m-1}\left(a_i + \max_{\substack{j \in [l,\,r] \\ j \equiv i \!\!\pmod{m}}} d_j\right) \leq mB
$$
其中 $\sum_{i=0}^{m-1}a_i=s_0$，可以将 $B$ 反解出来。
此时唯一的难点在于求出区间内所有组最大 $d$ 之和，这一步可以使用莫队+ST 表在 $O(n\sqrt{n})$ 的时间内做完，也可以分块。

[***AC 代码***](https://codeforces.com/contest/2206/submission/368855210)

```cpp
#include <bits/stdc++.h>
using namespace std;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }


int sgn(int x) { return (x > 0) - (x < 0); }

int main()
{
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int n;
    cin >> n;
    vector G(n + 1, vector<int>());
    for (int i = 2; i <= n; ++i) {
        int p; cin >> p;
        G[i].push_back(p);
        G[p].push_back(i);
    }
    vector<int> f(n + 1), g(n + 1);
    auto dfs = [&](auto &&dfs, int u, int fa, int t) -> void {
        for (auto v: G[u]) {
            if (v == fa) continue;
            dfs(dfs, v, u, t);
            g[u] += f[v];
        }
        if (G[u].size() == 1 && u != 1) g[u] = f[u] = (u <= t) ? 1 : -1;
        else                            f[u] = sgn(g[u]);
    };

    dfs(dfs, 1, 0, 2);

    int L = 0, R = n;
    while (L + 1 < R) {
        int m = (L + R) >> 1;
        f.assign(n + 1, 0);
        g.assign(n + 1, 0);
        dfs(dfs, 1, 0, m);
        if (f[1] < 0) { L = m; }
        else          { R = m; }
    }
    cout << R << "\n";
}
```
