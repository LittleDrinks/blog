## [QOJ16115. Sum Game](https://qoj.ac/contest/2828/problem/16115)

关注点在于 $a_i\bmod m$ 的值。
题目转化为从一个序列中选出若干个数，判断能不能凑出 $m$ 的倍数。
一个错误的想法是 Bob 先手选择 $(1,2,3)$，此时可以 $+1+2-3=0$。受此启发想到：任何一个数字都不能被剩余表示。最好的方法是按照二进制选，即 $(1,2,4,\ldots)$

[***AC 代码***](https://qoj.ac/submission/2370046)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    ll n, m;
    cin >> n >> m;
    int x = 0;
    ll s = 0;
    for (int i = 0; i < 62; ++i) {
        if (s + (1LL << i) < m) {
            s += 1LL << i;
            ++x;
        }
    }
    cout << (n <= x ? "Bob" : "Ana") << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
}
```
