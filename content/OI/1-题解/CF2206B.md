## [CF2206B. Subtree Removal Game](https://codeforces.com/contest/2206/problem/B)

最大最小博弈太过抽象，考虑二分答案 $v$，检查最后剩下的值能否小于等于 $v$。
这样一来，先手的策略固定为删大于等于 $v$ 的节点，而后手则反之。
考虑每一棵子树。
如果这个节点是叶子，编号大于 $v$ 则先手必败，编号小于等于 $v$ 则先手必胜。
如果这个节点不是叶子，接下来的每一次操作，要么在儿子的子树内博弈，要么删除一个儿子
前者的结果可以由子节点的胜负情况确定，因此博弈的过程是无意义的。只要直系儿子中必胜态不少于必败态，先手最后一定可以剩下一个必胜态的子树，因而必胜。
$O(n)$ 计算每个节点的胜负情况，时间复杂度 $O(n\log n)$

[***AC 代码***](https://codeforces.com/contest/2206/submission/368855210)

```cpp
#include <bits/stdc++.h>
using namespace std;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }


int sgn(int x) { return (x > 0) - (x < 0); }

int main()
{
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int n;
    cin >> n;
    vector G(n + 1, vector<int>());
    for (int i = 2; i <= n; ++i) {
        int p; cin >> p;
        G[i].push_back(p);
        G[p].push_back(i);
    }
    vector<int> f(n + 1), g(n + 1);
    auto dfs = [&](auto &&dfs, int u, int fa, int t) -> void {
        for (auto v: G[u]) {
            if (v == fa) continue;
            dfs(dfs, v, u, t);
            g[u] += f[v];
        }
        if (G[u].size() == 1 && u != 1) g[u] = f[u] = (u <= t) ? 1 : -1;
        else                            f[u] = sgn(g[u]);
    };

    dfs(dfs, 1, 0, 2);

    int L = 0, R = n;
    while (L + 1 < R) {
        int m = (L + R) >> 1;
        f.assign(n + 1, 0);
        g.assign(n + 1, 0);
        dfs(dfs, 1, 0, m);
        if (f[1] < 0) { L = m; }
        else          { R = m; }
    }
    cout << R << "\n";
}
```
