## [QOJ18361]()

考虑所有点度数均为偶数的情况。
前 $n-1$ 个点任意连边，方案数为
$$
2^{\Huge{n-1\choose2}}
$$
设边的数量为 $e$，则度数和为 $2e$，于是前 $n-1$ 个点中度数为奇数的点的数量必为偶数，让这些点向 $n$ 连边即可。于是上述每一种方案，都和一个度数为偶数的好图对应。
再考虑度数为奇数的情况。
同样前 $n-1$ 个点任意连边，度数为偶数的点向 $n$ 连边。奇度点的数量为
$$n-1-\#\{u:\text{deg}_u\bmod2 = 1\}$$
由于度数为奇数的点的数量必为偶数，所以当 $n$ 为偶数时，上式为奇数，存在度数全为奇数的情况，方案数同样为 $2^{n-1\choose2}$，最终答案为
$$
2^{\Huge{n-1\choose2}+1-(n\bmod 2)}
$$

[***AC 代码***](https://qoj.ac/submission/2597819)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;


ll MOD;
ll qpow(ll a, ll b = MOD - 2) {
    ll res = 1;
    for (; b; b >>= 1, a = a * a % MOD) {
        if (b & 1) {
            res = res * a % MOD;
        }
    }
    return res;
}

void solve() {
    ll n;
    cin >> n >> MOD;
    n -= 2;
    ll b = (n<0) ? 0: (n*n+n+1+(n%2==0 ? 1: -1)) / 2;
    // cerr << b << "\n";
    cout << qpow(2, b) << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int T = 1;
    cin >> T;
    while (T--) {
        solve();
    }
}
```
