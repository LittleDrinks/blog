## [NCC133879C. Retest Queue](https://ac.nowcoder.com/acm/contest/133879/C)

$m$ 位状压 $S$，某一位为 $1$ 表示这个测试点是否通过
设 $f(S)$ 表示已经通过这些测试点时的最小耗时，$g(j,S)$ 表示已经通过了 $S$ 中的测试点，下一道测评第 $j$ 个测试点时的花费，显然有状态转移方程
$$
f(S)+g(j,S)\to f(S|2^j), S[j]=0
$$
难点在于如何计算 $g$
将第 $i$ 个人可以通过的测试点压入一个状态 $M_i$
为了方便起见，我们不妨规定测试点可以重复测评。比如 $g(0,110_2)$ 表示已经通过前两题后，再次测评第一道题需要花的时间。由于我们在状态转移方程中规定了 $S[j]=0$，这些“多次测评同一测试点”的状态并不会被使用，只是起到方便计算的作用。
此时唯一的限制是某个测试点 reject 之后，剩下的测试点无法再次测评，这个限制条件可以转化为：对第 $i$ 个人的第 $j$ 道题来说，所有 $M_i$ 的子集 $S$ 都可以继续测评第 $j$ 道题，于是 $g(j,S)$ 都需要加上 $d_{i,j}$；反之所有包含至少一个 reject 测试点的集合，都无法继续测评，不用累加。
这是一个典型的 Sum of Superset，对于测试点 $j$，我们枚举每一个人，令 $g(j,M_i)=d_{i,j}$，然后通过一次 SOS DP 就可以 $O(m2^m)$ 算出所有 $g(j,\cdot)$。重复 $m$ 轮预处理出 $g$，然后 DP 转移即可。
总时间复杂度 $O(m^22^m+nm)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

const int N = 2e4 + 5, M = 20;
int n, m;
ll d[N][M+5];
ll f[(1<<M)+5], g[M+5][(1<<M)+5];

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    memset(f, 0x3f, sizeof(f));
    cin >> n >> m;
    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < m; ++j) {
            cin >> d[i][j];
        }

        string s;
        cin >> s;
        int S = 0;
        for (int j = 0; j < m; ++j) {
            if (s[j] == 'A') {
                S |= (1 << j);
            }
        }
        for (int j = 0; j < m; ++j) {
            g[j][S] += d[i][j];
        }
    }

    
    for (int j = 0; j < m; ++j) {
        for (int k = 0; k < m; ++k) {
            for (int S = (1<<m)-1; S >= 0; --S) {
                if (!(S>>k&1)) {
                    g[j][S] += g[j][S|(1<<k)];
                }
            }
        }
    }
    
    f[0] = 0;
    for (int S = 0; S < (1<<m); ++S) {
        for (int j = 0; j < m; ++j) {
            if (~S >> j & 1) {
                gmin(f[S|(1<<j)], f[S] + g[j][S]);
            }
        }
    }

    cout << f[(1<<m)-1] << "\n";
}
```
