## [CF2232E. Snaking Arrangement](https://codeforces.com/contest/2232/problem/E)

> [!tip] Observation
> - 最长的那一条蛇肯定占据两个对角线
> - 如果一开始什么都不放，结果是 $n!$
> - 一个合法的答案沿主对角线对称

考虑一个构造合法序列的过程。
我们先考虑主对角线上的情况，一定会选择一个点在主对角线上（$x+y=n+1$）结束，剩余所有节点按照各自的相对顺序链接上一层（$x+y=n$）的节点，然后反复这个过程。
先将输入中的那些蛇的位置标记，每层选择一个点的方案数可以根据上下两层被蛇占据的情况很方便地计算：

- 某个位置没有向上延伸，那就不用选了
- 某个位置向上延伸了，并且左边比上一层多空一个，那就从这些空的里面选出来
- 右边同理

```
0
00
010
0010 <- 从左边两个中选一个在这一层停下
```

最后答案乘起来就可以了，时间复杂度 $O(n^2)$。

[***AC 代码***](https://codeforces.com/contest/2232/submission/387110173)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

const int MOD = 1e9+7;
ll mul(ll x, ll y) { return (x * y) % MOD; }

void solve() {
    int n, k;
    cin >> n >> k;
    vector G(n+2, vector<int>(n+2));
    for (int i = 1; i <= k; ++i) {
        int s, r, c;
        cin >> s >> r >> c;
        G[r][c] = i;
        if (s == 1) {
            continue;
        }
        string d;
        cin >> d;
        for (int j = 0; j < s; ++j) {
            if (d[j] == 'R') ++c;
            if (d[j] == 'D') ++r;
            G[r][c] = i;
        }
    }
    vector gr(n + 2, vector<int>());
    for (int i = 2; i <= n+1; ++i) {
        gr[i-1].push_back(0);
        for (int j = 1; j < i; ++j) {
            gr[i-1].push_back(G[i-j][j]);
        }
        gr[i-1].push_back(-1);
    }
    ll ans = 1;
    for (int i = 1; i + 1 <= n; ++i) {
        array<int,2> pt{1,1};
        while (pt[0] <= i && pt[1] <= i+1) {
            auto npt(pt);
            while (npt[0] <= i && gr[i][npt[0]] == 0) { ++npt[0]; }
            while (npt[1] <= i+1 && gr[i+1][npt[1]] == 0) { ++npt[1]; }
            if (gr[i][npt[0]] == gr[i+1][npt[1]]) {
                if (npt[0]-pt[0] != npt[1]-pt[1]) {
                    ans = mul(ans, npt[1]-pt[1]);
                }
            } else {
                break;
            }
            pt = npt;
            ++pt[0];
            ++pt[1];
        }
    }
    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
}
```
