## [P1171 售货员的难题](https://www.luogu.com.cn/problem/P1171)

设 $f(des,msk)$ 表示已经经过了 $msk$ 这个集合中所有点，并且最后在 $des$ 的最短路径。
采用刷表法更新，每次从 $f(st,msk)$ 出发，枚举一个不在 $msk$ 中的点 $des$，更新 $f(des,msk\oplus2^{des})$
总状态数 $O(n\cdot 2^n)$，单次转移 $O(n)$

[***AC 代码***](https://www.luogu.com.cn/record/276733790)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

const int N = 21;
const int INF = 1e9;
int n, s[N][N], dp[N][1<<N];

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    memset(dp, 0x3f, sizeof(dp));
    cin >> n;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            cin >> s[i][j];
        }
    }
    dp[0][1] = 0;
    for (int msk = 0; msk < (1 << n); ++msk) {
        for (int i = 0; i < n; ++i) {
            if (~msk >> i & 1) continue;
            for (int j = 0; j < n; ++j) {
                if (msk >> j & 1) continue;
                gmin(dp[j][msk ^ (1 << j)], dp[i][msk] + s[i][j]);
            }
        }
    }
    int ans = INF;
    for (int i = 1; i < n; ++i) {
        gmin(ans, dp[i][(1<<n)-1] + s[i][0]);
    }
    cout << ans << "\n";
}
```
