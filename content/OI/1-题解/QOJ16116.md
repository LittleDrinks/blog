## [QOJ16116. AND Reconstruction](https://qoj.ac/contest/2828/problem/16116)

能被唯一确定，等价于把序列中任意一位反转，得到的序列一定会发生变化。
显然每一位是独立的，可以一位一位考虑，然后取 min。
考虑一个 corner case。如果有连续的三个零，把中间的 $0$ 换成 $1$，在 $k\ge2$ 时一定不会改变与序列，于是 $k$ 只能等于 $1$
接下来考虑 $1$ 的连续段，设某一段有连续 $L$ 个 $1$，当 $k=L+1$ 的时候，左侧和右侧的零会让这一段与出来为零，于是 $k=L+1$ 不合法。而当 $k=L$ 时，修改这个连续段一定会让这一段的与从 $1$ 变 $0$。
此外，因为只有连续的两个 $0$，把任意一个 $0$ 修改掉都会导致连续段一旁边的一个位置与值从 $0$ 变 $1$
因此，我们只需要按照 $1$ 连续段的长度取 min 即可

[***AC 代码***](https://qoj.ac/submission/2370207)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void gmin(auto &x, auto y) {
    x = min(x, y);
}

void solve() {
    int n, b;
    cin >> n >> b;
    vector<int> a(n * 2 + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        a[i + n] = a[i];
    }
    
    int ans = n;
    for (int i = 0; i < b; ++i) {
        for (int j = 1; j + 2 <= 2 * n; ++j) {
            if ((~a[j]>>i&1) && (~a[j+1]>>i&1) && (~a[j+2]>>i&1)) {
                ans = 1;
            }
        }
        int last = -1;
        for (int j = 1; j <= 2 * n; ++j) {
            if (~a[j]>>i&1) {
                if (last != -1 && j - last - 1 > 0) {
                    gmin(ans, j - last - 1);
                }
                last = j;
            }
        }
    }
    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int t = 1;
    // cin >> t;
    while (t--) {
        solve();
    }
}
```
