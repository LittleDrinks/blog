## [L3-035 完美树](https://pintia.cn/problem-sets/994805046380707840/exam/problems/type/7?page=2&problemSetProblemId=1649748772845703169)

设 $dp(u, \Delta)$ 表示以 $u$ 为根的子树内令 $\Delta=\text{白节点数量-黑节点数量}$ 的最小花费。
$O(n^2)$ 的树背包做法不难想到， 接下来考虑如何优化。
分子树内节点数量为奇数和偶数两种情况讨论。

- 当节点数量为偶数时，必须满足 $\Delta=0$
- 当节点数量为奇数时，必须满足 $\Delta=\pm1$

考虑反悔贪心。我们先钦定以 $u$ 为根的子树内，所有节点数量为奇数的子树都满足 $\Delta=-1$。要让 $u$ 子树满足条件，我们可以每次选择 $\Delta cost =dp(v,1)-dp(v,-1)$ 最小（最负）的那一个更新花费，然后让 $\Delta\to\Delta+2$，直到 $|\Delta|\le1$ 为止。
时间复杂度 $O(n\log n)$

[***AC 代码***]()

```cpp
#include <bits/stdc++.h>
using namespace std;

const int inf = 1e9;
const int B = 2;

template<typename T>
void gmin(T &x, T y) { x = min(x, y); }

int main()
{
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int n;
    cin >> n;
    vector<int> c(n + 1), p(n + 1);
    vector G(n + 1, vector<int>());
    for (int i = 1; i <= n; ++i) {
        cin >> c[i] >> p[i];
        int k;
        cin >> k;
        while (k--) {
            int x; cin >> x;
            G[i].push_back(x);
            G[x].push_back(i);
        }
    }

    vector<int> siz(n + 1, 1);
    vector f(n + 1, vector<int>(2*B+1, inf));
    auto dfs = [&](auto &&dfs, int u, int fa) -> void {
        int cost = (c[u] ? 0 : p[u]);
        int cnt = -1;
        multiset<int> dt{(c[u] ? p[u] : -p[u])};
        for (auto v: G[u]) {
            if (v == fa) {
                continue;
            }
            dfs(dfs, v, u);
            siz[u] += siz[v];
            if (siz[v] % 2 == 0) {
                cost += f[v][B];
            }
            else {
                cost += f[v][B-1];
                --cnt;
                dt.insert(f[v][B+1] - f[v][B-1]);
            }
        }
        
        while (!dt.empty() && cnt <= 1) {
            if (-1 <= cnt && cnt <= 1) {
                f[u][cnt+B] = cost;
            }
            cnt += 2;
            cost += *dt.begin();
            dt.erase(dt.begin());
            if (-1 <= cnt && cnt <= 1) {
                f[u][cnt+B] = cost;
            }
        }
    };
    dfs(dfs, 1, 0);

    cout << *min_element(f[1].begin(), f[1].end()) << "\n";
}
```
