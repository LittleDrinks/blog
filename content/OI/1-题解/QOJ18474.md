## [QOJ18474. 最大权独立集问题](https://qoj.ac/contest/3789/problem/18474)

> [!note] 结论
> $$
> \text{popcount}(x\oplus y)\equiv \text{popcount}(x)+\text{popcount}(y)\pmod 2
> $$

于是题目的条件可以翻译为：当且仅当 $x,y$ 二进制中 $1$ 数量的奇偶性不同时，两者会连边。
这是一张完全二分图，一部分是 $\text{popcount}(x)$ 为奇数的，另一部分是偶数的。
显然最大独立集是两部分中较大的那个，取 $\max$ 即可

[***AC 代码***](https://qoj.ac/submission/2516287)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

void solve() {
    int n;
    cin >> n;
    ll s[2]{0,0};
    for (int i = 1; i <= n; ++i) {
        int x; 
        cin >> x;
        s[popcount((unsigned)x)%2] += x;
    }
    cout << max(s[0], s[1]) << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
}
```
