## [CF2276F](https://codeforces.com/contest/2276/problem/F)

首先不要读错题，每一轮的玩家都可以选择自己是染什么颜色

> [!tip] Observation 1
> $a_i$ 需要被交换到下标为 $a_i$ 的地方，所以下标为 $i$ 和下标为 $a_i$ 的位置必须是同一个颜色。
> 
> $i$ 向 $a_i$ 连边，能形成若干个置换环

然后开始思考博弈方式

> [!tip] Observation 2
> 每次 Bob 染色了环的若干部分，Alice 在下一轮必须把这些环的剩下部分全部染成同一种颜色
> 
> 否则 Bob 在下一轮把环涂成一种相反的颜色即可获胜

这启发我们进行更加细致的分类讨论

---

接下来记 $siz[]$ 表示环的大小，从大到小排序
考虑一些极端的情况
- 如果 $k=1$
    - 有大小 $\ge3$ 的环时，Bob 必胜
    - 全部都是大小为 $2$ 的环时，先手必败
    - 据此，存在大小为 $2$ 的环时，$1$ 的数量为奇数时 Alice 必胜
    - 如果全是大小为 $1$ 的环，那就相当于已经排完序了，Alice 必胜
- 如果 $siz[1]>k+1$，Bob 必胜，因为 Alice 一轮删不掉，Bob 在此基础上操作 $1$ 即可
- 如果 $siz[1]=k+1$
    - 如果存在至少两个为 $k+1$ 的环，Alice 必败
    - 如果只有一个大小为 $k$ 的环
        - 先碰这个大小为 $k$ 的环的人必败（Alice 先碰 Bob 可以反色，Bob 先碰 Alice 可以同色）
        - Alice 必须把剩下所有不为 $1$ 的环 $\sum S$ 在第一轮删光，否则 Bob 可以构造 $k+...$
        - 剩下 $c$ 个 $1$ 就是一个 Nim 博弈了，$\bmod (k+1) = 0$ 的时候先手必败
        - 综合上面几条，此时 Alice 只要能删掉 $c\bmod(k+1)+\sum S$ 个环，就可以赢

---

对于剩下 $siz\le k$ 的情况，Bob 的最优攻击方式是，从大到小选择若干个环，每个环上选一个位置染色，剩下 $\sum (siz[x]-1)$ 个元素必须在下一轮由 Alice 染色。
这种攻击显然是从大到小选最优，因而如果第一轮没有成功，后续就不可能再成功了
Alice 可以在第一轮反制，减少前 $k$ 大置换环大小之和

> [!tip] Observation 3
> Alice 不能直接贪心选最大的删除
> 
> 考虑环的大小为 $[4,4,3,3],\ k=6$ 的情况，如果 Alice 删除一个 $4$，Bob 对应剩下三个环中各删掉一个数，Alice 就输了

这启发我们背包 DP
设 $dp(x,y,z)$ 表示前 $x$ 个环，Alice 选了 $y$ 个，且所有环的大小 $\le z$ 时，Bob 下一轮攻击后 Alice 最少需要花费的步数。
一种好写的转移方式是设 $x\le \min(2k,环的总数)$，转移方程：
$$
\begin{cases} 
dp(x,y,z) \leftarrow dp(x-1,y-1,z-siz[x]) & y>0 \land z\ge siz[x] \\
dp(x,y,z)\leftarrow dp(x-1,y,z)+cost
\end{cases}
$$
其中 $cost$ 表示 Bob 能构成多少的攻击，表达式为 `x-y<=k? siz[x]-1: 0`
时间复杂度 $O(k^3)$

[***AC 代码***](https://codeforces.com/contest/2276/submission/396087903)

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using db = long double;
using i128 = __int128;

template<typename T1,typename T2> ostream& operator<<(ostream& os, const pair<T1,T2>& p) {
    return os<<"("<<p.first<<","<<p.second<<")";
}
template<typename T> ostream& operator<<(ostream& os, const vector<T>& v) {
    os<<"["; for(int i=0;i<v.size();++i) os<<(i?", ":"")<<v[i]; return os<<"]";
}
template<typename T> void gmax(T&x,T y){ x = max(x, y); }
template<typename T> void gmin(T&x,T y){ x = min(x, y); }

struct DSU {
    int n;
    vector<int> f, siz;
    DSU(int n): n(n), f(n+1), siz(n+1, 1) {
        iota(f.begin(), f.end(), 0);
    }
    int find(int x) {
        return f[x]==x? f[x]: f[x]=find(f[x]);
    }
    void merge(int x, int y) {
        x = find(x);
        y = find(y);
        if (x == y) return;
        siz[y] += siz[x];
        siz[x] = 0;
        f[x] = y;
    }
    bool same(int x, int y) {
        return find(x) == find(y);
    }
};

const int inf = 1e9;

void solve() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n+1);
    DSU D(n);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        D.merge(i, a[i]);
    }
    int sg = 0;
    vector<int> vis(n+1);
    vector<int> siz{0};
    int tot = 0;
    for (int i = 1; i <= n; ++i) {
        int x = D.find(i);
        if (!vis[x]) {
            ++tot;
            vis[x] = 1;
            siz.push_back(D.siz[x]);
        }
    }

    if (k == 1) {
        int cnt=0, have2=false, have3=false;
        for (auto z: siz) {
            cnt += (z == 1);
            if (z > 2) have3 = true; 
            if (z == 2) have2 = true; 
        }
        cout << ((have3||(have2&&cnt%2==0))?"Bob":"Alice") << "\n";
        return;
    }

    sort(siz.begin()+1, siz.end(), greater<>());

    if (siz[1] > k+1) {
        cout << "Bob\n";
        return;
    }

    if (siz[1] == k+1) {
        if (tot >= 2 && siz[2] == k+1) {
            cout << "Bob\n";
            return;
        }
        int must = 0, c = 0;
        for (int i = 2; i <= tot; ++i) {
            if (siz[i] >= 2) {
                must += siz[i];
            } else {
                ++c;
            }
        }
        must += c%(k+1);
        cout << (1<=must&&must<=k? "Alice": "Bob") << "\n";
        return;
    }

    // dp[x][y][z]
    // 前 i 个数里
    // 选 <= j 个删除
    // 容量 <= k
    int m = min(2*k, tot);
    vector dp(m+1, vector(k+1, vector<int>(k+1, inf)));
    dp[0][0][0] = 0;
    for (int x = 1; x <= m; ++x) {
        for (int y = 0; y <= k; ++y) {
            for (int z = 0; z <= k; ++z) {
                if (y > 0 && z >= siz[x]) {  // Alice
                    gmin(dp[x][y][z], dp[x-1][y-1][z-siz[x]]);
                }
                int cost = (x-y<=k? siz[x]-1: 0);
                gmin(dp[x][y][z], dp[x-1][y][z]+cost);
            }
        }
    }
    bool ok = false;
    for (int y = 1; y <= k; ++y) {
        for (int z = 1; z <= k; ++z) {
            ok |= (dp[m][y][z] <= k);
        }
    }

    cout << (ok? "Alice": "Bob") << "\n";
}

int main() {
    ios::sync_with_stdio(0); cin.tie(0); cout.tie(0); 
    int t = 1;
    cin >> t;
    while (t--) {
        solve();
    }
}
```
