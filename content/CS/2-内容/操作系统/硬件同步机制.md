关中断：“开/关中断指令”，进程开始访问临界区到结束访问为止都不允许被中断
执行效率低；只适用于内核程序

原子化指令：Test and Set
```cpp
do {
    while TS(&lock);
    critical section;
    lock := false;
    remainder section;
} while(true);
```
实现简单，适用于多处理机环境，但不满足“让权等待”原则，会有“忙等”现象

原子化指令：Swap，逻辑上和 TS 等价
```cpp
do {
	do {
	    key = true;
	    swap(&lock, &key);
	} while (key != false);
    // 临界区操作
    lock = false;
} while (true);
```
