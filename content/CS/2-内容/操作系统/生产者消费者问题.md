生产者—消费者问题是并发[[进程]] 共享有界缓冲池的经典同步互斥模型。
一组生产者进程向容量为 $n$ 的环形缓冲区写入数据，一组消费者进程从缓冲区读取数据。

> [!faq]- 【14-15 秋期末二·7】生产者-消费者问题是（　）。</br>A. 工厂生产调度问题</br>B. 使用缓冲区时的同步互斥问题</br>C. 资源分配问题</br>D. 进程调度问题
> 选 B。
> 
> 生产者-消费者问题的本质是并发进程在共享有界缓冲区时的同步与互斥问题。

> [!faq]- 【第 2 章作业题 1·(1)】请用[[记录型信号量]] 解决生产者-消费者问题，并写出相应的伪代码。
> ```c
> int in = 0, out = 0;
> item buffer[n];
> semaphore mutex = 1, empty = n, full = 0;  // 有n个空，有0个满
> 
> void producer() {
>     do {
>         produce an item in nextp;
>         wait(empty);      // 先申请空缓冲（同步信号量）
>         wait(mutex);      // 再申请缓冲池互斥锁
>         buffer[in] = nextp;
>         in = (in + 1) % n;
>         signal(mutex);
>         signal(full);
>     } while (TRUE);
> }
> 
> void consumer() {
>     do {
>         wait(full);       // 先申请满缓冲（同步信号量）
>         wait(mutex);      // 再申请缓冲池互斥锁
>         nextc = buffer[out];
>         out = (out + 1) % n;
>         signal(mutex);
>         signal(empty);
>         consume the item in nextc;
>     } while (TRUE);
> }
> 
> void main() {
>     cobegin producer(); consumer(); coend
> }
> ```

> [!faq]- 【第 2 章作业题 1·(2)】请用 [[AND型信号量]] 解决生产者-消费者问题，并写出相应的伪代码。
> ```c
> int in = 0, out = 0;
> item buffer[n];
> semaphore mutex = 1, empty = n, full = 0;
> 
> void producer() {
>     do {
>         produce an item in nextp;
>         Swait(empty, mutex); // 原子性同时申请空缓冲与互斥锁
>         buffer[in] = nextp;
>         in = (in + 1) % n;
>         Ssignal(mutex, full);
>     } while (TRUE);
> }
> 
> void consumer() {
>     do {
>         Swait(full, mutex);  // 原子性同时申请满缓冲与互斥锁
>         nextc = buffer[out];
>         out = (out + 1) % n;
>         Ssignal(mutex, empty);
>         consume the item in nextc;
>     } while (TRUE);
> }
> ```

用[[管程]]解决：
```cpp
monitor ProducerConsumer {
    condition full, empty;  // 分别表示 not_full 和 not_empty
    int count=0;
    void insert(Item item) {
        if (count == N) full.wait();
        count++;
        insert_item(item);
        if (count == 1) empty.signal();
    }
    void remove() {
        if (count == 0) empty.wait();
        count--;
        if (count == N) signal(full);
        return remove_item();
    }
}
end monitor;

Producer() { while(1) { item=produce(); ProducerConsumer.insert(item); } }
Consumer() { while(1) { item=ProducerConsumer.remove(); consume(item); } }
```

> ```c
> /* 生产者进程 */
> while (TRUE) {
>     生产一个产品;
>     P(empty);
>     P(p_mutex);
>     产品送往 buffer(in);
>     in = (in + 1) mod n;
>     V(p_mutex);
>     V(full);
> }
> 
> /* 消费者进程 */
> while (TRUE) {
>     P(full);
>     P(c_mutex);
>     从 buffer(out) 中取出产品;
>     out = (out + 1) mod n;
>     V(c_mutex);
>     V(empty);
> }
> ```

> [!faq]- 【王道第二章 2.3 单选第40题】所有的消费者必须等待生产者先运行的前提条件是（ ）。</br>A.缓冲区空</br>B.缓冲区满</br>C.缓冲区不可用</br>D.缓冲区半空
> **【答案】** A
>
> **【解析】** 当缓冲区为空时，消费者进程取产品会被阻塞，此时需等待生产者进程生产新产品。

> [!faq]- 【王道第二章 2.3 单选第41题】下列关于生产者－消费者问题的唤醒操作的说法中，正确的是（ ）。</br>Ⅰ.生产者唤醒其他生产者</br>Ⅱ.生产者唤醒消费者</br>Ⅲ.消费者唤醒其他消费者</br>Ⅳ.消费者唤醒生产者</br>A.Ⅰ和Ⅱ　B.Ⅲ和Ⅳ　C.Ⅱ和Ⅲ　D.Ⅰ、Ⅱ、Ⅲ和Ⅳ
> **【答案】** D
>
> **【解析】** 生产者和消费者共享缓冲区，每次只允许一个生产者或消费者进入缓冲区，当有一个生产者或消费者进入缓冲区时，其他生产者或消费者就必须阻塞等待。因此，生产者有可能唤醒其他生产者或消费者，消费者也有可能唤醒其他生产者或消费者，四个选项均正确。
