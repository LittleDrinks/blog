高响应比优先（Highest Response Ratio Next，HRRN）是对 FCFS 与 [[短作业优先调度]] 的综合折中方案，专为解决短作业优先导致的“长作业饥饿”而设计。

算法属于非抢占式调度，每次调度时动态计算就绪队列中各任务的响应比 $R_p$，选取 $R_p$ 最高的任务投入执行。

响应比动态计算公式：
$$R_p = \frac{\text{等待时间 } T_w + \text{服务时间 } T_s}{\text{服务时间 } T_s} = 1 + \frac{T_w}{T_s}$$

动态自适应机理：
1. 短作业照顾：当等待时间 $T_w$ 较小时，服务时间 $T_s$ 越小的作业，其 $\frac{T_w}{T_s}$ 增长越快，优先被调度（呈现短作业优先特性）。
2. 长作业保底：当长作业被推迟等待很长时间后，$T_w$ 持续累积膨胀，带动 $R_p$ 显著攀升，最终超过新到的短作业，必然获得处理机调度，彻底消除了饥饿现象。
3. FCFS 兼容：对于服务时间相近的作业，等待越久的先调度（退化为 FCFS）。

核心代价是每次选择前必须为队列中所有等待作业实时计算响应比，带来不可忽视的调度算法运算开销。

> [!faq]- 【14-15秋期末七·(1)】在一个分时系统中，$5$ 个进程的（提交时间，所需运行时间）分别为：$A(0, 4), B(1, 5), C(2, 3), D(3, 2), E(4, 1)$。若采用最高响应比优先（HRRN）调度算法，求各进程的开始时间、结束时间、[[周转时间]]、带权周转时间、平均周转时间、平均带权周转时间及进程调度序列（$6$ 分）。
> - 时刻 $0$：仅 $A$ 到达，$A$ 在 $0 \sim 4$ 执行，完成时刻 $4$，周转时间 $T_A = 4 - 0 = 4$，带权周转时间 $W_A = \frac{4}{4} = 1$。
> - 时刻 $4$：$B, C, D, E$ 均已到达。计算响应比 $R_p = 1 + \frac{T_w}{T_s}$：$R_p(B) = 1 + \frac{3}{5} = 1.6$，$R_p(C) = 1 + \frac{2}{3} \approx 1.67$，$R_p(D) = 1 + \frac{1}{2} = 1.5$，$R_p(E) = 1 + \frac{0}{1} = 1$。选中 $C$ 在 $4 \sim 7$ 执行，完成时刻 $7$，$T_C = 7 - 2 = 5$，$W_C = \frac{5}{3}$。
> - 时刻 $7$：计算剩余进程响应比：$R_p(B) = 1 + \frac{6}{5} = 2.2$，$R_p(D) = 1 + \frac{4}{2} = 3$，$R_p(E) = 1 + \frac{3}{1} = 4$。选中 $E$ 在 $7 \sim 8$ 执行，完成时刻 $8$，$T_E = 8 - 4 = 4$，$W_E = \frac{4}{1} = 4$。
> - 时刻 $8$：计算剩余进程响应比：$R_p(B) = 1 + \frac{7}{5} = 2.4$，$R_p(D) = 1 + \frac{5}{2} = 3.5$。选中 $D$ 在 $8 \sim 10$ 执行，完成时刻 $10$，$T_D = 10 - 3 = 7$，$W_D = \frac{7}{2} = 3.5$。
> - 时刻 $10$：最后执行 $B$，在 $10 \sim 15$ 执行，完成时刻 $15$，$T_B = 15 - 1 = 14$，$W_B = \frac{14}{5} = 2.8$。
> - 汇总指标：进程调度序列为 `A, C, E, D, B`；平均周转时间 $\bar{T} = \frac{4 + 14 + 5 + 7 + 4}{5} = 6.8$；平均带权周转时间 $\bar{W} = \frac{1 + 2.8 + 1.67 + 3.5 + 4}{5} = 2.6$。

算例：作业 A、B 同时到达，服务时间 $T_s(A)=20\text{ ms}$、$T_s(B)=100\text{ ms}$，等待 $40\text{ ms}$ 时 $R_p(A)=1+40/20=3$，$R_p(B)=1+40/100=1.4$，调度选择 A。
