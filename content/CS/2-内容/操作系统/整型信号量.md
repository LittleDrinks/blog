整型信号量是最早的信号量形式，用一个整型量 $S$ 表示可用资源数目。除初始化外，$S$ 只能通过两个原子操作访问：`wait(S)` 又称 `P(S)`，`signal(S)` 又称 `V(S)`。

```c
wait(S) {
    while (S <= 0);   /* 循环测试 */
    S--;
}
signal(S) {
    S++;
}
```

`wait` 的语义是申请一个单位资源：资源不足时停留在循环中，资源可用时把 $S$ 减一。`signal` 的语义是释放一个单位资源：把 $S$ 加一。两个操作必须原子执行，中间不可中断，否则多个进程可能同时通过 `wait` 的判断。

初值决定用途。$S$ 初值为 $1$ 时用于互斥，等价于一把锁；$S$ 初值为 $n$ 时表示系统中有 $n$ 个同类资源，任一进程执行 `wait` 取得一个。

缺陷在 `wait` 的实现方式。资源不足时进程在 `while` 中反复测试，持续占用 CPU，不满足四条准则中的让权等待。改进办法是把整型量换成记录型结构，增加一个等待队列，资源不足时把进程阻塞在队列上，见 [[记录型信号量]]。
