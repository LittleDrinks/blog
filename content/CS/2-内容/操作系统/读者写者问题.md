多个并发 [[进程]] 共享同一个文件或数据区：允许多个读者同时并发读取，但严禁写者与任何其他读者或写者同时访问。

核心设计机制：
1. [[记录型信号量]] 解法（读者优先 / 读写公平）：
   - 设 `wmutex = 1` 实现读与写、写与写之间的互斥；设整型计数器 `readcount = 0` 统计当前正在读的进程数；设 `rmutex = 1` 保护多个读者对全局变量 `readcount` 的互斥修改。
   - 首尾读者代理锁：仅当第 $1$ 个读者进入时（`readcount == 0`）负责执行 `wait(wmutex)` 阻塞后续写者；后续读者直接递增 `readcount` 并发读取；仅当最后 $1$ 个读者离开时（`readcount` 减为 $0$）负责执行 `signal(wmutex)` 唤醒等待的写者。
   - 若要避免写者饥饿（读写公平），可再引入排队信号量 `w = 1`，使读者和写者均先经过 `wait(w)` 公平排队。
2. [[信号量集]] 解法（限制最多 $RN$ 个读者同时读）：
   - 设信号量 `L = RN` 控制剩余允许进入的读者名额，`mx = 1` 控制写互斥。
   - 读者执行 `Swait(L, 1, 1)` 扣减 $1$ 个名额并执行 `Swait(mx, 1, 0)`（开关测试：当 `mx >= 1` 即无写者时放行，但不扣减 `mx`）。
   - 写者执行 `Swait(mx, 1, 1; L, RN, 0)`：仅当 `mx >= 1`（无其他写者）且 `L >= RN`（无任何读者占用名额）时，才分配 `mx` 进入写操作。

> [!faq]- 【第2章作业题1·(5)】请用 [[记录型信号量]] 解决读者-写者问题，并写出相应的伪代码。
> ```c
> semaphore rmutex = 1, wmutex = 1;
> semaphore w = 1; // 用于读写公平排队，防止写者饥饿
> int readcount = 0;
> 
> void reader() {
>     do {
>         wait(w);
>         wait(rmutex);
>         if (readcount == 0) wait(wmutex); // 第 1 个读者负责锁写者
>         readcount++;
>         signal(rmutex);
>         signal(w);
>         // perform read operation
>         wait(rmutex);
>         readcount--;
>         if (readcount == 0) signal(wmutex); // 最后 1 个读者负责释放写锁
>         signal(rmutex);
>     } while (TRUE);
> }
> 
> void writer() {
>     do {
>         wait(w);
>         wait(wmutex);
>         // perform write operation
>         signal(wmutex);
>         signal(w);
>     } while (TRUE);
> }
> 
> void main() {
>     cobegin reader(); writer(); coend
> }
> ```

> [!faq]- 【第2章作业题1·(6)】请用 [[信号量集]] 机制解决读者-写者问题（最多允许 $RN$ 个读者同时读），并写出相应的伪代码。
> ```c
> int RN;
> semaphore L = RN, mx = 1;
> 
> void reader() {
>     do {
>         Swait(L, 1, 1);
>         Swait(mx, 1, 0); // 当 mx >= 1（无写者）时放行，不消耗 mx
>         // perform read operation
>         Ssignal(L, 1);
>     } while (TRUE);
> }
> 
> void writer() {
>     do {
>         Swait(mx, 1, 1, L, RN, 0); // 既无 writer 在写(mx=1)、又无 reader 在读(L=RN)才能写
>         // perform write operation
>         Ssignal(mx, 1);
>     } while (TRUE);
> }
> 
> void main() {
>     cobegin reader(); writer(); coend
> }
> ```
