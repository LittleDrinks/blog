多个并发 [[进程]] 共享同一个文件或数据区：允许多个读者同时并发读取，但严禁写者与任何其他读者或写者同时访问。

> [!faq]- 【第2章作业题1·(5)】请用 [[记录型信号量]] 解决读者-写者问题，并写出相应的伪代码。
> ```c
> semaphore rmutex = 1, wmutex = 1;
> semaphore w = 1; // 用于读写公平排队，防止写者饥饿
> int readcount = 0;
> 
> void reader() {
>     do {
>         wait(w);
>         wait(rmutex);
>         if (readcount == 0) wait(wmutex); // 第 1 个读者负责锁写者
>         readcount++;
>         signal(rmutex);
>         signal(w);
>         // perform read operation
>         wait(rmutex);
>         readcount--;
>         if (readcount == 0) signal(wmutex); // 最后 1 个读者负责释放写锁
>         signal(rmutex);
>     } while (TRUE);
> }
> 
> void writer() {
>     do {
>         wait(w);
>         wait(wmutex);
>         // perform write operation
>         signal(wmutex);
>         signal(w);
>     } while (TRUE);
> }
> 
> void main() {
>     cobegin reader(); writer(); coend
> }
> ```

> [!faq]- 【第2章作业题1·(6)】请用 [[信号量集]] 机制解决读者-写者问题（最多允许 $RN$ 个读者同时读），并写出相应的伪代码。
> ```c
> int RN;
> semaphore L = RN, mx = 1;
> 
> void reader() {
>     do {
>         Swait(L, 1, 1);
>         Swait(mx, 1, 0); // 当 mx >= 1（无写者）时放行，不消耗 mx
>         // perform read operation
>         Ssignal(L, 1);
>     } while (TRUE);
> }
> 
> void writer() {
>     do {
>         Swait(mx, 1, 1, L, RN, 0); // 既无 writer 在写(mx=1)、又无 reader 在读(L=RN)才能写
>         // perform write operation
>         Ssignal(mx, 1);
>     } while (TRUE);
> }
> 
> void main() {
>     cobegin reader(); writer(); coend
> }
> ```

> [!faq]- 【王道第二章 2.3 单选第31题】若系统有n个进程，则就绪队列中进程的个数最多有（①）个；阻塞队列中进程的个数最多有（②）个。①</br>A.n＋1</br>B. n</br>C. n－1</br>D. 1②</br>A. n＋1</br>B. n</br>C. n－1</br>D.1
> **【答案】** ①C②B
>
> **【解析】** ① 系统中有n个进程，只要这些进程不都处于阻塞态，则至少有一个进程正在处理器上运行（处理器至少有一个），因此就绪队列中的进程个数最多有n－1个。选项B容易被错选，以为出现了处理器为空、就绪队列全满的情况，实际调度无此状态。②本题易错选C，阻塞队列有n－1个进程是可能发生的，但不是最多的情况。不少读者会忽略死锁的情况，死锁就是n个进程都被阻塞，因此阻塞队列最多可以有n个进程。

> [!faq]- 【王道第二章 2.3 单选第44题】在读者－写者问题中，能同时执行的是（）。</br>A.读者和写者</br>B.不同的写者</br>C.不同的读者</br>D.都不能
> **【答案】** C
>
> **【解析】** 在读者－写者问题中，写者和写者之间、写者和读者之间必须互斥访问共享对象，读者和读者之间则可以同时访问。
