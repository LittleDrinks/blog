单道批处理受限于 CPU 与 I/O 设备的串行等待，CPU 利用率极低。多道批处理系统在内存中同时存放多道独立的作业，当某道作业因 I/O 请求阻塞时，调度程序立即将 CPU 切换给另一道就绪作业执行。

核心机制依赖于中断系统与通道技术，实现计算与 I/O 硬件在物理层面的并行重叠。

核心代价：
1. 彻底失去了人机交互能力。作业提交后变为黑盒执行，用户无法干预中间状态。
2. 作业周转周期不可控，导致短作业响应时延恶化。为解决即时交互需求，催生了 [[分时系统]]。

> [!faq]- 【真题计算】系统有 $3$ 个作业，单道串行耗时为 $180\text{ ms}, 150\text{ ms}, 160\text{ ms}$（各含 $60\text{ ms}, 50\text{ ms}, 80\text{ ms}$ 的 I/O 操作）。在单道和多道并发下 CPU 利用率分别是多少？
> 单道总耗时为三者之和 $180 + 150 + 160 = 490\text{ ms}$，纯 CPU 计算时间为 $(180 - 60) + (150 - 50) + (160 - 80) = 300\text{ ms}$，利用率为 $\frac{300}{490} \approx 61.2\%$。
> 
> 多道并发下计算与 I/O 重叠并行，总时间压缩为 $310\text{ ms}$，利用率提升至 $\frac{300}{310} \approx 96.8\%$。
