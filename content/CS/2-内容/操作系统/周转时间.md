周转时间（Sojourn Time）是批处理系统中衡量 [[处理机调度]] 算法效率的核心指标，指从作业提交给系统开始，到作业完全执行完成并退出系统所经历的全部时间间隔。

核心推导公式：
1. 周转时间（$T$）：$$T = \text{完成时刻} - \text{到达时刻} = \text{实际服务运行时间 } T_s + \text{排队等待时间 } T_w$$
2. 平均周转时间（$\bar{T}$）：$$\bar{T} = \frac{1}{n}\sum_{i=1}^{n} T_i$$
3. 带权周转时间（$W$，反映用户对等待感知的相对不满程度）：$$W = \frac{T}{T_s} = \frac{T_s + T_w}{T_s} = 1 + \frac{T_w}{T_s} \ge 1$$
4. 平均带权周转时间（$\bar{W}$）：$$\bar{W} = \frac{1}{n}\sum_{i=1}^{n} W_i$$

若一个运行耗时仅 $\pu{1 ms}$ 的短任务排队等待了 $\pu{100 ms}$，其带权周转时间高达 $101$（用户感知体验极差）
而运行耗时 $\pu{1000 ms}$ 的长任务同样等待 $\pu{100 ms}$，带权周转时间仅为 $1.1$。

算例：作业 A 于 $0$ 时刻到达、需运行 $4$ 小时，作业 B 于 $1$ 时刻到达、需运行 $1$ 小时。按先来先服务调度，A 于 $4$ 完成，$T_A = 4 - 0 = 4$；B 于 $5$ 完成，$T_B = 5 - 1 = 4$；平均周转时间为 $(4+4)/2 = 4$ 小时。
