$5$ 位哲学家围坐圆桌，每两位哲学家之间放置 $1$ 支筷子，共 $5$ 支筷子。每位哲学家必须同时拿到左右两支筷子才能开始进餐。

若每位哲学家同时饿了并同时拿起其左侧筷子（`P(chopstick[i])`），紧接着去拿右侧筷子时发现全被邻座占有，导致所有人持有 $1$ 支筷子陷入无限阻塞，构成 [[死锁]] 环路。

破除死锁的三种经典策略：
1. 限制并发就餐人数：设置信号量 `count = 4`，最多仅允许 $4$ 位哲学家同时尝试拿筷子，利用抽屉原理保证必然至少有 $1$ 人能拿到双筷进餐。
2. 奇偶号不对称拿筷：规定奇数号哲学家先拿左筷再拿右筷，偶数号哲学家先拿右筷再拿左筷，打破对称性与环路等待条件。
3. 原子性申请全部资源（AND 型信号量）：仅当左右两支筷子同时空闲可用时，才允许哲学家一次性拿起双筷（如 `Swait(chopstick[(i+1)%5], chopstick[i])`），否则不拿任何筷子。

> [!faq]- 【14-15秋期末二·6】哲学家就餐问题是（　）。</br>A. 餐饮问题</br>B. 酒店管理问题</br>C. 同步互斥问题</br>D. 缓冲管理问题
> 选 C。
> 
> 哲学家就餐问题是操作系统中用于阐述并发进程竞争多个 [[临界资源]] 时如何协调同步互斥并防止 [[死锁]] 的经典问题。

> [!faq]- 【第2章作业题1·(3)】请用 [[记录型信号量]] 解决哲学家进餐问题，并写出相应的伪代码。
> 设置 `count = 4` 限制至多允许 $4$ 位哲学家同时竞争筷子，防止 $5$ 人同时持左筷死锁：
> 
> ```c
> semaphore chopstick[5] = {1, 1, 1, 1, 1};
> semaphore count = 4; // 至多允许 4 位哲学家同时竞争筷子
> 
> void philosopher(int i) {
>     do {
>         // think
>         wait(count);
>         wait(chopstick[i]);           // 先拿左边筷子
>         wait(chopstick[(i + 1) % 5]); // 再拿右边筷子
>         // eat
>         signal(chopstick[i]);
>         signal(chopstick[(i + 1) % 5]);
>         signal(count);
>     } while (TRUE);
> }
> ```

> [!faq]- 【第2章作业题1·(4)】请用 AND 型信号量解决哲学家进餐问题，并写出相应的伪代码。
> 利用 AND 型信号量要求左右两支筷子同时可用时才一次性原子分配，破坏请求和保持条件：
> 
> ```c
> semaphore chopstick[5] = {1, 1, 1, 1, 1};
> 
> void philosopher(int i) {
>     do {
>         // think
>         Swait(chopstick[(i + 1) % 5], chopstick[i]);   // 两支筷子同时拿
>         // eat
>         Ssignal(chopstick[(i + 1) % 5], chopstick[i]); // 两支筷子同时放下
>     } while (TRUE);
> }
> ```

三种策略破坏的必要条件不同：奇偶号不对称拿筷破坏环路等待条件；AND 型信号量一次性申请全部资源破坏请求和保持条件。

> [!faq]- 【王道第二章 2.3 单选第45题】哲学家就餐问题的解决方案如下。其中，信号量 seat 的初值最大为（ ）。</br>A.0　B.1　C.4　D.5
> ![[王道习题原图/王道2.3单选45-程序.png]]
>
> **【答案】** C
>
> **【解析】** 信号量seat 表示桌子上可以坐下的位置数，因为只有五个位置，所以每次只能有四位哲学家同时拿起左边的餐叉，才能保证不会发生死锁，所以seat的初值应该为4。

> [!faq]- 【王道第二章 2.4 单选第02题】在哲学家进餐问题中，若所有哲学家同时拿起左筷子，则发生死锁，因为他们都需要右筷子才能用餐。为了让尽可能多的哲学家可以同时用餐，并且不发生死锁，可以利用信号量PV操作实现同步互斥，下列说法中正确的是（ ）。</br>A.使用信号量进行控制的方法一定可以避免死锁</br>B. 同时检查两支筷子是否可用的方法可以预防死锁，但是会导致饥饿问题</br>C.限制允许拿起筷子的哲学家数量可以预防死锁，它破坏了“循环等待”条件</br>D. 对哲学家顺序编号，奇数号哲学家先拿左筷子，然后拿右筷子，而偶数号哲学家刚好相反，可以预防死锁，它破坏了“互斥”条件
> **【答案】** C
>
> **【解析】** 信号量机制能确保临界资源的互斥访问，不能完全避免死锁，选项A错误。同时检查两支筷子是否可用的方法可以预防死锁，但是会导致资源浪费，因为可能有一些空闲的筷子无法使用，但拿到筷子的哲学家用完餐后，释放筷子，其他哲学家就可以正常用餐，因此不会导致饥饿现象，选项B错误。若限制允许拿起筷子的哲学家数量，则不被允许的哲学家左边的哲学家一定可以拿到两边的筷子，从而破坏“循环等待”条件，选项C正确。对哲学家顺序编号，奇数号哲学家先拿左筷子，然后拿右筷子，而偶数号哲学家刚好相反，则相邻的哲学家总有一个可以拿起两边的筷子，但这破坏的是“循环等待”条件，而不是“互斥条件”，选项D错误。

> [!faq]- 【王道第二章 2.4 单选第33题】在哲学家就餐问题中，若同时存在左撇子和右撇子（将先拿起左侧筷子的人称为左撇子，而将先拿起右侧筷子的人称为右撇子），则不会发生死锁，因为破坏了（ ）。</br>A.互斥条件</br>B.请求与保持条件</br>C.不剥夺条件</br>D.循环等待条件
> **【答案】** D
>
> **【解析】** 当哲学家中同时存在左撇子（先取左侧筷子）和右撇子（先取右侧筷子）时，各进程请求资源的顺序不再一致，至少有一对相邻哲学家不会同时持有一根筷子并等待对方释放另一根，从而无法形成环形等待链，破坏了死锁的循环等待条件，避免了死锁的发生。
