图像的三种常见表示：

| 类型        | 数据范围           | shape               | 备注            |
| --------- | -------------- | ------------------- | ------------- |
| PIL Image | $[0,255]$ 中的整数 | `(H,W)` 或 `(H,W,C)` | 几何变换常在 PIL 上做 |
| Numpy     | $[0,255]$ 中的整数 | `(H,W,C)`           | OpenCV 常用     |
| Tensor    |                | `(C,H,W)`           | 神经网络输入        |


# transform
## 归一化
在归一化前，先使用 `transforms.ToTensor()` 转化为张量，把图片三个通道的值从 $[0,255]$ 变为 $[0,1]$
归一化公式为 $$x_{norm}=\frac{x-\mu}{\sigma}$$
可以通过 `transforms.Normalize((mean_R, mean_G, mean_B), (std_R, std_G, std_B))` 完成，三个参数分别对应 RGB 三通道
目的：让梯度下降更稳定，统一不同特征的尺度，加速收敛
比如，CIFAR-10 的真实均值和标准差大约为：
```python
 transforms.Normalize(
	 mean=(0.4914, 0.4822, 0.4465),
	 std=(0.2470, 0.2435, 0.2616)
 )
```
显示图像时，需要反归一化以保证显示效果，即 `img = img * std + mean`

## 数据增强
增加训练数据多样性，防止过拟合，只用于训练集
- 几何
	- 随机裁切 `transforms.RandomCrop(size, padding=None)`，随机裁切，可以配合 `padding` 实现图像随机平移
	- 水平翻转 `transforms.RandomHorizontalFlip(p=0.5)`，实现图像以概率 `p` 水平翻转
	- 随机旋转 `transforms.RandomRotation(degrees)`
- 颜色
	- `transforms.ColorJitter(brightness=0, contrast=0, saturation=0, hue=0)`
		- `brightness`：亮度幅度变化
		- `contrast`：对比度变化幅度
		- `saturation`：饱和度变化幅度
		- `hue`：色调变化幅度
	- 随机把图片变灰 `transforms.RandomGrayscale(p=0.1)`

CIFAR-10（自然图像分类）经典选择：
```python
train_transform = transforms.Compose([
	transforms.RandomCrop(32, padding=4),
	transforms.RandomHorizontalFlip(p=0.5),
	transforms.ToTensor(),
	transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))
])
```
