```cpp
SetType Find(ElementType X, DisjSet S)
{
	ElementType root, trail, lead;
	for (root=X; S[root]>0; root=S[root]);
	for (root=X; trail!=root; trail=lead) {
		lead=S[trail];
		S[trail]=root;
	}
}
```

> [!faq]- 设集合 $\{1,2,3,4,5\}$ 进行并查集操作序列为 $\text{union}(3,4),\text{union}(4,5),\text{union}(3,5),\text{union}(2,1),\text{union}(2,3)$，合并策略按节点个数多者为节点个数少者的双亲，相同节点个数以前者为双亲，问根节点为？
> $3$
