```cpp
template <class ElemType>
int BinSearch(ElemType elem[], int n, ElemType key) {
	int low=0, high=n+1;
	int mid;
	while (low <= high) {
		mid = (low + high) / 2;
		if (key == elem[mid])
			return mid;
		else if (key <= elem[mid])
			high = mid - 1;
		else
			low = mid + 1;
	}
	return -1;
}
```

> [!faq]- 设有序顺序表中的元素以此为 $\{017,094,154,170,275,503,509,512,533,612\}$，折半查找等概率情况下成功的平均查找长度为？
> $29 / 10$
> 所需的查找长度分别为：$3,2,3,4,1,3,2,4,3,4$
