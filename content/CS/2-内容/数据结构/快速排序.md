```cpp
template <class ElemType>
void QuickSort(ElemType elem[], int low, int high) {
    ElemType e=elem[low];
    int i=low, j=high;
	while (i < j)	{
		while (i < j && elem[j] >= e)	j--;
		if (i < j)  elem[i++]=elem[j];
		while (i < j && elem[i] <= e)	i++;
		if (i < j)  elem[j--]=elem[i];
	}
	elem[i]=e;
     if (low < i-1)	QuickSort(elem, low, i - 1);	
     if (i + 1 < high) QuickSort(elem, i + 1, high);
}
```

最优时间复杂度：$T(n)\le cn+2T(n / 2)\le\cdots\le cn\log_2n+nT(1)=O(n\log_2n)$
平均时间复杂度：$T(n)=cn+\frac{1}{n}\sum_{k=1}^n(T(n-k)+T(k-1))=cn+\frac{2}{n}\sum_{i=0}^{n-1}T(i)$
空间复杂度：$O(\log_2n)$
不稳定

> [!faq]- 对初始序列 $(50,81,42,31,72,42,101,62,15,60,34)$ 按递增方式进行排序。给出快速排序的第一趟排序结果（以第 1 个元素 50 为基准元素）。
> 快排可以理解为“挖坑法”，先把 $pivot=50$ 的位置留出来，从右往左找第一个 $>50$ 填到坑里，此时右侧形成一个坑，然后从左往右找第一个 $>50$ 填到右侧的坑里
> 
> 答案为：$(34, 15, 42, 31, 42, 50, 101, 62, 72, 60, 81)$
