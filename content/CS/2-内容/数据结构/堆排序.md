```cpp
template <class ElemType>
void FilterDown(ElemType elem[], int low, int high)   {
    int f = low, i = 2 * low + 1;
    ElemType   e = elem[low];
    while (i <= high) {	// f为被调整结点,i为f的最大孩子
	if (i < high && elem[i] < elem[i + 1])	i++;
            if (e < elem[i]){
	     elem[f] = elem[i];    f = i;     i = 2 * f + 1;
             }
             else          break;
      }
      elem[f] = e;
}
template <class ElemType>
void HeapSort(ElemType elem[], int n)
{
	int i;
	for (i=(n-2)/2; i >= 0; --i)
		FilterDown(elem, i, n - 1);
	for (i=n - 1; i > 0; --i)	{  // 第i趟堆排序
		Swap(elem[0], elem[i]);		
		FilterDown(elem, 0, i - 1);	
	}
}
```
$O(n)$ 建堆复杂度分析：设完全二叉树高 $k$（根第 $1$ 层，叶子第 $k$ 层），节点数 $n \ge 2^{k-1}$。  
第 $i$ 层有 $2^{i-1}$ 个节点，每个最多下沉 $(k-i)$ 层，每次下沉常数工作量记因子 $2$：
$$
\begin{aligned}
T &\le 2\sum_{i=1}^{k-1} 2^{i-1}(k-i) \\
&= 2\sum_{j=1}^{k-1} 2^{k-j-1}\cdot j \qquad (j=k-i) \\
&= 2\cdot 2^{k-1}\sum_{j=1}^{k-1}\frac{j}{2^j} \\
&\le 2n\sum_{j=1}^{\infty}\frac{j}{2^j}
\end{aligned}
$$
由 $\displaystyle\sum_{j=1}^{\infty}jx^j=\frac{x}{(1-x)^2}$，取 $x=\frac12$：
$$
\sum_{j=1}^{\infty}\frac{j}{2^j}=2
$$
故
$$
T \le 2n\cdot 2 = 4n = O(n)
$$
