顺序栈：用顺序存储方式存储的栈
链式栈

> [!faq]- 设栈 S 和队列 Q 的初始状态均为空，元素 abcdefg 依次进入栈 S，若每个元素出栈后立即进入队列 Q，且 7 个元素的出队顺序是 bdcfeag，则栈 S 的容量至少为？

> [!faq]- 判断：消除递归不一定需要栈
> √
> 
> 书 P 107
> 尾递归和单向递归可以使用循环结构的算法代替，比如
> ```c
> int fib(int n) {
>     if (n <= 1) return n;
>     return fib(n-1) + fib(n-2);
> }
> ```
> 存在**分支回溯**或**多层嵌套调用**时需要用栈消除递归

为了减少栈的上溢情况，可以把两个顺序栈存放在同一个数组中，将两个栈的栈底分别设置在数组两端，入栈时各自往中间延伸，当 `top1 == top2 + 1` 时才会溢出。这比两个栈分别各自占用一半的空间溢出概率小很多。

> [!faq]- 判断：为了增加内存空间的利用率和减少溢出的可能性，由两个顺序栈共享一片连续的内存空间，此时当其两个栈的栈顶相邻时，产生上溢。
> √
