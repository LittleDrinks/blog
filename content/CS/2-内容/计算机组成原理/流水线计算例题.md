# 流水线计算例题

### 例题1：基本流水线性能计算

**题目**：某指令流水线由5段组成，每段执行时间均为2ns。请计算：
1. 执行100条指令所需的总时间
2. 实际吞吐率
3. 加速比
4. 效率

**解答**：

已知：k = 5段，Δt = 2ns，n = 100条指令

#### (1) 总时间计算

```
T_k = (k + n - 1) × Δt = (5 + 100 - 1) × 2ns = 104 × 2ns = 208ns
```

#### (2) 吞吐率计算

```
TP = n / T_k = 100 / 208ns = 100 / (208 × 10^-9 s) = 4.81 × 10^8 条/秒 ≈ 481 MIPS
```

#### (3) 加速比计算

```
S = k × n / (k + n - 1) = 5 × 100 / 104 = 500 / 104 ≈ 4.81
```

#### (4) 效率计算

```
E = n / (k + n - 1) = 100 / 104 ≈ 96.15%
```

> [!tip]
> 当指令数很大时（n >> k），加速比接近流水线段数，效率接近100%。

### 例题2：不等长流水线段

**题目**：某流水线有4段，各段执行时间分别为：100ns、150ns、200ns、100ns。计算执行10条指令的吞吐率和加速比。

**解答**：

流水线时钟周期取决于**最长段**：
```
Δt = max(100, 150, 200, 100) = 200ns
```

#### 总时间

```
T_k = (k + n - 1) × Δt = (4 + 10 - 1) × 200ns = 13 × 200ns = 2600ns
```

#### 吞吐率

```
TP = n / T_k = 10 / 2600ns ≈ 3.85 × 10^6 条/秒
```

#### 加速比

```
T_nonpipe = n × (100 + 150 + 200 + 100) = 10 × 550ns = 5500ns
S = T_nonpipe / T_pipe = 5500ns / 2600ns ≈ 2.12
```

> [!warning]
> **关键点**：流水线时钟周期取各段中的**最大值**，短段会有空闲等待时间！

### 例题3：有停顿的流水线计算

**题目**：5段流水线（每段2ns），执行20条指令，假设有3次数据冒险，每次需停顿1个周期。计算实际吞吐率和加速比。

**解答**：

```
T_k = (k + n - 1 + 停顿次数) × Δt = (5 + 20 - 1 + 3) × 2ns = 27 × 2ns = 54ns

TP = 20 / 54ns ≈ 0.37 条/ns ≈ 370 MIPS

非流水线时间 = 20 × 5 × 2ns = 200ns
S = 200ns / 54ns ≈ 3.70

E = (20 × 5) / (27 × 5) = 100 / 135 ≈ 74.1%
```

> [!tip]
> 冒险导致的停顿会显著降低流水线效率！

### 例题4：带数据冒险的流水线详细计算

**题目**：某5段流水线（IF、ID、EX、MEM、WB），每段耗时10ns。执行以下指令序列：
```
I1: ADD R1, R2, R3   ; R1 = R2 + R3
I2: SUB R4, R1, R5   ; R4 = R1 - R5  （与I1有RAW相关）
I3: AND R6, R4, R7   ; R6 = R4 & R7  （与I2有RAW相关）
I4: OR  R8, R6, R9   ; R8 = R6 | R9  （与I3有RAW相关）
```
假设不采用数据前递技术，每次RAW相关需停顿3个周期。计算吞吐率、加速比、效率。

**解答**：

#### 分析数据冒险

| 冒险位置 | 类型 | 停顿周期数 |
|----------|------|-----------|
| I1→I2 | RAW | 3周期 |
| I2→I3 | RAW | 3周期 |
| I3→I4 | RAW | 3周期 |

总停顿 = 3次 × 3周期 = 9周期

```
无停顿理想时间 = (5 + 4 - 1) × 10ns = 80ns
实际时间 = 80ns + 9 × 10ns = 170ns

TP = 4 / 170ns ≈ 23.5 MIPS
S = (4 × 5 × 10ns) / 170ns = 200ns / 170ns ≈ 1.18
E = 20 / 85 ≈ 23.5%
```

> [!tip]
> 数据冒险导致大量停顿，效率大幅降低！采用数据前递技术可显著改善。

### 例题5：采用数据前递后的计算

**题目**：对于上题，假设采用数据前递技术，RAW相关只需停顿1个周期。重新计算各项指标。

**解答**：

```
总停顿 = 3次 × 1周期 = 3周期
实际时间 = 80ns + 30ns = 110ns
TP = 4 / 110ns ≈ 36.4 MIPS
S = 200ns / 110ns ≈ 1.82
E = 20 / 55 ≈ 36.4%
```

> [!warning]
> 数据前递使效率从23.5%提升到36.4%，效果显著！

### 例题6：不等长流水线计算

**题目**：某处理器采用5段流水线，各段耗时分别为80ns、70ns、90ns、80ns、70ns。求连续执行100条指令的吞吐率、加速比和效率。

**解答**：

```
T = max(80, 70, 90, 80, 70) = 90ns

T_pipe = (5 + 100 - 1) × 90ns = 104 × 90 = 9360ns
TP = 100 / 9360 ≈ 10.68 × 10^6 条/秒

T_seq = 100 × 390 = 39000ns
S = 39000 / 9360 ≈ 4.17

E = 39000 / (5 × 9360) ≈ 83.3%
```

### 例题7：理想情况计算

**题目**：某流水线有5段，理想情况下执行50条指令，求吞吐率、加速比、效率。

**解答**：

```
T = (5 + 50 - 1) × Δt = 54 × Δt
TP = 50 / (54 × Δt)
S = 250 / 54 ≈ 4.63
E = 50 / 54 ≈ 92.6%
```

> [!tip]
> 当指令数较大时，效率接近100%，加速比接近段数。

## 考试常见题型

> [!faq] 当n趋向无穷大时，流水线的加速比趋向于？</br>A. 0</br>B. 1</br>C. k（流水线段数）</br>D. 无穷大
> C。加速比公式S=k×n/(k+n-1)。当**n趋向无穷大**时，S趋向于**k**（流水线段数）。

> [!faq] 流水线的效率公式是什么？</br>A. n/T</br>B. k×n/(k+n-1)</br>C. n/(k+n-1)</br>D. (k+n-1)/k
> C。流水线效率E=**n/(k+n-1)**，或E=S/k。当n趋向无穷大时，E趋向于1（100%）。

> [!faq] 4段流水线，各段时间分别为100ns、150ns、200ns、100ns，执行10条指令。计算吞吐率和加速比。
> Δt=max(100,150,200,100)=200ns。总时间T=(4+10-1)×200ns=2600ns。TP=10/2600ns≈3.85×10^6条/秒。非流水时间=10×550=5500ns。S=5500/2600≈2.12。

> [!faq] 5段流水线每段2ns，执行20条指令，有3次数据冒险每次停顿1周期。计算实际吞吐率和加速比。
> T=(5+20-1+3)×2ns=54ns。TP=20/54ns≈370MIPS。S=200/54≈3.70。E=100/135≈74.1%。
