# 定点除法运算

> [!important] 概述
> 定点除法运算约占3-5分，可能考查不恢复余数法的计算过程。

## 原码恢复余数法

### 算法步骤

1. 符号位单独处理（异或）
2. 被除数和除数取绝对值
3. 被除数减去除数，判断余数符号
4. 余数为正：商1，余数左移再减
5. 余数为负：商0，恢复余数，左移再减

### 特点

- 每次不够减时需要恢复余数
- 运算步骤不固定
- 效率较低

### 例题1：恢复余数法

**已知**：x = 0.1011，y = 0.1101，求 x ÷ y

**解**：
- |x| = 0.1011，|y| = 0.1101，|y|补 = 0.1101
- [-|y|]补 = 1.0011

**步骤**（简略）：
1. R₀ = 0.1011 - 0.1101 = 1.1000 < 0 → q₁ = 0，恢复余数
2. R₀ + y = 0.1011 + 0.1101 = 1.0000 > 0
3. 左移，继续...

## 原码加减交替法（不恢复余数法）⭐推荐

### 改进思想

省去恢复余数的步骤，提高效率。

### 规则

| 余数符号 | 商位 | 下一步操作 |
|----------|------|------------|
| 余数为正 | 商1 | 余数左移减除数 |
| 余数为负 | 商0 | 余数左移加除数 |

> [!note] 核心思想
> 先减后判，如减后发现不够减，则在下一步改作加除数操作。

### 算法步骤

1. 符号位单独处理
2. 初始：被除数减除数
3. 余数为正 → 商1，余数左移后减除数
4. 余数为负 → 商0，余数左移后加除数
5. 重复n次得到n位商

### 例题2：不恢复余数除法完整步骤

**已知**：x = 0.101001，y = 0.111，求 x ÷ y

**解**：
- [x]补 = 0.101001
- [y]补 = 0.111
- [-y]补 = 1.001

**运算过程**：
```
        0.101001        ;被除数
+[-y]补 1.001           ;第一步减除数y
───────────────────────
        1.110001  <0  q4=0  ;余数为负，商0
        
+[y]补→ 0.0111           ;除数右移1位加（实际是余数左移后加y）
───────────────────────
        0.001101  >0  q3=1  ;余数为正，商1
        
+[-y]补→ 1.11001         ;除数右移2位减
───────────────────────
        1.111111  <0  q2=0  ;余数为负，商0
        
+[y]补→ 0.000111         ;除数右移3位加
───────────────────────
        0.000110  >0  q1=1  ;余数为正，商1
```

**结果**：
- 商 q = **0.101**
- 余数 r = **0.000110**

### 例题3：不恢复余数法详细步骤

**已知**：x = 0.1011，y = 0.1101，求 x ÷ y

**解**：
- |x| = 0.1011，|y| = 0.1101
- [-|y|]补 = 1.0011

**步骤**：
| 步骤 | 操作 | 余数R | 商位q |
|------|------|-------|-------|
| 1 | R₀ = x - y | 0.1011 + 1.0011 = 1.1001 < 0 | q₀ = 0 |
| | 恢复：R₀ + y | 1.1001 + 0.1101 = 0.1010 | |
| | 左移 | 1.0100 | |
| 2 | R₁ = R₀ - y | 1.0100 + 1.0011 = 0.0111 > 0 | q₁ = 1 |
| | 左移 | 0.1110 | |
| 3 | R₂ = R₁ - y | 0.1110 + 1.0011 = 0.0001 > 0 | q₂ = 1 |
| | 左移 | 0.0010 | |
| 4 | R₃ = R₂ - y | 0.0010 + 1.0011 = 1.0011 < 0 | q₃ = 0 |

**结果**：商 = 0.110，最后余数需恢复

## 补码除法

### 特点

- 符号位参与运算
- 商的符号自然形成
- 采用加减交替法

### 规则

| 余数与除数符号 | 商位 | 下一步操作 |
|----------------|------|------------|
| 同号 | 商1 | 余数左移减除数 |
| 异号 | 商0 | 余数左移加除数 |

### 注意事项

- 商的最后一位恒置1
- 不需要恢复余数

---

## 阵列除法器

### 组成

可控加法/减法（CAS）单元阵列

### CAS单元功能

| 控制信号P | 运算类型 |
|-----------|----------|
| P = 0 | 加法运算 |
| P = 1 | 减法运算 |

### 时间延迟

```
td = 3(n+1)²T
```

- 每个CAS单元延迟：3T
- 单元总数：(n+1)²

> [!note] 阵列除法器优势
> 相比串行除法器：
> - 无需复杂控制电路
> - 运算速度固定
> - 适合硬件实现

## 除法运算对比

| 方法 | 恢复余数 | 步骤数 | 效率 |
|------|----------|--------|------|
| 恢复余数法 | 需要 | 不固定 | 低 |
| 加减交替法 | 不需要 | 固定n步 | 高 |
| 补码除法 | 不需要 | 固定n步 | 高 |

## 考试真题精选

> [!faq] 用不恢复余数法计算x÷y，其中x=0.1011，y=0.1101。
> |x|=0.1011，|y|=0.1101，[-y]补=1.0011。步骤：①R₀=x=0.1011>0，商0，R₀左移得1.0110；②R₁=1.0110+[-y]补=1.0110+1.0011=0.1001>0，商1，左移得1.0010；③R₂=1.0010+1.0011=0.0101>0，商1，左移得0.1010；④R₃=0.1010+1.0011=1.1001<0，商0。商=0.110，余数=1.1001需恢复加y得0.0110。

> [!faq] 原码除法中，恢复余数法和加减交替法各有什么特点？
> 恢复余数法：每次不够减时需要加除数恢复余数，运算步骤不固定，效率较低。加减交替法（不恢复余数法）：余数为正时下一步减除数，余数为负时下一步加除数，省去恢复步骤，步骤固定为n步，效率更高。

> [!faq] 阵列除法器的CAS单元有什么功能？
> CAS（可控加法/减法）单元根据控制信号P选择运算类型：P=0做加法，P=1做减法。每个CAS单元延迟3T。阵列除法器由(n+1)²个CAS单元组成，总延迟td=3(n+1)²T，运算速度固定，适合硬件实现。
