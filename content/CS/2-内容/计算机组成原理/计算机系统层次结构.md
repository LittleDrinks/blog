# 计算机系统层次结构

计算机系统是一个十分复杂的**硬、软件结合而成的整体**。从不同角度观察，计算机呈现出不同的属性。对高层级用户来说，低层级是**透明的、不可见的**。

---

## 一、7级计算机层次系统（必背！）

| 层次 | 名称 | 执行方式 | 性质 | 观察者 |
|------|------|----------|------|--------|
| **M6** | 应用语言级 | 由应用程序支持和执行 | **软件层** | 最终用户 |
| **M5** | 高级语言级 | 由各种高级语言编译程序支持和执行 | **软件层** | 高级语言程序员 |
| **M4** | 汇编语言级 | 由汇编程序支持和执行 | **软件层** | 汇编语言程序员 |
| **M3** | 操作系统级 | 由操作系统程序实现（机器指令+广义指令） | **混合级** | 系统管理员 |
| **M2** | 一般机器级（机器语言级） | 由微程序解释机器指令系统 | **硬件层** | 机器语言程序员 |
| **M1** | 微程序设计级 | 由机器硬件直接执行微指令 | **硬件层** | 微程序设计员 |
| **M0** | 硬联逻辑级 | 直接实现微指令 | **硬件层** | 硬件设计人员 |

```
        ┌────────────────────────────────────┐
    M6  │        应用语言级                   │  ← 最终用户
        ├────────────────────────────────────┤
    M5  │        高级语言层                   │  ← 高级语言程序员
        ├────────────────────────────────────┤
    M4  │        汇编语言层                   │  ← 汇编程序员
        ├────────────────────────────────────┤
    M3  │        操作系统级（混合级）          │  ← 系统程序员
        ├────────────────────────────────────┤
    M2  │        机器语言级                   │  ← 机器语言程序员
        ├────────────────────────────────────┤
    M1  │        微程序设计级                 │  ← 微程序设计员
        ├────────────────────────────────────┤
    M0  │        硬联逻辑级                   │  ← 硬件工程师
        └────────────────────────────────────┘
              ▲ 越往下越接近物理实现
```

## 二、各层详细说明

### M6 应用语言级
- 面向用户，为满足特定应用而设置
- 例如：数据库查询语言、Excel公式、CAD命令等

### M5 高级语言级
- 面向用户，用接近人类语言的方式编写程序
- 由C/C++、Java、Python等高级语言编译程序支持和执行
- 可移植性好

### M4 汇编语言级
- 用符号形式表示机器指令、数据和地址
- 减少程序编写的复杂性
- 由汇编程序翻译为机器语言后执行

### M3 操作系统级（混合级）⭐
- 对具体程序、指令进行软硬件资源的调度
- 由**机器指令**和**广义指令**组成
- **广义指令**是操作系统定义和解释的软件指令
- 属于**混合级**（既有软件又有硬件支持）

### M2 一般机器级（机器语言级）
- 具体计算机的**指令系统（ISA）**
- 由微程序解释机器指令系统
- 是软硬件的**分界面**

### M1 微程序设计级
- 由机器硬件直接执行**微指令**
- 微程序控制器在此层工作
- 如果某应用程序直接用微指令编写，可在此层运行

### M0 硬联逻辑级
- 计算机的**数字逻辑电路**
- 实现运算功能、寄存器地址等最基本的硬件操作
- 由门电路、触发器等物理器件组成

## 三、层次与学科领域的对应

| 学科领域 | 对应层次 | 说明 |
|----------|----------|------|
| **计算机组成与实现** | M0、M1 | 关注硬件如何实现功能 |
| **计算机系统结构（体系结构）** | M2 | 关注指令系统、软硬件界面 |
| **系统软件** | M3、M4、M5 | 操作系统、编译器、汇编器 |
| **应用软件** | M6 | 面向最终用户的程序 |

> [!tip]
> **下级尽量对上级透明**。透明意味着：本来存在的事物或属性，从某种角度看似乎不存在。详见[[透明性]]。

## 四、虚拟机概念

> **虚拟机**：由软件实现的机器。

虚拟机的概念是理解计算机层次结构的关键：
- 站在使用者立场上观察，计算机系统可视作带上不同语言的**虚拟计算机**
- 不同观察者用不同语言（广义语言）来描述信息处理流程
- **广义语言**：用以描述控制流程的有一定规则的字符集合

### 虚拟机的工作原理

```
┌─────────────┐
│  广义语言   │ ← 观察者使用的语言
└──────┬──────┘
       │ 编译或解释器
       ▼
┌─────────────┐
│  虚拟计算机 │ ← 由软件实现的机器
└──────┬──────┘
       │ 控制信息 / 状态信息
       ▼
┌─────────────┐
│   作用对象  │ ← 实际硬件执行
└─────────────┘
```

> [!tip]
> 各种语言必须翻译或解释成机器指令才能执行。编译或解释程序是系统不可分割的一部分。

## 考试常考题型

> [!faq] 计算机系统的层次结构从下到上依次为？</br>A. 微程序级、机器语言级、操作系统级、汇编语言级、高级语言级、应用语言级</br>B. 高级语言级、汇编语言级、操作系统级、机器语言级、微程序级</br>C. 硬联逻辑级、微程序级、机器语言级、操作系统级、汇编语言级、高级语言级、应用语言级</br>D. 应用语言级、高级语言级、汇编语言级、操作系统级、机器语言级、微程序级、硬联逻辑级
> D。计算机系统层次从上到下（从用户到硬件）依次为：M6应用语言级→M5高级语言级→M4汇编语言级→M3操作系统级→M2机器语言级→M1微程序级→M0硬联逻辑级。C选项是从下到上的正确顺序。

> [!faq] 操作系统级（M3）为什么被称为"混合级"？
> 操作系统级由操作系统程序实现，这些操作系统由机器指令和广义指令组成。广义指令是操作系统定义和解释的软件指令，所以这一级既有硬件支持（机器指令）又有软件成分（广义指令），因此称为混合级。它介于纯硬件层（M0、M1、M2）和纯软件层（M4、M5、M6）之间。

> [!faq] 计算机层次结构中，软硬件分界面在哪一层？
> 软硬件分界面在M2机器语言级（一般机器级）。这一层是具体计算机的指令系统（ISA），由微程序解释机器指令系统。向上是软件层（操作系统、汇编、高级语言），向下是硬件层（微程序、硬联逻辑）。

> [!faq] M1微程序设计级和M0硬联逻辑级各有什么特点？
> M1微程序设计级由机器硬件直接执行微指令，微程序控制器在此层工作。如果某应用程序直接用微指令编写，可在此层运行。M0硬联逻辑级是计算机的数字逻辑电路，实现运算功能、寄存器地址等最基本的硬件操作，由门电路、触发器等物理器件组成，是最接近物理实现的层次。

> [!faq] 层次结构与学科领域如何对应？
> 计算机组成与实现对应M0、M1层，关注硬件如何实现功能；计算机系统结构（体系结构）对应M2层，关注指令系统、软硬件界面；系统软件对应M3、M4、M5层，包括操作系统、编译器、汇编器；应用软件对应M6层，面向最终用户的程序。

> [!faq] 什么是虚拟机？它在层次结构中的作用是什么？
> 虚拟机是由软件实现的机器。在层次结构中，站在使用者立场上观察，计算机系统可视作带上不同语言的虚拟计算机。不同观察者用不同语言（广义语言）来描述信息处理流程。各种语言必须翻译或解释成机器指令才能执行，编译或解释程序是系统不可分割的一部分。虚拟机概念是理解计算机层次结构的关键。
