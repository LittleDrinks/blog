# 定点乘法运算

> [!important] 本章考试权重
> 定点乘法运算约占5-10分，Booth算法是必考题型。要求能写出完整运算步骤。

## 原码一位乘法

### 算法步骤

1. 符号位单独处理（异或）
2. 绝对值相乘
3. 部分积和被乘数取双符号位

### 硬件实现

- 使用加法器和移位器
- 需要n次加法和n次移位（n位乘数）

### 例题1：原码一位乘法

**已知**：x = +15，y = -13，用原码乘法求 x·y

**解**：
- [x]原 = 01111，[y]原 = 11101
- |x| = 1111，|y| = 1101
- 符号位：0 ⊕ 1 = 1（结果为负）
- 绝对值相乘：
```
      1111   |x|
    × 1101   |y|
    ─────────
      1111    （乘数末位1）
     0000     （乘数第2位0，左移1位）
    1111      （乘数第3位1，左移2位）
   1111       （乘数第4位1，左移3位）
   ─────────
   11000011
```
- 乘积符号为1，[x×y]原 = **111000011**
- x·y = **-11000011** = -195

## 不带符号阵列乘法器

### 组成

- m×n个"与"门产生部分积
- 加法器阵列求和

### 时间延迟

```
tm = (8n - 4)T
```

### 例题2：不带符号阵列乘法

**已知**：A=11011，B=10101，用阵列乘法器求A×B

**解**：
```
      11011  = A (27)
    × 10101  = B (21)
    ─────────
      11011   a4b0...a0b0 = 1,1,0,1,1
     00000    a4b1...a0b1 = 0,0,0,0,0
    11011     a4b2...a0b2 = 1,1,0,1,1
   00000      a4b3...a0b3 = 0,0,0,0,0
+ 11011       a4b4...a0b4 = 1,1,0,1,1
─────────────
1000110111    = 567
```

验证：27 × 21 = 567 ✓

## 带符号阵列乘法器

### 组成

- 算前求补器
- 不带符号阵列乘法器
- 算后求补器

### 求补电路原理

- 从右向左扫描，找到第一个1
- 第一个1及右边各位保持不变
- 第一个1左边各位取反

**例**：
```
10110 → 从右扫描，第一个1在位置2
位置2及右边：10（保持）
位置2左边：101 → 取反得010
结果：01010
```

## 补码一位乘法（Booth算法）⭐必考

### 基本思想

通过判断相邻两位乘数的状态决定操作。

### 运算规则

| Yn | Yn+1 | 操作 |
|----|------|------|
| 0  | 0    | 部分积右移 |
| 0  | 1    | 部分积加[X]补，右移 |
| 1  | 0    | 部分积加[-X]补，右移 |
| 1  | 1    | 部分积右移 |

> [!tip] Booth算法速记
> 记住口诀："**01加被乘数，10加负被乘数，00/11只移位**"

### 算法步骤

1. 设置部分积初始值为0，乘数末位加附加位Yn+1 = 0
2. 从最低位开始，判断Yn和Yn+1两位
3. 根据规则执行操作
4. 右移一位（部分积和乘数一起右移）
5. 重复n次（n为数值位位数）

### Booth算法优点

- 符号位自然形成
- 不需要单独处理符号

> [!warning] Booth算法易错点
> 1. **附加位必须初始化为0**：乘数末位要加一位y₋₁=0
> 2. **判断方向是低位到高位**：每次看yn和yn-1，不是看相邻高位
> 3. **移位是算术右移**：负数补码右移要补符号位1
> 4. **部分积和乘数一起右移**：乘数最低位移入附加位位置

## Booth算法完整例题

### 例题3：Booth算法详细步骤

**已知**：x = -0.1101，y = +0.1011，用Booth算法求 x·y

**解**：
- [x]补 = **1.0011**（取双符号位11.0011）
- [-x]补 = **0.1101**（取双符号位00.1101）
- [y]补 = **0.1011**，附加位Yn+1 = 0
- 被乘数和乘数均取双符号位

**运算过程**：

| 步骤 | 部分积 | 乘数Y | Yn | Yn+1 | 判断 | 操作 |
|------|--------|-------|----|----|------|------|
| 初始 | 00.0000 | 1011**0** | - | - | - | - |
| 1 | 00.0000 | 10110 | 1 | 0 | 10 | 加[-x]补，右移 |
| | +00.1101 | | | | | |
| | =00.1101 | 10110 | | | | 右移得：00.0110 **1101** |
| 2 | 00.0110 | 1101**0** | 1 | 0 | 10 | 加[-x]补，右移 |
| | +00.1101 | | | | | |
| | =01.0011 | | | | | 右移得：00.1001 **1110** |
| 3 | 00.1001 | 1110**1** | 0 | 1 | 01 | 加[x]补，右移 |
| | +11.0011 | | | | | |
| | =11.1010 | | | | | 右移得：11.1101 **0111** |
| 4 | 11.1101 | 0111**1** | 1 | 1 | 11 | 右移 |
| | | | | | | 右移得：11.1110 **1011** |

**最终结果**：[x·y]补 = **11.11101011**

**验证**：
- 结果为负数，取反加1得真值：00.00010101
- x·y = **-0.00010101** = -(0.08203125)

### 例题4：正数乘负数

**已知**：x = +0.1101，y = -0.1011，用Booth算法求 x·y

**解**：
- [x]补 = 00.1101，[-x]补 = 11.0011
- [y]补 = 11.0101，附加位y₋₁ = 0

**判断序列**：
- ①y₁y₋₁ = 10 → 加[-x]补
- ②y₂y₁ = 01 → 加[x]补
- ③y₃y₂ = 10 → 加[-x]补
- ④y₄y₃ = 11 → 只移位

**结果**：[x×y]补 = **11.11010011**
- x×y = **-0.00101101**

### 例题5：负数乘负数

**已知**：x = -0.1011，y = -0.1101，用Booth算法求 x·y

**解**：
- [x]补 = 11.0101，[-x]补 = 00.1011
- [y]补 = 11.0011，附加位 = 0

**判断序列**：
- 10 → 加[-x]补
- 01 → 加[x]补
- 01 → 加[x]补
- 11 → 只移位

**结果**：[x×y]补 = **00.10001111**
- x×y = **+0.10001111**

> [!note] 分析
> 两负数相乘结果为正数，符号位自然形成。

## 考试真题精选

> [!faq] 用Booth算法计算x·y，其中x=+0.1101，y=-0.1011，写出详细计算过程。
> [x]补=00.1101，[-x]补=11.0011，[y]补=11.0101，附加位y₋₁=0。初始化部分积P=00.0000。步骤：①y₁y₋₁=10，加[-x]补：00.0000+11.0011=11.0011，右移得11.1001 1101；②y₂y₁=01，加[x]补：11.1001+00.1101=00.0101，右移得00.0010 1110；③y₃y₂=10，加[-x]补：00.0010+11.0011=11.0101，右移得11.1010 0111；④y₄y₃=11，只右移得11.1101 0011。最终结果[x·y]补=11.11010011，真值=-0.00101101。

> [!faq] 设x=-0.1011，y=-0.1101，用Booth算法求x·y。
> [x]补=11.0101，[-x]补=00.1011，[y]补=11.0011，附加位=0。判断序列：10加[-x]补→01加[x]补→01加[x]补→11只移位。计算过程略。最终结果：[x·y]补=00.10001111，x·y=+0.10001111。两负数相乘结果为正数。

> [!faq] 已知[x]补=0.1101，[y]补=1.0101，用Booth算法求x×y的详细步骤。
> [x]补=00.1101，[-x]补=11.0011，[y]补=11.0101，附加位=0。初始部分积P=00.0000。①y₁y₋₁=10，加[-x]补：P=11.0011，右移得11.1001|1010；②y₂y₁=01，加[x]补：P=00.0100，右移得00.0010|0101；③y₃y₂=10，加[-x]补：P=11.0101，右移得11.1010|1010；④y₄y₃=11，只右移得11.1101|0101。结果[x×y]补=11.11010101，x×y=-0.00101011。
