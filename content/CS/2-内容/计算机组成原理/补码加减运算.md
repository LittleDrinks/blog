# 补码加减运算

> [!important] 本章考试权重
> 补码加减运算约占5-10分，是计算题基础题型。常考内容包括：补码加减法计算、[-Y]补求解。

## 补码加减法基本公式

```
[X + Y]补 = [X]补 + [Y]补
[X - Y]补 = [X]补 + [-Y]补
```

### 运算特点

- 符号位参与运算
- 减法转换为加法实现
- 自然丢掉最高位的进位

> [!tip] 核心要点
> 补码加减运算使得运算器只需要一个加法器即可完成加减运算，不必再配一个减法器。

---

## 求[-Y]补的方法

### 方法

对[Y]补**连同符号位一起**取反，末位加1

> [!warning] 易错点
> 不是只对数值位取反加1，而是**连同符号位一起**取反加1！

### 例题1：求[-Y]补

**已知**：[Y]补 = 00110

**求**：[-Y]补

**解**：
- [Y]补 = 00110
- 连同符号位取反：11001
- 末位加1：11001 + 1 = **11010**
- [-Y]补 = **11010**

### 例题2：求[-X]补

**已知**：[x]补 = 00110

**求**：[-x]补

**解**：
- 对[x]补连同符号位一起取反加1：取反得11001，加1得11010
- [-x]补 = **11010**

> [!warning] 注意
> 必须连同符号位一起处理，不是只对数值位！

## 补码加法运算例题

### 例题3：正数加正数（无溢出）

**已知**：x = +1011，y = +0101，求 x + y

**解**：
- [x]补 = **010011**（取双符号位）
- [y]补 = **000101**
- 计算：
```
    010011   [x]补
  + 000101   [y]补
  ──────────
    010110   [x+y]补
```
- 双符号位为 **00**，无溢出
- x + y = **+1110**

### 例题4：正数加负数

**已知**：x = +1001，y = -0101，求 x + y

**解**：
- [x]补 = **01001**
- [y]补 = **11011**（负数补码）
- 计算：
```
    01001    [x]补
  + 11011    [y]补
  ──────────
   100110    [x+y]补（最高位进位抛弃）
```
- 抛弃最高位进位后得：**00110**
- x + y = **+0110** = +6

## 补码减法运算例题

### 例题5：补码减法运算

**已知**：x = +1101，y = +0110，求 x - y

**解**：
- [x]补 = **01101**
- [y]补 = **00110**
- [-y]补 = **11010**（对00110连同符号位取反加1）
- 计算：
```
    01101    [x]补
  + 11010    [-y]补
  ──────────
   100111    [x-y]补
```
- 抛弃最高进位后得：**00111**
- x - y = **+0111** = +7

### 例题6：负数减正数

**已知**：x = -1100，y = +0100，求 x - y

**解**：
- [x]补 = **10100**（-12的补码）
- [y]补 = **00100**
- [-y]补 = **11100**（对00100连同符号位取反加1）
- 计算：
```
    10100    [x]补
  + 11100    [-y]补
  ──────────
   110100    [x-y]补
```
- 抛弃最高进位得：**10100**
- x - y = **-11000** = -16

## 双符号位运算

### 变形补码（双符号位）

- 正数：**00**.xxxx...
- 负数：**11**.xxxx...

**用途**：便于溢出判断

### 例题7：双符号位加法

**已知**：x = -0.1011，y = -0.0101，求 x + y

**解**：
- [x]补 = **11.0101**（双符号位）
- [y]补 = **11.1011**
- 计算：
```
    11.0101   [x]补
  + 11.1011   [y]补
  ───────────
   110.1000   [x+y]补
```
- 结果为 **10.1000**，双符号位10表示负溢出

## 考试真题精选

> [!faq] 已知[x]补=00110，求[-x]补。
> 对[x]补连同符号位一起取反加1：取反得11001，加1得11010。[-x]补=11010。注意：不是只对数值位取反，必须连同符号位一起处理！

> [!faq] 设字长5位（含符号位），x=+1101，y=+1001，用双符号位法求x+y并判断是否溢出。
> [x]补=001101，[y]补=001001。计算：001101+001001=010110。双符号位为01，发生正溢。正确答案：正溢出，结果超出5位补码表示范围-16~+15。

> [!faq] 用双符号位补码计算x+y并判断溢出，其中x=-1100，y=-1000。
> [x]补=110100，[y]补=111000。计算：110100+111000=101100。双符号位为10，发生负溢出。
