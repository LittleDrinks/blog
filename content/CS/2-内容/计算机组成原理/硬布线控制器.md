# 硬布线控制器

## 基本概念

**硬布线控制（Hardwired Control）**：通过**组合逻辑电路（门电路）直接连线**而产生的控制方式，又称为**组合逻辑控制方式**。

### 核心思想

根据以下三个输入，通过组合逻辑电路**直接产生**微操作控制信号：
1. **指令操作码译码输出**
2. **时序信号（节拍电位、节拍脉冲）**
3. **状态条件信号**

不需要像微程序控制器那样去访问控制存储器取微指令！

### 设计目标
- 使用最少元件（复杂的树形网络）
- **速度最高**

## 硬布线控制器的组成

```
┌──────────────────────────────────────────────────────────────┐
│                      硬布线控制器                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐                   │

│       │             │             │                         │

│            ┌────────────────┐                               │
│            │   组合逻辑网络  │                               │

```

### 各部件功能

| 部件 | 功能 |
|------|------|
| **指令译码器（ID）** | 对指令操作码译码，输出表示不同指令的信号 |
| **节拍发生器** | 产生时序信号，区分指令执行的不同阶段 |
| **状态条件寄存器** | 提供状态条件（进位、零标志、溢出等）用于条件判断 |
| **组合逻辑网络** | 由门电路构成，根据输入信号产生控制信号 |

## 控制信号的产生

每个微操作控制信号都可以用**布尔代数表达式**描述：

```
C = Σ (指令信号 · 时序信号 · 状态条件)
```

### 典型逻辑表达式示例

```
RD(I)   = M1                       ; 取指周期读指令存储器（电位信号）
RD(D)   = M3 · LAD                 ; 执行LAD时读数据存储器（电位信号）
WE(D)   = M3 · T3 · LDA            ; 写数据存储器（脉冲信号）
LDPC    = M1·T4 + M2·T4·JMP        ; 打入PC（取指结束时或JMP执行时）
LDIR    = M1·T4                    ; 取指结束时将指令打入IR
LDAR    = M2·T4·(LAD + STO)        ; LAD和STO指令在执行周期将地址打入AR
LDDR    = M2·T3·(MOV+ADD) + M3·T3·LDA  ; 将数据打入DR
PC+1    = M1                       ; 取指周期PC自动加1
LDR2    = M2·T4·ADD                ; ADD执行时将结果打入R2
```

> [!tip]
> 上述表达式中：`M1, M2, M3` 为节拍电位信号；`T1, T2, T3, T4` 为节拍脉冲信号；`MOV, LAD, ADD, STO, JMP` 为指令译码输出信号。

## 硬布线控制器的设计步骤

1. **分析指令系统**：列出所有指令，分析每条指令的执行过程
2. **确定控制信号**：列出所有微操作控制信号
3. **写出逻辑表达式**：对每个控制信号写出布尔表达式并化简
4. **绘制逻辑电路**：用门电路或可编程器件实现

## 硬布线控制的优缺点

### 优点
1. **速度快**：不需要取微指令，控制信号直接由门电路产生
2. **成本低**：不需要控制存储器
3. **效率高**：适合高速处理器

### 缺点
1. **设计复杂**：指令系统复杂时，逻辑电路变得非常复杂
2. **难以修改**：改变指令功能需要重新设计硬件
3. **规整性差**：控制逻辑分散，不规整
4. **调试困难**：错误定位和修改困难

> [!warning]
> 硬布线控制器**速度快但设计复杂**；微程序控制器**规整易改但速度较慢**。考试简答题和选择题高频考点！

## 硬布线 vs 微程序控制对比表（考试必背！）

| 特性 | 硬布线控制器 | 微程序控制器 |
|------|-------------|-------------|
| **实现方式** | 组合逻辑电路（门电路） | 存储程序（控制存储器） |
| **执行速度** | **快**（直接产生） | 较慢（需访问控存） |
| **设计难度** | 难（逻辑复杂） | 较易（编程方式） |
| **可修改性** | 差（需改硬件） | **好**（改控存内容） |
| **规整性** | 差（分散不规整） | **好**（结构规整） |
| **硬件成本** | 较低 | 较高（需控存） |
| **调试难度** | 难 | 易 |
| **适用场景** | **RISC、高速CPU** | **CISC、复杂指令** |
| **时序体制** | **三级体制**（主状态周期-节拍-节拍脉冲） | **二级体制**（节拍电位-节拍脉冲） |
| **指令扩展** | 困难（需重新设计） | **容易**（增加微程序） |
| **代表机型** | ARM、MIPS、RISC-V | IBM 360/370、x86复杂指令 |

> [!warning]
> **简答题高频考点**：请比较硬布线控制器和微程序控制器的优缺点。
> 
> **标准答案要点**：
> - **硬布线优点**：速度快、成本低、效率高
> - **硬布线缺点**：设计复杂、难以修改、规整性差、调试困难
> - **微程序优点**：规整性好、易于修改扩展、调试方便
> - **微程序缺点**：速度慢（需访问控存）、硬件成本高

## 控制信号逻辑表达式例题（必考！）

> [!warning]
> 控制信号的逻辑表达式是**综合题高频考点**，需要能够根据指令流程写出表达式！

### 例题：写出控制信号的逻辑表达式

**题目**：根据指令流程图，写出以下操作控制信号的逻辑表达式：
- RD(I)：指存读命令
- RD(D)：数存读命令
- WE(D)：数存写命令
- LDPC：打入程序计数器
- LDIR：打入指令寄存器
- LDAR：打入数存地址寄存器
- LDDR：打入数据缓冲寄存器
- PC+1：程序计数器加1
- LDR2：打入R2寄存器

**解答**：

设M1、M2、M3为节拍电位信号，T1、T2、T3、T4为一个CPU周期中的节拍脉冲信号，MOV、LAD、ADD、STO、JMP分别表示对应机器指令的OP操作码译码输出信号。

| 控制信号 | 逻辑表达式 | 说明 |
|----------|-----------|------|
| **RD(I)** | `M1` | 取指周期读指令存储器（电位信号） |
| **RD(D)** | `M3·LAD` | 执行LAD时读数据存储器（电位信号） |
| **WE(D)** | `M3·T3·STO` | 写数据存储器（脉冲信号） |
| **LDPC** | `M1·T4 + M2·T4·JMP` | 取指结束时或JMP执行时打入PC |
| **LDIR** | `M1·T4` | 取指结束时将指令打入IR |
| **LDAR** | `M2·T4·(LAD + STO)` | LAD和STO指令将地址打入AR |
| **LDDR** | `M2·T3·(MOV+ADD) + M3·T3·LAD` | 将数据打入DR |
| **PC+1** | `M1` | 取指周期PC自动加1 |
| **LDR2** | `M2·T4·ADD` | ADD执行时将结果打入R2 |

> [!tip]
> **关键理解**：
> - **电位信号**（如RD）：持续整个周期，用节拍电位（M1、M2）表示
> - **脉冲信号**（如WE、LD）：瞬时触发，需加上节拍脉冲（T3、T4）
> - **指令信号**（如MOV、ADD）：来自指令译码器输出
> - **"+"表示或**：不同情况都需要触发该信号
> - **"·表示与**：多个条件同时满足才触发

## 现代应用

- **RISC 处理器**：指令简单，控制逻辑相对简单，普遍采用硬布线控制
- **CISC 处理器**（如 Intel x86）：内部复杂指令采用微程序控制，简单指令可能直接硬布线实现

## 本章考试常见题型

### 一、选择题

> [!faq] 硬布线控制器的基本思想是什么？</br>A. 存储程序控制</br>B. 组合逻辑电路直接产生控制信号</br>C. 微指令序列控制</br>D. 时序逻辑控制
> B。硬布线控制器的基本思想是通过**组合逻辑电路（门电路）直接连线产生控制信号**，又称为组合逻辑控制方式。不需要像微程序那样访问控存取微指令。

> [!faq] 硬布线控制器采用什么时序体制？</br>A. 一级体制</br>B. 二级体制</br>C. 三级体制</br>D. 四级体制
> C。硬布线控制器采用**三级时序体制**（主状态周期-节拍电位-节拍脉冲）。微程序控制器采用二级体制。这是两种控制器的重要区别点。

> [!faq] 硬布线控制器的主要优点是什么？</br>A. 易于修改</br>B. 规整性好</br>C. 速度快</br>D. 设计简单
> C。硬布线控制器的主要优点是**速度快**，因为控制信号直接由门电路产生，不需要取微指令的时间。缺点是设计复杂、难以修改、规整性差。

> [!faq] 某控制信号的逻辑表达式为"C=M1·T4+M2·T4·JMP"，这说明什么？</br>A. 该信号只在M1周期有效</br>B. 该信号在M1或JMP指令的M2周期T4时刻有效</br>C. 该信号是电位信号</br>D. 该信号只在JMP指令时有效
> B。表达式含义：该控制信号在**M1周期的T4时刻**有效（取指结束时），或者在**JMP指令执行时M2周期的T4时刻**有效（转移指令打入PC）。"+"表示或，"·"表示与。

> [!faq] 硬布线控制器最适合用于哪种类型的CPU？</br>A. CISC复杂指令系统</br>B. RISC精简指令系统</br>C. 微程序控制器</br>D. 任何类型CPU
> B。硬布线控制器最适合**RISC精简指令系统**的CPU，因为指令简单，控制逻辑相对简单，硬布线实现效率高。CISC复杂指令系统更适合微程序控制器。

> [!faq] 在硬布线控制器中，控制信号C是哪些因素的逻辑函数？</br>A. 操作码译码输出</br>B. 时序信号</br>C. 状态条件信号</br>D. 以上三者
> D。控制信号C是**指令操作码译码输出、时序信号（节拍电位和节拍脉冲）、状态条件信号**三者的逻辑函数：C = f(Im, Mi, Tk, Bj)。

### 二、简答题

> [!faq] 比较硬布线控制器和微程序控制器的优缺点。
> 硬布线优点：速度快、成本低、效率高。硬布线缺点：设计复杂、难以修改、规整性差、调试困难。微程序优点：规整性好、易于修改扩展、调试方便。微程序缺点：速度慢（需访问控存）、硬件成本高。硬布线适合RISC，微程序适合CISC。

> [!faq] 简述硬布线控制器的设计步骤。
> 硬布线控制器设计步骤：(1)**分析指令系统**：列出所有指令，分析每条指令的执行过程；(2)**确定控制信号**：列出所有微操作控制信号；(3)**写出逻辑表达式**：对每个控制信号写出布尔表达式并化简；(4)**绘制逻辑电路**：用门电路或可编程器件实现。

> [!faq] 什么是电位信号和脉冲信号？在控制信号表达式中如何区分？
> **电位信号**：持续整个周期的控制信号，如RD、WE等读写命令。在表达式中只含节拍电位（M1、M2），不含节拍脉冲。**脉冲信号**：瞬时触发的控制信号，如LD、打入命令等。在表达式中必须包含节拍脉冲（T3、T4），表示在特定时刻触发。

> [!faq] 为什么硬布线控制器在现代RISC处理器中得到重视？
> 原因：(1)RISC指令系统简单，控制逻辑相对简单，硬布线实现可行；(2)VLSI技术发展，复杂逻辑电路实现成本降低；(3)对机器速度要求提高，硬布线速度快；（4）硬布线更适合高频指令的优化实现。虽然微程序规整，但速度瓶颈促使硬布线重新受到重视。

### 三、综合题

> [!faq] 根据指令流程图，写出以下控制信号的逻辑表达式：RD(I)指存读命令；RD(D)数存读命令；WE(D)数存写命令；LDPC打入PC；LDIR打入IR。设M1、M2、M3为节拍电位，T1-T4为节拍脉冲，MOV、LAD、ADD、STO、JMP为指令译码输出。
> 根据指令流程分析：(1)RD(I)=M1（电位信号，取指周期读指存）；(2)RD(D)=M3·LAD（电位信号，LAD指令M3周期读数存）；(3)WE(D)=M3·T3·STO（脉冲信号，STO指令M3周期T3时刻写数存）；(4)LDPC=M1·T4+M2·T4·JMP（脉冲信号，取指结束或JMP转移时打入PC）；(5)LDIR=M1·T4（脉冲信号，取指结束时打入IR）。

> [!faq] 设计硬布线控制器的控制信号C3，该信号控制主存读操作。已知：取指周期M1需要读主存；执行周期M4中，LAD、ADD、AND指令需要读操作数。写出C3的逻辑表达式。
> 控制信号C3控制主存读操作。分析条件：(1)取指周期M1=1时，读指令需要激活C3；(2)执行周期M4=1时，LAD、ADD、AND指令读操作数需要激活C3。表达式：C3=M1+M4·(LAD+ADD+AND)。注意这是电位信号，持续整个周期有效。
