通过组合逻辑电路（门电路）直接连线产生控制信号，又称组合逻辑控制方式

三个输入：指令操作码译码输出 + 时序信号（节拍电位/节拍脉冲）+ 状态条件信号
控制信号 = f(指令译码, 时序, 状态条件)，即 C = Σ(指令信号·时序信号·状态条件)

逻辑表达式示例：
- RD(I) = M1（取指周期读指存，电位信号）
- WE(D) = M3·T3·STO（写数存，脉冲信号需加T3）
- LDPC = M1·T4 + M2·T4·JMP（取指结束或JMP时打入PC）
- 电位信号只含节拍电位M，脉冲信号必须含节拍脉冲T

设计步骤：分析指令系统 → 列出控制信号 → 写布尔表达式并化简 → 用门电路实现

| | 硬布线 | 微程序 |
|---|--------|--------|
| 实现方式 | 组合逻辑电路 | 存储程序（控存） |
| 速度 | 快（直接产生） | 慢（需访问控存） |
| 可修改性 | 差（改硬件） | 好（改控存） |
| 规整性 | 差 | 好 |
| 适用 | RISC | CISC |
| 时序体制 | 三级 | 二级 |

> [!faq] 硬布线控制器的主要优点？速度快，控制信号直接由门电路产生

> [!faq] 电位信号和脉冲信号的区别？电位信号持续整个周期（只含M），脉冲信号瞬时触发（必须含T）
