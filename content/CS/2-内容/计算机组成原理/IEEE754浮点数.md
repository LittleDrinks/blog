# IEEE 754浮点数

> [!important] 本章考试权重
> IEEE 754浮点数转换是必考大题，约占10-15分。常考题型包括：十进制转IEEE 754、IEEE 754转十进制、特殊值判断。

## IEEE 754标准格式

```
┌─────┬─────────────┬─────────────────────────────┐
│ 符号 │    阶码      │            尾数             │
│  1位 │   8位(单)    │         23位(单)            │
│      │  11位(双)    │         52位(双)            │
└─────┴─────────────┴─────────────────────────────┘
```

### 单精度浮点数（32位）

- 符号位（S）：1位
- 阶码（E）：8位（移码表示，偏移127）
- 尾数（M）：23位（隐含最高位1）

**规格化数真值公式**：
```
x = (-1)^S × (1.M) × 2^(E-127)
```

### 双精度浮点数（64位）

- 符号位（S）：1位
- 阶码（E）：11位（移码表示，偏移1023）
- 尾数（M）：52位

**规格化数真值公式**：
```
x = (-1)^S × (1.M) × 2^(E-1023)
```

> [!warning] 隐藏位（必考点）
> 规格化尾数的最高位**一定是1**，这个1不存储在23位M中，是**隐藏的**！
> 所以真正的尾数是 **1.M**，不是 0.M！

## 浮点数规格化

### 规格化形式

- **规格化形式**：尾数最高位为1
- **非规格化形式**：用于表示接近0的数
- **特殊值**：0、无穷大、NaN（非数）

### IEEE 754各类型详解

| 类型 | 阶码 | 尾数 | 含义 |
|------|------|------|------|
| 零 | 全0 | 全0 | ±0 |
| 非规格化数 | 全0 | 非0 | 接近0的数 |
| 规格化数 | 非全0非全1 | 任意 | 正常数值 |
| 无穷大 | 全1 | 全0 | ±∞ |
| NaN | 全1 | 非0 | 非数 |

**规格化数详解**：
- 阶码E范围：1 ~ 254
- 真值指数：e = E - 127（单精度）或 e = E - 1023（双精度）
- 尾数真值：1.M（隐藏位为1）

**非规格化数（阶码全0）详解**：
- 用于表示接近0的数
- 尾数真值：0.M（隐藏位为0）
- 指数：固定为-126（单精度）或-1022（双精度）
- 填补了0和最小规格化数之间的"缺口"

**零（阶码全0，尾数全0）**：
- 有+0和-0之分（符号位不同）
- 某些运算会产生-0，如-1×0

**无穷大（阶码全1，尾数全0）**：
- 有+∞和-∞之分
- 当运算结果超过最大规格化数时产生

**NaN（阶码全1，尾数非0）**：
- 非数值（Not a Number）
- 如0/0、∞-∞、∞×0等运算产生

> [!warning] 偏移量易错点
> IEEE 754中阶码偏移量：**8位偏移127，11位偏移1023**。不要记成128！
> 全0和全1被保留用于特殊值，规格化数阶码范围1~254，真值范围-126~+127。

## 十进制转IEEE 754完整步骤

### 步骤

1. 确定符号位 S（正数为0，负数为1）
2. 将十进制数的整数部分和小数部分分别转二进制
3. 写成规格化形式：1.xxxx × 2^e
4. 阶码 E = e + 127（单精度）
5. 尾数 M = xxx...（去掉前面的1，凑够23位，不足补0）
6. 组合成 1 + 8 + 23 = 32 位

### 例题1：十进制转IEEE 754

**已知**：X = (20.59375)₁₀

**求**：IEEE 754单精度浮点数的二进制存储格式（用十六进制表示）

**解**：

**第一步：分别转换整数和小数部分**
- 整数部分 20 = 10100
- 小数部分 0.59375：
  - 0.59375 × 2 = 1.1875 → 1
  - 0.1875 × 2 = 0.375 → 0
  - 0.375 × 2 = 0.75 → 0
  - 0.75 × 2 = 1.5 → 1
  - 0.5 × 2 = 1.0 → 1
- 所以 0.59375 = 0.10011
- 合并：20.59375 = **10100.10011**

**第二步：规格化**
- 10100.10011 = **1.010010011** × 2⁴
- 指数真值 e = 4

**第三步：求各部分**
- S = 0（正数）
- E = 4 + 127 = 131 = **10000011**
- M = **010010011**00000000000000（去掉1.，后面补0到23位）

**第四步：组合**
```
0 10000011 01001001100000000000000
```

分组为十六进制：`0100 0001 1010 0100 1100 0000 0000 0000` = **(41A4C000)₁₆**

### 例题2：分数转IEEE 754

**已知**：将十进制数(27/64)₁₀转换为IEEE 754单精度浮点数

**解**：
- 27/64 = 0.421875 = 0.011011₂ = 1.1011 × 2^-2
- S = 0
- E = -2 + 127 = 125 = 01111101
- M = 10110000000000000000000（去掉隐藏位1.）
- 组合：00111110110110000000000000000000 = **(3EDC0000)₁₆**

### 例题3：负数转IEEE 754

**已知**：将十进制数-27/64转换为IEEE 754单精度浮点数

**解**：
- -27/64 = -0.421875 = -0.011011₂ = -1.1011 × 2^-2
- S = 1
- E = -2 + 127 = 125 = 01111101
- M = 10110000000000000000000
- 组合：10111110110110000000000000000000 = **(BEDC0000)₁₆**

## IEEE 754转十进制完整步骤

### 步骤

1. 十六进制转二进制，按1+8+23分割
2. 提取符号位S、阶码E、尾数M
3. 求指数真值 e = E - 127
4. 求尾数真值（加上隐藏位1）：1.M
5. 计算真值：(-1)^S × 1.M × 2^e
6. 二进制转十进制

### 例题4：IEEE 754转十进制

**已知**：浮点数x的754标准存储格式为 **(41360000)₁₆**

**求**：其十进制数值

**解**：

**第一步：十六进制转二进制**
```
41360000 = 0100 0001 0011 0110 0000 0000 0000 0000
```
按 1+8+23 分割：
- S = **0**
- E = **10000010**
- M = **01101100000000000000000**

**第二步：求指数真值 e**
- E = 10000010₂ = 130₁₀
- e = E - 127 = 130 - 127 = **3**

**第三步：求尾数（别忘了隐藏位1）**
- 1.M = **1.011011**

**第四步：计算真值**
```
x = (-1)^0 × 1.011011 × 2³
  = 1.011011 × 2³
  = 1011.011
```

**第五步：二进制转十进制**
- 整数部分 1011₂ = 11₁₀
- 小数部分 0.011₂ = 0×2⁻¹ + 1×2⁻² + 1×2⁻³ = 0 + 0.25 + 0.125 = **0.375**
- 结果：x = **11.375**

> [!warning] 隐藏位是必考点
> 很多同学算尾数时忘了加隐藏的1，直接用0.M计算，导致结果错误。记住：**规格化数一定是 1.M**。

### 例题5：特殊值识别

**已知**：浮点数格式为 **(FF800000)₁₆**

**求**：其表示的数值

**解**：
- 二进制：1111 1111 1000 0000 0000 0000 0000 0000
- S = 1，E = 11111111（全1），M = 000...0（全0）
- 阶码全1且尾数全0 → **负无穷大 -∞**

## 浮点数表示范围

### 非IEEE 754浮点数范围计算

**已知**：由S、E、M三个域组成的32位浮点数，真值表示为：
```
x = (-1)^S × (1.M) × 2^(E-128)
```
（注意：此例非IEEE 754标准，偏移量128）

**求**：规格化的最大正数、最小正数、最大负数、最小负数

**解**：
- E为8位移码，范围：00000000 ~ 11111111（真值：-128 ~ +127）

**(1) 最大正数**
```
S=0, E=11111111(255), M=全1
x = [1 + (1 - 2^-23)] × 2^127
```

**(2) 最小正数**
```
S=0, E=00000000(0), M=全0
x = 1.0 × 2^-128
```

**(3) 最小负数**
```
S=1, E=11111111, M=全1
x = -[1 + (1 - 2^-23)] × 2^127
```

**(4) 最大负数**
```
S=1, E=00000000, M=全0
x = -1.0 × 2^-128
```

## 考试真题精选

> [!faq] IEEE 754单精度浮点数中，为什么偏移量选127而不是128？
> 8位阶码可表示256个编码，除去全0（表示0或非规格化数）和全1（表示无穷大或NaN）后剩254个。若偏移量选128，则真值范围为-128~+127，不对称；选127则真值范围为-126~+127，更均衡。同时，全0和全1被保留用于特殊值，规格化数阶码范围1~254，真值范围-126~+127。

> [!faq] 若浮点数x的IEEE 754存储格式为(40490FDB)₁₆，求其十进制数值。
> 二进制展开：0100 0000 0100 1001 0000 1111 1101 1011。S=0，E=10000000=128，e=128-127=1，1.M=1.10010010000111111011011。x=(-1)⁰×1.10010010000111111011011×2¹=11.0010010000111111011011≈3.14159（近似π）

> [!faq] IEEE 754单精度浮点数的规格化数，其阶码E的范围和对应的真值指数e的范围分别是什么？
> 阶码E范围：1~254（全0和全1保留给特殊值）。真值指数e范围：e=E-127，故为-126~+127。
