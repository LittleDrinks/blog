## 主要组成部件

### 算术逻辑单元（ALU）
- **功能**：执行所有算术和逻辑运算
- **核心**：加法器、逻辑运算单元、移位器
- **控制**：由操作码选择具体运算

### 寄存器组
- **通用寄存器**：R0～Rn，用于暂存操作数和中间结果
- **累加器（ACC）**：存放运算结果
- **暂存器（TMP）**：暂存操作数
- **乘商寄存器（MQ）**：乘除运算专用

### 标志寄存器（PSW/FR）

| 标志位 | 名称 | 含义 |
|--------|------|------|
| CF | 进位标志 | 无符号数运算的进位/借位 |
| OF | 溢出标志 | 有符号数运算溢出 |
| SF | 符号标志 | 运算结果的符号 |
| ZF | 零标志 | 运算结果为零 |
| PF | 奇偶标志 | 结果低8位中1的个数为偶数 |
| AF | 辅助进位 | BCD运算的半字节进位 |

### 移位器

- **逻辑移位**：空位补0
- **算术移位**：符号位不变，空位补符号位
- **循环移位**：移出的位从另一端移入

## 运算器的内部总线

### 单总线结构

```
R0 ──┐
R1 ──┤
R2 ──┼──→ 总线 ──→ ALU ──→ R0/ACC
... ─┤
TMP ─┘

特点：结构简单，但一个时钟周期只能传送一个数据
```

### 双总线结构

```
R0 ──┐        ┌──→ ALU ──→ R0/ACC
R1 ──┼──→ 总线A │
R2 ──┤        │
TMP ─┘        └──→ 总线B

特点：可同时传送两个操作数到ALU
```

### 三总线结构

```
R0 ──→ 总线A ──→┐
R1 ──→ 总线B ──→┼──→ ALU ──→ 总线C ──→ R0/ACC
TMP ──→ 总线B ──┘

特点：可同时传送两个操作数并输出结果，性能最高
```

## 总线结构对比 ⭐考点

| 结构 | 传送能力 | 执行速度 | 硬件成本 |
|------|----------|----------|----------|
| 单总线 | 一次传一个数 | 慢（需多次传送） | 低 |
| 双总线 | 一次传两个数 | 中等 | 中 |
| 三总线 | 一次传两数并输出结果 | 快 | 高 |

> [!warning] 单总线运算特点
> 单总线结构执行一次加法需要3个时钟周期：
> 1. R0 → TMP（暂存）
> 2. R1 → ALU，TMP → ALU
> 3. ALU结果 → R0

## 逻辑运算详解

| 运算 | 符号 | 规则 |
|------|------|------|
| 逻辑非 | NOT / ¬ | 每位取反 |
| 逻辑加 | OR / + | 有1则1 |
| 逻辑乘 | AND / · | 有0则0 |
| 逻辑异 | XOR / ⊕ | 相异为1 |

### 例题：逻辑运算

**已知**：x = 10101011，y = 11001100

```
NOT x = 01010100
x OR y = 11101111
x AND y = 10001001
x XOR y = 01100111
```

## 考试真题精选

> [!faq] 单总线结构的运算器执行一次加法运算需要几个时钟周期？为什么？
> 需要3个时钟周期。①第一个周期：将第一个操作数从寄存器送到ALU输入端的暂存器；②第二个周期：将第二个操作数送ALU，同时执行加法；③第三个周期：将结果送回目标寄存器。因为单总线同一时刻只能传送一个数据，两个操作数无法同时到达ALU。

> [!faq] 标志寄存器中CF和OF的区别是什么？
> CF（进位标志）：表示无符号数运算的最高位进位/借位，用于判断无符号数溢出。OF（溢出标志）：表示有符号数运算的溢出（结果超出有符号数表示范围），可通过V=Cf⊕C0判断。同一个运算结果，CF和OF可能不同。
