解决 CPU 和主存之间速度不匹配的问题
![[Pasted image 20260630160447.png]]
一般由 [[SRAM]] 构成（作为对比，主存用 [[DRAM]]）

# 性能评价

命中率：cache 存取次数占总存取次数的比例，即 $h=\frac{N_e}{N_e+N_m}$
平均访问时间：cache 存取周期和主存存取周期按 $h$ 加权平均，即 $t_a=ht_c+(1-h)t_m$
Cache 访问效率：全命中的访问时间在实际时间中的占比，即 $e=\frac{t_c}{t_a}$

> [!faq]- CPU 执行一段程序时，cache 完成存取的次数为 960 次，主存完成存取的次数为 40 次，已知 cache 存取周期为 30 ns，主存存取周期为 150 ns，求</br>（1）cache/主存系统的命中率</br>（2）平均访问时间</br>（3）Cache 访问效率。 
> 命中率 $h=\frac{960}{960+40}=0.96$
> 平均访问时间 $t_a=0.96\times30+0.04\times150=34.8\pu{ns}$
> cache 访问效率 $e=\frac{30}{34.8}\approx0.86$

# 地址映射

cache 数据块大小称为**行**，主存数据块大小称为**块**，一块包含若干**字**
主存的某一块可以映射到 cache 中的的一**组**数据块，组内任意放置
cache 一行可能对应主存中多个块，用**标记**唯一标识
**主存地址**可以对应表示为：【块号】+【块内偏移（字）】，按照 cache 映射方式可以进一步对【块号】做切分

| 映射方式     | 主存块号被切成      | 地址格式                          | 定位规则                  |
| :------- | :----------- | :---------------------------- | :-------------------- |
| **全相联**  | **Tag（全部）**  | `Tag \| Offset`               | 主存块可放 Cache **任意行**   |
| **直接相联** | **Tag + 行号** | `Tag \| Line Index \| Offset` | 主存块只能放 Cache **特定一行** |
| **组相联**  | **Tag + 组号** | `Tag \| Set Index \| Offset`  | 主存块可放 **特定组内的任意行**    |

> [!faq]- 一个组相联 cache 由 64 个行组成，每组 4 行。主存包含  8 K 个块，每块 256 字。请表示内存地址的格式。
> $8\pu{K}=2^{13}$，$256=2^8$，于是**块号长度**和**块内偏移**分别为 $13,8$
> 
> 组相联 cache 分为 $64 / 4=2^4$ 组，于是块号长度可以进一步分为【低 $4$ 位的**组索引**】+【高 $13-4=9$ 位的**标记**】
> 
> 最终答案为：
> 
> ```
> 主存块号（13位）          块内偏移（8位）
> ├─────────────┬──────────┤───────────────|
> │  Tag (9位)  │ Set(4位) │  Offset (8位) |
> └─────────────┴──────────┴───────────────|
> ```

> [!faq]- 某计算机 cache 共 $16$ 行，2 路组相联映射，每块 $32$ 字节，按字节编址。主存 $135$ 号单元所在块应装入的 cache 组号是？
> 2 路组相联说明分为 $16 / 2 = 8$ 组，每块 32 字节说明 $135$ 号单元的块号是 $\lfloor 135 / 32 \rfloor = 4$，于是对应的组号为 $4\bmod 8=4$

# 替换策略

- 随机替换
- LFU：Least Frequently Used，最不经常使用
- LRU：Least Recently Used，最后一次使用时间最久远

# 写一致性

- 写回法：不到万不得已，绝不写主存，快但存在丢失风险
  ![[Pasted image 20260630170322.png]]
- 全写法：只要改Cache，就同时改主存，性能开销大但主存数据永远最新，利于多核共享
  ![[Pasted image 20260630170356.png]]
- 写一次法：第一次写入必须同时修改主存和 cache，目的是让其他处理器看到这次修改，将自己手上的副本置为无效
  ![[Pasted image 20260630170408.png]]
