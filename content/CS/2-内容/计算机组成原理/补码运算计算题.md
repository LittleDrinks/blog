# 补码运算计算题

## 核心知识

**补码运算规则：**
- [X]补 + [Y]补 = [X+Y]补 (mod 2ⁿ)
- 符号位参与运算

**溢出判断：**
- 双符号位法：01正溢出，10负溢出
- 进位判断：Cₙ ⊕ Cₙ₋₁ = 1 则溢出

---

### 例题1：补码加法

**题目：**
> 设X=+0.1011，Y=+0.1100，用双符号位补码计算X+Y，判断是否溢出。

**解答：**
```
[X]补 = 00.1011
[Y]补 = 00.1100

  00.1011
+ 00.1100
---------
  01.0111

结果符号位为01 → 正溢出
```

---

### 例题2：补码减法

**题目：**
> 设X=-0.1011，Y=+0.1100，用双符号位补码计算X-Y。

**解答：**
```
[X]补 = 11.0101
[-Y]补 = 11.0100 (对[Y]补求补)

  11.0101
+ 11.0100
---------
 110.1001 (舍去最高位)
  10.1001

结果符号位为10 → 负溢出
```

---

### 例题3：补码减法 + 进位判断法

**题目：**
> 设X=+0.1011，Y=-0.0110，用单符号位补码计算X-Y，并用进位判断法判断是否溢出。

**解答：**
```
[X]补 = 0.1011
[Y]补 = 1.1010
[-Y]补 = 0.0110 (对[Y]补连同符号位求补)

计算 X-Y = [X]补 + [-Y]补：

    0.1011  (最高位进位 Cₙ = 0)
  + 0.0110  (次高位进位 Cₙ₋₁ = 1)
  ----------
    0.1161  → 模2运算，舍去最高进位

实际运算过程（按位）：
    00.1011
  + 00.0110
  ----------
    01.0001

进位判断法溢出判断：
- Cₙ = 0 (符号位产生的进位)
- Cₙ₋₁ = 1 (最高数值位向符号位的进位)
- Cₙ ⊕ Cₙ₋₁ = 0 ⊕ 1 = 1 → 发生溢出

由于结果符号位为0，且发生了溢出，故为正溢出。

实际结果：X-Y = +0.1011 - (-0.0110) = +0.1011 + 0.0110 = +0.1161
超出定点小数表示范围，发生了溢出。
```

> [!tip] 进位判断法要点
> - **Cₙ** = 符号位产生的进位
> - **Cₙ₋₁** = 最高数值位向符号位的进位
> - **Cₙ ⊕ Cₙ₋₁ = 1** → 溢出；**= 0** → 无溢出
> - 正溢出时符号位为01，负溢出时符号位为10
