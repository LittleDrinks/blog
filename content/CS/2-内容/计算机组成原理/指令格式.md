# 指令格式

指令格式是指令字用二进制代码表示的结构形式，通常由**操作码字段**和**地址码字段**组成。

## 操作码（Opcode）

### 需表示的信息
- **操作类型**：操作功能 + 操作数类型
- **格式信息**：操作数个数 + 位置

### 编码方法

#### 1. 定长编码
- **方法**：按序编码，长度 = $\lceil \log_2(\text{指令种类数}) \rceil$
- **特点**：
  - 信息冗余大，程序总长度增加
  - 但译码电路简单，解码速度快
- **例子**：IBM 370机，字长32位，183条指令，操作码固定8位，指令长度可变（16、32、48位）
- **适用**：**RISC** 更适合定长编码（指令格式规整，译码简单，利于流水线）

#### 2. 变长编码（扩展操作码）
- **方法**：基于哈夫曼编码思想的带权编码，常用指令用短操作码，不常用指令用长操作码
- **特点**：
  - 信息冗余小，程序总长度优化
  - 译码复杂，需要更多硬件支持
- **适用**：**CISC** 更适合变长编码（指令系统庞大，追求代码密度）

> [!tip] 考试对比表（必背）

| 对比项 | 定长编码 | 变长编码（扩展操作码） |
|--------|----------|------------------------|
| 操作码长度 | 固定 | 不固定 |
| 信息冗余 | 大 | 小 |
| 程序长度 | 较长 | 较短 |
| 译码难度 | 简单 | 复杂 |
| 典型应用 | RISC（如MIPS） | CISC（如x86） |
| 流水线友好度 | 高 | 低 |

> [!warning] 易错点
> 定长编码和变长编码的选择与 CISC/RISC 的体系结构思想密切相关。考试常考：**RISC 采用定长编码，CISC 采用变长编码**。

## 地址码

根据一条指令中操作数地址的数量，可分为：

### 三地址指令
```
OP  A1  A2  A3
```
- **功能**：`(A1) OP (A2) → A3`，`(PC) + 1 → PC`
- **特点**：指令长度比较长，在字长较长的大、中型机中使用，小型、微型机中很少使用
- **优点**：不破坏源操作数

### 二地址指令
```
OP  A1  A2
```
- **功能**：`(A1) OP (A2) → A1`，`(PC) + 1 → PC`
- **特点**：广泛应用；指令执行之后，A1 中的内容被新的运算结果替换
- **分类**（按操作数物理位置）：
  - **SS型（Storage-Storage）**：两个操作数都在存储器中，访存次数多，执行最慢
  - **RS型（Register-Storage）**：一个操作数在寄存器，一个在存储器
  - **RR型（Register-Register）**：两个操作数都在寄存器中，执行最快

> [!tip] 速度口诀
> **RR > RS > SS**（寄存器比存储器快得多）

### 单地址指令
```
OP  A1
```
- **功能**：`(AC) OP (A1) → A1`，`(PC) + 1 → PC`（隐含累加器 AC）
- **适用场景**：
  - 单操作数运算指令，如 "+1"、"-1"、"求反"
  - 指令中给出一个源操作数的地址，另一个操作数隐含在累加器中

### 零地址指令
```
OP
```
- **功能**：无需显式地址
- **适用场景**：
  - 控制类指令："停机"、"空操作"、"清除"
  - 堆栈操作指令（操作数隐含在栈顶）

## 指令字长度

### 概念
- **指令字长度**：一个指令字包含二进制代码的位数
- **机器字长**：计算机能直接处理的二进制数据的位数

### 分类
| 类型 | 说明 | 特点 |
|------|------|------|
| **单字长指令** | 指令长度 = 机器字长 | 取指一次完成，速度快 |
| **半字长指令** | 指令长度 = ½ 机器字长 | 节省存储空间 |
| **双字长指令** | 指令长度 = 2 × 机器字长 | 可提供更多地址位，扩大寻址范围 |

### 多字长指令的优缺点
- **优点**：提供足够的地址位来解决访问内存任何单元的寻址问题
- **缺点**：
  - 两次或多次访问内存才能取出一整条指令，降低 CPU 运算速度
  - 占用了更多存储空间

### 等长指令 vs 非等长指令
- **等长指令**：各种指令字长度相等，结构简单，控制方便（**RISC 典型特征**）
  - 译码简单，存储低效
- **非等长指令**：各种指令字长度随指令功能而异，结构灵活（**CISC 典型特征**）
  - 存储高效，译码复杂

> [!tip] 记忆口诀
> **等长 = 简单规整 = RISC 爱用**
> **不等长 = 灵活高效 = CISC 爱用**

## 指令助记符

由于硬件只能识别1和0，所以采用二进制操作码是必要的，但我们用二进制来书写程序却非常麻烦。

为了便于书写和阅读程序，每条指令通常用3个或4个英文缩写字母来表示，这种缩写码叫做**指令助记符**。

| 操作 | 助记符 |
|------|--------|
| 加法 | ADD |
| 减法 | SUB |
| 传送 | MOV |
| 跳转 | JMP |
| 加载 | LD / LDR |
| 存储 | ST / STR |

> [!warning] 注意
> 不同的计算机系统，助记符规定不一样，必须用汇编器翻译成二进制代码才能被硬件执行。

## 典型指令格式举例

### 1. MIPS R4000 指令格式（RISC）
- 32位字长，32个通用寄存器
- **R型（寄存器）指令**：
  ```
  | 6位 op | 5位 rs | 5位 rt | 5位 rd | 5位 shamt | 6位 funct |
  ```
- **I型（立即数）指令**：
  ```
  | 6位 op | 5位 rs | 5位 rt | 16位 常数或地址 |
  ```

> [!tip] MIPS 特点
> 指令长度固定为32位，只有R型和I型（还有J型跳转指令），格式高度规整，非常适合流水线。

### 2. ARM 指令格式（RISC）
- 32位定长指令
- 支持条件执行（每条指令可带条件码）
- 三地址指令格式，寄存器资源丰富

### 3. Pentium 指令格式（CISC）
- 指令长度可变，最短1个字节，最长12个字节
- 典型的 CISC 指令系统，操作码长度固定但指令整体长度可变

> [!warning] 考试重点
> 常考 MIPS 的 R型/I型指令格式识别，以及 **RISC 采用定长指令、CISC 采用变长指令** 这一核心区别。

## 考试重点题型汇编

> [!faq] 某计算机指令字长16位，地址码各4位。采用扩展操作码技术，若设计三地址指令15条，二地址指令14条，一地址指令31条，则零地址指令最多可设计____条。</br>A. 16</br>B. 32</br>C. 64</br>D. 128
> A。计算过程：三地址预留1个扩展点，二地址可编码1×16=16种，使用14条后预留2个扩展点，一地址可编码2×16=32种，使用31条后预留1个扩展点，零地址可编码1×16=16条。

> [!faq] 定长编码和变长编码的主要区别是____。</br>A. 定长编码程序短</br>B. 变长编码译码简单</br>C. 定长编码信息冗余大</br>D. 变长编码流水线友好
> C。定长编码操作码长度固定，信息冗余大（所有指令占用相同位数），程序总长度增加；变长编码信息冗余小，程序更短。定长编码译码简单、流水线友好（RISC采用）；变长编码译码复杂（CISC采用）。

> [!faq] 二地址指令中，操作数物理位置不同导致执行速度差异，速度排序正确的是____。</br>A. SS > RS > RR</br>B. RR > RS > SS</br>C. RS > RR > SS</br>D. RR > SS > RS
> B。RR型（寄存器-寄存器）最快，两个操作数都在寄存器中，无需访存；RS型（寄存器-存储器）次之，需一次访存；SS型（存储器-存储器）最慢，需多次访存。

> [!faq] 某指令系统有128条指令，则操作码最少需要____位。</br>A. 6</br>B. 7</br>C. 8</br>D. 9
> B。n位操作码最多表示2^n条指令。128条指令需要 $\lceil \log_2(128) \rceil = 7$ 位操作码。

> [!faq] 关于指令字长度，下列说法错误的是____。</br>A. 单字长指令取指一次完成</br>B. 多字长指令可扩大寻址范围</br>C. RISC通常采用定长指令</br>D. 等长指令译码复杂
> D。等长指令（各种指令字长度相等）结构简单，译码简单；非等长指令译码复杂。选项D描述与事实相反，故选D。
