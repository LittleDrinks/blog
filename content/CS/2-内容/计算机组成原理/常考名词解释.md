# 常考名词解释

| 名词 | 定义要点 |
|------|---------|
| **CPI** | 每条指令的平均时钟周期数 |
| **MIPS** | 每秒百万条指令 |
| **ALU** | 算术逻辑单元，执行算术和逻辑运算 |
| **CU** | 控制单元，产生控制信号 |
| **MAR** | 存储器地址寄存器 |
| **MDR** | 存储器数据寄存器 |
| **PC** | 程序计数器，存放下条指令地址 |
| **IR** | 指令寄存器，存放当前指令 |
| **PSW** | 程序状态字，存放程序运行状态 |
| **微指令** | 一组微命令的集合，完成一个基本操作 |
| **微程序** | 完成一条机器指令的微指令序列 |
| **控制存储器** | 存放微程序的控制存储器 |
| **数据冒险** | 指令间数据依赖导致的冲突 |
| **控制冒险** | 分支指令改变执行顺序导致的冲突 |
| **吞吐率** | 单位时间内完成的指令数 |
| **加速比** | 改进前后执行时间的比值 |
