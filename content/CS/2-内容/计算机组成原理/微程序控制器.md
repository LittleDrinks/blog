[[微命令]]、[[微操作]]
相容微操作（可并行）→ 各占一位直接控制；
互斥微操作（不可并行）→ 可编码表示
[[微指令]]、[[微程序]]
【1 机器指令】对应【1 微程序】
![[Pasted image 20260424205233.png]]

控制存储器、微指令寄存器、地址转移逻辑

| 部件 | 功能 |
|------|------|
| 控制存储器 μCM | 存放全部微程序（核心部件） |
| 微指令寄存器 μIR | 存放当前微指令 |
| 微地址形成部件 | 产生初始/后继微地址 |
| 微地址寄存器 μMAR | 接受微地址 |

工作流程：取指微程序（CM 的 0 号单元）→ 操作码形成微程序入口 → 逐条执行微指令 → 回到取指微程序入口

微指令格式 = 操作控制字段 + 顺序控制字段

编码方法：直接表示法（一位一命令，快但字长）→ 编码表示法（互斥命令分组编码，短但慢）→ 混合表示法（折中）

微地址形成：计数器方式（μMAR+1，简单但不能多路转移）vs 多路转移方式（修改μMAR 某些位，灵活）
