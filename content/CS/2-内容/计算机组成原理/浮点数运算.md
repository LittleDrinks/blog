# 浮点数运算

> [!important] 本章考试权重
> 浮点数运算占总分约10-15分，是计算题的重点。必考题型包括：浮点数加减运算完整步骤、IEEE 754格式转换、规格化处理。

## 浮点加减运算

### 运算步骤

```
┌─────────────────────────────────────────────┐
│  1. 对阶（小阶向大阶看齐）                    │
│     - 比较两数阶码                            │
│     - 小阶数的尾数右移，阶码增加               │
├─────────────────────────────────────────────┤
│  2. 尾数加减                                  │
│     - 对阶后的尾数进行加减运算                 │
├─────────────────────────────────────────────┤
│  3. 规格化                                    │
│     - 左规：尾数左移，阶码减小（左规可能多次）  │
│     - 右规：尾数右移，阶码增加（右规最多一次）  │
├─────────────────────────────────────────────┤
│  4. 舍入                                      │
│     - 0舍1入法                                │
│     - 恒置1法                                 │
├─────────────────────────────────────────────┤
│  5. 溢出判断                                  │
│     - 阶码溢出才是真正溢出                     │
│     - 尾数溢出可通过右规解决                   │
└─────────────────────────────────────────────┘
```

> [!tip] 核心要点
> - **对阶原则**：小阶向大阶看齐（不是大阶向小阶）
> - **规格化原则**：补码规格化要求符号位与最高数值位不同

### 规格化

**原码规格化形式**：
- 正数：0.1xxxx...
- 负数：1.1xxxx...

**补码规格化形式**：
- 正数：0.1xxxx...
- 负数：1.0xxxx...（符号位与最高数值位不同）

> [!warning] 补码规格化的关键判断
> 补码负数规格化：小数点后第一位应该是 **0**（与符号位1相反）
> 如果小数点后第一位是1，需要继续左规。

### 舍入方法

1. **0舍1入法**
   - 丢弃位最高位为0：舍去
   - 丢弃位最高位为1：在末位加1

2. **恒置1法**
   - 不论丢弃位如何，结果的末位恒置1

3. **截断法**
   - 直接丢弃多余位（向零舍入）

> [!note] 补码舍入规则
> - 丢失的位全为0，不必舍入
> - 丢失的最高位为0，以后各位不全为0时；或最高位为1，以后各位全为0时，不必舍入
> - 丢失的最高位为1，以后各位不全为0时，则在尾数的最低位入1

### 舍入处理例题

#### 例题：补码舍入处理

**已知**：尾数保留4位小数，有以下补码尾数需舍入：
- [x₁]补 = 11.01100000 → 保留4位
- [x₂]补 = 11.01100001 → 保留4位
- [x₃]补 = 11.01101000 → 保留4位
- [x₄]补 = 11.01111001 → 保留4位

**解**：
- x₁：丢弃0000，全0，不舍入 → 11.0110
- x₂：丢弃0001，最高位0后不全0，不舍入 → 11.0110
- x₃：丢弃1000，最高位1后全0，不舍入 → 11.0110
- x₄：丢弃1001，最高位1后不全0，末位入1 → 11.0111

### 浮点加减运算完整例题 ⭐必考

> [!warning] 浮点加减运算五大易错点
> 1. **对阶方向**：小阶向大阶看齐（不是反过来）
> 2. **右移精度丢失**：小阶数的尾数右移会丢失精度，丢失位要保留用于舍入
> 3. **规格化判断**：补码负数要求符号位与最高数值位**不同**
> 4. **溢出判断对象**：阶码溢出才是真正溢出，尾数溢出可通过右规解决
> 5. **舍入时机**：只有对阶右移和右规时才需要舍入

#### 例题1：浮点数加法运算

**已知**：x = 2^10 × 0.11011011，y = -2^100 × 0.10101100，求 x + y

**解**：

**第一步：0操作数检查**
- x和y均不为0，继续运算

**第二步：对阶**
- [x]浮 = 00010, 0.11011011（阶码用双符号位）
- [y]浮 = 00100, 1.01010100
- 阶差 ΔE = [Ex]补 - [Ey]补 = 00010 - 00100 = 11110（补码形式为-2）
- x阶码小，需要x的尾数右移2位，阶码加2
- [x]浮 = 00100, 0.00110110(11)（右移2位，精度降低）

> [!note] 对阶说明
> 小阶向大阶看齐，x的阶码从00010变成00100，尾数右移2位。右移时丢失的位(11)暂时保留用于舍入。

**第三步：尾数相加**
```
  00.00110110(11)   [Mx]补
+ 11.01010100       [My]补
───────────────────
  11.10001010(11)   [Mx+My]补
```

**第四步：规格化**
- 结果 11.10001010 不是规格化数（小数点后第一位是1，与符号位相同）
- 需要左规：尾数左移1位，阶码减1
- 结果变为：11.00010101(10)，阶码为 00011

> [!tip] 规格化判断
> 补码负数规格化要求：符号位为1，小数点后第一位为0（两者不同）
> 当前结果11.100...不满足（小数点后第一位是1），需要左移

**第五步：舍入处理**
- 采用0舍1入法，丢弃位最高位为1，入1
- 结果变为：11.00010110

**第六步：溢出判断**
- 阶码为00011，符号位为00，不溢出

**最终结果**：x + y = 2^11 × (-0.11101010)

#### 例题2：十进制浮点数加法

**已知**：x = 10^2 × 0.3，y = 10^3 × 0.2，求 x + y 和 x - y

**解**：
- Ex = 2，Ey = 3，Ex < Ey，小阶向大阶看齐

**x + y**：
```
x + y = (0.3 × 10^(2-3) + 0.2) × 10^3
      = (0.03 + 0.2) × 10^3
      = 0.23 × 10^3
      = 230
```

**x - y**：
```
x - y = (0.3 × 10^(2-3) - 0.2) × 10^3
      = (0.03 - 0.2) × 10^3
      = -0.17 × 10^3
      = -170
```

#### 例题3：浮点数乘法运算

**已知**：x = 2^-5 × 0.0110011，y = 2^3 × (-0.1110010)，求 x × y

**解**：
- 阶码采用双符号位，尾数原码采用单符号位
- [Mx]原 = 0.0110011，[My]原 = 1.1110010
- [Ex]补 = 11011（-5的补码），[Ey]补 = 00011（3的补码）

**第一步：求阶码和**
```
[Ex]补 + [Ey]补 = 11011 + 00011 = 11110（-2的补码）
```

**第二步：尾数乘法运算**
```
[Mx]原 × [My]原 = [0.0110011]原 × [1.1110010]原
                = [1.0101101,0110110]原
```
- 符号位：0 ⊕ 1 = 1（负数）

**第三步：规格化处理**
- 乘积不是规格化的数，需要左规
- 尾数左移1位变为：1.1011010,1101100
- 阶码变为：11101（-3的补码）

**第四步：舍入处理**
- 尾数为负数，按舍入规则处理，结果为：1.1011011

**最终结果**：[x×y]浮 = 11101, 1.1011011

**真值**：x × y = 2^-3 × (-0.1011011)

### 流水线原理

**时钟周期定义**：
```
τ = max{τi} + τl = τm + τl
```
其中τi为各段处理时间，τl为缓冲寄存器延迟

**流水线加速比**：
```
Ck = TL / Tk = nk / (k + n - 1)
```
- TL = n·k·τ（非流水线总时间）
- Tk = k + (n-1)（流水线时钟周期数）
- k为过程段数，n为任务数

> [!tip] 流水线特点
> - 当n远大于k时，加速比接近k
> - 流水线需要装满时间，完全装满后每周期输出一个结果
> - 浮点加法流水线典型分为4段：对阶、尾数相加、规格化、舍入

### 例题：流水线加速比计算

**已知**：4级流水浮点加法器，各段时间τ1=70ns, τ2=60ns, τ3=90ns, τ4=80ns，缓冲器延迟τl=10ns。

**求**：加速比

**解**：
- 时钟周期：τ = max{τi} + τl = 90 + 10 = 100ns
- 非流水线时间：70+60+90+80 = 300ns
- 加速比：300/100 = **3倍**

## 考试真题精选

> [!faq] 设x=2^10×0.11011011，y=-2^100×0.10101100，求x+y，写出完整运算步骤。
> ①对阶：Ex=10<Ey=100，阶差=-2，x尾数右移2位得0.00110110(11)，阶码变为100。②尾数相加：0.00110110(11)+1.01010100=1.10001010(11)。③规格化：11.100...不满足规格化（小数点后第一位为1与符号位相同），左移1位得11.00010101(10)，阶码减1为11。④舍入：0舍1入，丢弃位最高为1，末位加1得11.00010110。⑤溢出判断：阶码00.011无溢出。结果：x+y=2^11×(-0.11101010)。

> [!faq] 浮点数加法运算中，对阶的原则是什么？为什么？
> 对阶原则：**小阶向大阶看齐**。原因：若大阶向小阶看齐，则需要尾数左移，左移会丢失最高有效位，造成很大误差；而小阶向大阶看齐时尾数右移，只丢失最低有效位，误差较小。因此规定小阶的尾数右移，阶码增加，保持数值不变。

> [!faq] 补码浮点数规格化的条件是什么？
> 补码浮点数规格化条件：**符号位与最高数值位不同**。即正数规格化形式为0.1xxxx...，负数规格化形式为1.0xxxx...。这与原码规格化不同（原码要求尾数最高位为1）。

> [!faq] 设x=2^-5×0.0110011，y=2^3×(-0.1110010)，求x×y。
> ①阶码相加：[-5]补+[3]补=11011+00011=11110=-2。②尾数相乘：符号0⊕1=1，|0.0110011|×|0.1110010|=10110110110110。③规格化：结果非规格化，左移1位得1.10110101101100，阶码变为-3=11101。④舍入：取高位得1.1011011。结果：x×y=2^-3×(-0.1011011)。

> [!faq] IEEE 754单精度浮点数中，为什么偏移量选127而不是128？（详见[[IEEE754浮点数]]）
> 8位阶码可表示256个编码，除去全0（表示0或非规格化数）和全1（表示无穷大或NaN）后剩254个。若偏移量选128，则真值范围为-128~+127，不对称；选127则真值范围为-126~+127，更均衡。同时，全0和全1被保留用于特殊值，规格化数阶码范围1~254，真值范围-126~+127。
