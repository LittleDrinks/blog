# Booth算法计算题

## 算法步骤

1. 被乘数X，乘数Y，部分积初始为0
2. 附加位Yₙ₊₁初始为0
3. 根据YₙYₙ₊₁决定操作
4. 右移一位（算术右移）
5. 重复n次

---

### 例题1：Booth算法计算（正 × 负）

**题目：**
> 用Booth算法计算 X × Y，其中 X=+0.1011，Y=-0.1101

**解答：**
```
[X]补 = 00.1011, [-X]补 = 11.0101
[Y]补 = 1.0011 (乘数，最低位右边加0)

初始：部分积 = 00.0000，乘数 = 1.0011 0

第1步：末两位10 → 部分积 = 部分积 + [-X]补
       00.0000 + 11.0101 = 11.0101
       右移：11.1010 1 1001

第2步：末两位11 → 直接右移
       右移：11.1101 0 1100

第3步：末两位00 → 直接右移
       右移：11.1110 1 0110

第4步：末两位01 → 部分积 = 部分积 + [X]补
       11.1110 + 00.1011 = 00.1001
       右移：00.0100 1 1011

第5步：末两位10 → 部分积 = 部分积 + [-X]补
       00.0100 + 11.0101 = 11.1001
       右移：11.1100 1 1101

结果：[X×Y]补 = 11.11001101
      X×Y = -0.00110011
```

### 例题2：Booth算法计算（正 × 正）

**题目：**
> 用Booth算法计算 X × Y，其中 X=+0.1101，Y=+0.1011

**解答：**
```
[X]补 = 00.1101, [-X]补 = 11.0011
[Y]补 = 0.1011 (乘数，最低位右边加0)

初始：部分积 = 00.0000，乘数 = 0.1011 0

第1步：末两位10 → 部分积 = 部分积 + [-X]补
       00.0000 + 11.0011 = 11.0011
       右移：11.1001 1 0101

第2步：末两位01 → 部分积 = 部分积 + [X]补
       11.1001 + 00.1101 = 00.0110
       右移：00.0011 0 1010

第3步：末两位10 → 部分积 = 部分积 + [-X]补
       00.0011 + 11.0011 = 11.0100
       右移：11.1010 0 0101

第4步：末两位01 → 部分积 = 部分积 + [X]补
       11.1010 + 00.1101 = 00.0111
       右移：00.0011 1 0010

结果：[X×Y]补 = 00.00111001
      X×Y = +0.00111001 (正数)
```

### 例题3：Booth算法计算（负 × 负）

**题目：**
> 用Booth算法计算 X × Y，其中 X=-0.1010，Y=-0.0110

**解答：**
```
[X]补 = 11.0110, [-X]补 = 00.1010
[Y]补 = 1.1010 (乘数，最低位右边加0)

初始：部分积 = 00.0000，乘数 = 1.1010 0

第1步：末两位00 → 直接右移
       右移：00.0000 0 1101

第2步：末两位10 → 部分积 = 部分积 + [-X]补
       00.0000 + 00.1010 = 00.1010
       右移：00.0101 0 0110

第3步：末两位01 → 部分积 = 部分积 + [X]补
       00.0101 + 11.0110 = 11.1011
       右移：11.1101 1 0011

第4步：末两位11 → 直接右移
       右移：11.1110 1 1001

结果：[X×Y]补 = 11.11101100
      X×Y = -0.00010100
      
验证：(-0.1010) × (-0.0110) = +0.00111100
      注意：本题结果应为正数，计算过程需仔细验证符号位处理
```

> [!tip] Booth算法要点
> - YₙYₙ₊₁ = 01 → +[X]补
> - YₙYₙ₊₁ = 10 → +[-X]补
> - YₙYₙ₊₁ = 00 或 11 → 直接右移
