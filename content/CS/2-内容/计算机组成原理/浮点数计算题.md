# 浮点数计算题

## 转换公式

**单精度(32位)：**
```
V = (-1)^S × 1.M × 2^(E-127)

S: 符号位(1位)
E: 阶码(8位，偏移127)
M: 尾数(23位，隐含最高位1)
```

---

### 例题1：十进制转IEEE 754

**题目：**
> 将 -12.75 转换为IEEE 754单精度浮点数

**解答：**
```
第1步：确定符号
  -12.75 → S = 1

第2步：转换为二进制
  12.75 = 1100.11 = 1.10011 × 2³

第3步：计算阶码
  E - 127 = 3 → E = 130 = 10000010

第4步：确定尾数
  1.10011 → 去掉隐含的1，M = 10011000000000000000000

第5步：组合
  1 10000010 10011000000000000000000

十六进制：C14C0000H
```

---

### 例题2：IEEE 754转十进制

**题目：**
> IEEE 754单精度：0 10000001 01000000000000000000000，求十进制值

**解答：**
```
S = 0 → 正数
E = 10000001₂ = 129
M = 01000000000000000000000

真值 = (-1)^0 × 1.01 × 2^(129-127)
     = 1.01 × 2²
     = 101₂
     = 5
```

### 例题3：浮点数加法运算

**题目：**
> 用IEEE 754单精度格式计算两个浮点数相加：X=1.5，Y=2.5，写出计算过程和结果。

**解答：**
```
第1步：转换为IEEE 754格式
  X = 1.5 = 1.1 × 2⁰
    → S=0, E=127(01111111), M=10000000000000000000000
    → [X] = 0 01111111 10000000000000000000000

  Y = 2.5 = 10.1 × 2⁰ = 1.01 × 2¹
    → S=0, E=128(10000000), M=01000000000000000000000
    → [Y] = 0 10000000 01000000000000000000000

第2步：对阶
  X阶码127，Y阶码128，阶差 = 128-127 = 1
  将X的尾数右移1位，阶码加1：
  X尾数：1.100000... → 0.110000...（右移后）
  X阶码：127 → 128

第3步：尾数相加
  0.1100000... × 2¹²⁸
  + 1.0100000... × 2¹²⁸
  = 1.1200000... × 2¹²⁸
  
  实际计算（二进制）：
  0.1100... + 1.0100... = 1.1000...（需规范化）

第4步：规范化
  结果：1.100000... × 2¹²⁸
  E = 128, M = 10000000000000000000000

第5步：组合结果
  0 10000000 10000000000000000000000
  
  十进制验证：1.100 × 2¹ = 1.5 + 2.5 = 4.0
  4.0 = 1.0 × 2² → E=129, M=000...
  
  实际结果应为4.0的IEEE 754表示：
  0 10000001 00000000000000000000000
```

> [!tip] 浮点运算步骤
> 1. **对阶**：小阶向大阶看齐，尾数右移
> 2. **尾数运算**：加减尾数
> 3. **规范化**：调整结果使尾数符合格式
> 4. **舍入**：处理精度问题
> 5. **溢出判断**：检查阶码是否超出范围
