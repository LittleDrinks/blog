# 计算机性能指标

> [!warning]
> 本章是**期末考试计算题重灾区**，必须熟练掌握以下公式的推导和计算！
> Amdahl定律相关计算详见[[Amdahl定律]]。

---

## 一、基本性能指标与公式

### 1. 主频（f）与时钟周期（T）

**定义**：
- **主频（f）**：CPU的工作节拍频率，单位是 MHz 或 GHz
- **时钟周期（T）**：主频的倒数，是CPU操作的最基本时间单位

**公式**：
```
T = 1 / f
```

> 例：主频 2 GHz，则时钟周期 T = 1 / (2×10⁹) = 0.5 ns

---

### 2. CPU执行时间（t_CPU）

**定义**：CPU执行一段程序所占用的CPU时间。

**公式**：
```
t_CPU = CPU时钟周期数 × 时钟周期
      = CPU时钟周期数 / 时钟频率
      = IC × CPI × T
      = (IC × CPI) / f
```

其中：
- **IC**（Instruction Count）：指令条数
- **CPI**（Cycles Per Instruction）：每条指令的平均时钟周期数
- **T**：时钟周期
- **f**：时钟频率

---

### 3. CPI（Cycles Per Instruction）

**定义**：执行一条指令所需的**平均**时钟周期数。

**公式**：
```
CPI = CPU时钟周期总数 / 指令条数(IC)
    = Σ(CPIi × Ii) / IC
```

其中：
- **CPIi**：第 i 类指令的平均时钟周期数
- **Ii**：第 i 类指令在程序中出现的次数

> [!tip]
> 如果某类指令占比为 Pi，则 CPI = Σ(CPIi × Pi)

---

### 4. MIPS（Million Instructions Per Second）

**定义**：每秒执行的**百万条指令数**。

**公式**：
```
MIPS = 指令条数 / (执行时间 × 10⁶)
     = 时钟频率 / (CPI × 10⁶)
     = f / (CPI × 10⁶)
```

> [!warning]
> MIPS值越高，机器速度越快（在相同指令集和程序下）。但不同机器指令功能不同，MIPS不能直接比较！

---

### 5. MFLOPS / TFLOPS

**定义**：
- **MFLOPS**：每秒百万次浮点操作次数
- **TFLOPS**：每秒万亿次浮点操作次数（超级计算机常用）

**公式**：
```
MFLOPS = 浮点操作次数 / (执行时间 × 10⁶)
```

> [!tip]
> MFLOPS只能衡量浮点操作性能，**不能体现机器整体性能**。

## 二、经典计算例题（考试必考类型）

### 例题 1：CPI计算

**题目**：某程序包含指令：整数运算45000条(CPI=1)，数据传送32000条(CPI=2)，浮点运算15000条(CPI=2)，控制传送8000条(CPI=2)。处理机主频50MHz。求有效CPI、MIPS速率、程序执行时间。

**解答**：

总指令数IC = 45000+32000+15000+8000 = 100000条

**CPI计算**：
```
CPI = (45000×1 + 32000×2 + 15000×2 + 8000×2) / 100000
    = (45000+64000+30000+16000)/100000
    = 155000/100000
    = 1.55
```

**MIPS计算**：
```
MIPS = f/(CPI×10⁶) = 50×10⁶/(1.55×10⁶) ≈ 32.26
```

**执行时间计算**：
```
t_CPU = IC×CPI/f = 100000×1.55/(50×10⁶) = 0.0031秒 = 3.1毫秒
```

---

### 例题 2：MIPS计算

**题目**：计算 Pentium IV 2GHz 处理机的指令执行速度。已知其 IPC = 4（或 CPI = 0.25）。

**解答**：
```
f = 2000 MHz = 2×10⁹ Hz
IPC = 4

MIPS = f × IPC / 10⁶ = 2000 × 4 = 8000 MIPS = 8 GIPS
```

或：
```
MIPS = f / (CPI × 10⁶) = 2000 / 0.25 = 8000 MIPS
```

---

### 例题 3：两台机器性能对比

**题目**：两台机器A和B对条件转移指令采用不同方法。
- **CPUA**：用一条比较指令设置条件码，再跟一条转移指令测试。实现一条条件转移需**2条指令**。条件转移指令占20%，比较指令也占20%（因为每条转移都需要比较），其他指令占60%。所有指令CPI=1，时钟周期为T。
- **CPUB**：比较和转移合在一条指令中，实现条件转移只需**1条指令**。但时钟周期比CPUA慢25%，即 T_B = 1.25 T_A。

比较哪个工作速度更快。

**解答**：

假设程序总指令数相同，设为 IC。

**CPUA**：
- 指令数：IC_A = IC
- 条件转移指令：0.2 IC，比较指令：0.2 IC，其他：0.6 IC
- 所有指令 CPI = 1
- 总时钟周期数 = IC × 1 = IC
- 执行时间：t_A = IC × T_A

**CPUB**：
- 条件转移占功能的20%，但只需1条指令完成
- 设完成同一功能，CPUA的指令数为 N
  - CPUA：0.2N 条比较 + 0.2N 条转移 + 0.6N 条其他 = N 条
  - CPUB：0.2N 条转移（含比较）+ 0.6N 条其他 = 0.8N 条

假设转移指令CPI=2，其他CPI=1：
```
CPI_A = 0.2×1 + 0.2×2 + 0.6×1 = 0.2 + 0.4 + 0.6 = 1.2
CPI_B = 0.2×2 + 0.8×1 = 0.4 + 0.8 = 1.2
```

执行时间：
```
t_A = N × CPI_A × T_A = N × 1.2 × T_A = 1.2 N T_A
t_B = 0.8N × CPI_B × T_B = 0.8N × 1.2 × 1.25 T_A = 1.2 N T_A
```

**答**：两台机器**速度相同**。

> [!tip]
> 此题关键：CPUB虽然省了指令数，但时钟周期变长了，刚好抵消。

## 三、其他重要性能指标

| 指标 | 定义 | 单位 |
|------|------|------|
| **吞吐量** | 某一时间间隔内能够处理的信息量 | 字节/秒（B/S） |
| **响应时间** | 从输入有效到系统产生响应之间的时间度量 | 微秒、纳秒 |
| **利用率** | 在给定时间间隔内，系统被实际使用的时间比率 | 百分比 |
| **处理机字长** | 运算器中一次能完成二进制运算的位数 | 8/16/32/64位 |
| **总线宽度** | CPU中运算器与存储器之间内部总线的二进制位数 | 位（bit） |
| **存储器容量** | 存储器中所有存储单元的总数目 | KB、MB、GB、TB |
| **存储器带宽** | 单位时间内从存储器读出的信息量 | 字节数/秒 |

## 四、易错点与记忆口诀

> [!warning]
> **CPI vs IPC**：
> - CPI = Cycles Per Instruction（每条指令多少周期）
> - IPC = Instruction Per Cycle（每个周期多少条指令）
> - **CPI = 1 / IPC**，两者互为倒数！

> [!tip]
> **性能比较黄金法则**：
> 比较两台机器执行同一程序的性能，本质是比较 **CPU执行时间 = IC × CPI × T**。指令数少的机器不一定快（可能CPI高或时钟周期长）！

## 考试常考题型

> [!faq] CPI的含义是什么？它与IPC的关系是什么？
> CPI（Cycles Per Instruction）表示每条指令周期数，即执行一条指令所需的平均时钟周期数。IPC（Instruction Per Cycle）表示每个时钟周期平均执行的指令条数。两者的关系是：CPI = 1/IPC，它们互为倒数。

> [!faq] MIPS的定义和计算公式是什么？
> MIPS（Million Instructions Per Second）表示每秒执行的百万条指令数。计算公式：MIPS = 指令条数 / (执行时间 × 10⁶) = 时钟频率 / (CPI × 10⁶) = f / (CPI × 10⁶)。MIPS值越高，说明机器速度越快（在相同指令集和程序下）。但不同机器指令功能不同，MIPS不能直接比较。

> [!faq] 某程序包含指令：整数运算45000条(CPI=1)，数据传送32000条(CPI=2)，浮点运算15000条(CPI=2)，控制传送8000条(CPI=2)。处理机主频50MHz。求有效CPI、MIPS速率、程序执行时间。
> 总指令数IC = 45000+32000+15000+8000 = 100000条。CPI = (45000×1 + 32000×2 + 15000×2 + 8000×2) / 100000 = (45000+64000+30000+16000)/100000 = 155000/100000 = 1.55。MIPS = f/(CPI×10⁶) = 50×10⁶/(1.55×10⁶) ≈ 32.26。执行时间t_CPU = IC×CPI/f = 100000×1.55/(50×10⁶) = 0.0031秒 = 3.1毫秒。

> [!faq] 主频2GHz的Pentium IV处理器，IPC=4，求其MIPS值。
> MIPS = f × IPC = 2000 MHz × 4 = 8000 MIPS = 8 GIPS。或用CPI=1/IPC=0.25计算：MIPS = f/(CPI×10⁶) = 2000/0.25 = 8000 MIPS。

> [!faq] MIPS和MFLOPS的区别是什么？为什么MFLOPS不能体现机器整体性能？
> MIPS是每秒百万条指令数，基于指令计算；MFLOPS是每秒百万次浮点操作次数，基于操作计算。MFLOPS只能衡量浮点操作性能，不能体现机器整体性能，因为：(1)不同程序的浮点操作比例不同；(2)整数运算、I/O操作等对整体性能也很重要；(3)不同机器的指令功能复杂度不同。

> [!faq] CPU执行时间的三个决定因素是什么？写出CPU执行时间的计算公式。
> CPU执行时间取决于三个要素：时钟频率f、每条指令时钟周期数CPI、指令条数IC。计算公式：t_CPU = IC × CPI × T = (IC × CPI) / f = CPU时钟周期数 / f。时钟周期T = 1/f。这三个因素相互影响，比较两台机器性能本质是比较CPU执行时间。
