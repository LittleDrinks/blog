# 流水线性能计算

> [!warning]
> **吞吐率、加速比、效率的计算是考试必考计算题！** 必须熟练掌握公式和计算方法！

---

## 性能指标公式速记表

| 指标 | 公式 | 说明 |
|------|------|------|
| **总时间** | `T_k = (k + n - 1) × Δt` | k段流水线执行n条指令 |
| **吞吐率** | `TP = n / T_k` | 单位时间完成指令数 |
| **加速比** | `S = k×n / (k+n-1)` | 流水线与非流水线时间比 |
| **效率** | `E = n / (k+n-1)` | 时空图有效面积占比 |
| **时钟周期** | `Δt = max(各段时间)` | 不等长流水线 |

---

## 吞吐率（Throughput）

### 定义

**吞吐率**：单位时间内完成的指令数。

### 公式

**基本公式**：
```
TP = n / T_k
```

**最大吞吐率**（理想情况）：
```
TP_max = 1 / Δt
```

**实际吞吐率**（考虑流水线建立时间）：
```
TP = n / ((k + n - 1) × Δt)
```

---

## 加速比（Speedup）

### 定义

**加速比**：非流水线执行时间与流水线执行时间的比值。

### 公式

```
S = T_nonpipe / T_pipe = (k × n × Δt) / ((k + n - 1) × Δt) = (k × n) / (k + n - 1)
```

### 理想情况

当 `n → ∞` 时，`S → k`（最大加速比等于流水线段数）

> [!tip]
> 流水线段数越多，最大加速比越大。但实际中，段数过多会增加复杂度和开销。

---

## 效率（Efficiency）

### 定义

**效率**：流水线中设备的使用效率，即时空图中有效面积与总面积之比。

### 公式

```
E = S / k = n / (k + n - 1)
```

### 理想情况

当 `n → ∞` 时，`E → 1`（100%）

### 时空图理解

```
时空图示例（k=5段，n=4条指令）：

时钟  1    2    3    4    5    6    7    8
────┬────┬────┬────┬────┬────┬────┬────┬────
I1  │ IF │ ID │ EX │ MEM│ WB │    │    │    │  有效面积
I2  │    │ IF │ ID │ EX │ MEM│ WB │    │    │
I3  │    │    │ IF │ ID │ EX │ MEM│ WB │    │
I4  │    │    │    │ IF │ ID │ EX │ MEM│ WB │
────┴────┴────┴────┴────┴────┴────┴────┴────

有效面积 = n × k = 4 × 5 = 20 个单位
总面积 = (k + n - 1) × k = 8 × 5 = 40 个单位
效率 E = 20 / 40 = 50%
```

> [!warning]
> 考试计算题常考！记住三个公式：
> - 吞吐率 `TP = n / ((k+n-1) × Δt)`
> - 加速比 `S = k×n / (k+n-1)`
> - 效率 `E = n / (k+n-1)`
