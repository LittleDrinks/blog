k段流水线执行n条指令：

| 指标 | 公式 |
|------|------|
| 总时间 | T = (k + n - 1) × Δt |
| 吞吐率 | TP = n / T = n / ((k+n-1)×Δt) |
| 最大吞吐率 | TP_max = 1/Δt |
| 加速比 | S = k×n / (k+n-1)，n→∞时S→k |
| 效率 | E = n / (k+n-1)，时空图有效面积/总面积 |
| 时钟周期 | Δt = max(各段时间)（不等长时取最长段） |

S = k × E，即加速比 = 流水线段数 × 效率
