# 寻址方式计算例题

> [!warning] 考试重点提醒
> 相对寻址、基址寻址、变址寻址的有效地址计算是**必考题型**，务必掌握计算方法和步骤！

### 例题 1：相对寻址计算（转移指令）

**题目：**
> 某计算机采用相对寻址的转移指令，转移指令占2个字节。
> 当前转移指令所在地址为 2000H，指令中的偏移量 D = 08H（补码表示）。
> 问：转移后的目标地址是多少？

**解答：**
```
EA = (PC) + D = 2002H + 08H = 200AH
（取指后 PC = 2000H + 2H = 2002H）
```

> [!tip] 易错点
> **PC 不是当前指令地址，而是下一条指令地址！**

---

### 例题 2：相对寻址负偏移量

**题目：**
> 转移指令地址为 1000H，指令长度2字节，偏移量 D = F0H（补码）。

**解答：**
```
PC = 1002H，F0H = -16D
EA = 1002H - 10H = 0FF2H（向后跳转）
```

---

### 例题 3：基址寻址计算（程序重定位）

**题目：**
> BR = 4000H，逻辑地址 A = 0100H。

**解答：**
```
EA = (BR) + A = 4000H + 0100H = 4100H
```

---

### 例题 4：变址寻址计算（数组访问）

**题目：**
> 数组 A 起始地址 1000H，IX = 10，元素占 4 字节。

**解答：**
```
EA = 1000H + 10 × 4 = 1040H
```

---

### 例题 5：综合寻址方式计算

**题目：**
> 指令格式：| 6位 OP | 2位 X | 1位 I | 7位 D |
> PC = 1000H，IX = 200H，BR = 300H，D = 0050H

**解答：**
```
(1) X=00, I=0：直接寻址   → EA = 0050H
(2) X=01, I=0：相对寻址   → EA = 1001H + 0050H = 1051H
(3) X=10, I=0：变址寻址   → EA = 0050H + 0200H = 0250H
(4) X=11, I=0：基址寻址   → EA = 0050H + 0300H = 0350H
(5) X=00, I=1：先直接后间接 → EA = (0050H)
(6) X=10, I=1：先变址后间接 → EA = (0250H)
```

> [!warning] 组合寻址核心规则
> **严格按照字面顺序执行**！访存次数 = 基本寻址方式访存次数 + 间址层数

### 例题 6：二地址指令寻址方式判断

**题目：**
> | 6位 OP | 4位 REG | 1位 I | 2位 X | 16位 D |
> PC=500H，IX=50H，BR=400H，D=0020H

**解答：**
```
(1) I=0, X=00：直接寻址  → EA = 0020H
(2) I=0, X=01：相对寻址  → EA = 500H + 0020H = 0520H
(3) I=0, X=10：变址寻址  → EA = 0020H + 50H = 0070H
(4) I=0, X=11：基址寻址  → EA = 0020H + 400H = 0420H
(5) I=1, X=00：间接寻址  → EA = (0020H)
(6) I=1, X=10：先变址后间接 → EA = (0070H)
```

### 例题 7：堆栈寻址方式分析

**题目：** 分析 PUSH R1 和 POP R2 的操作过程。

**解答：**
```
PUSH R1：(1) SP ← (SP) - 1  (2) (SP) ← (R1)    ; 先减后写
POP R2： (1) R2 ← (SP)       (2) SP ← (SP) + 1  ; 先读后加
```

### 例题 8：复合寻址方式判断

**题目：**
> D = 100H，IX = 50H，(150H) = 200H。"先变址后间接"。

**解答：**
```
第1步：EA₁ = 100H + 50H = 150H
第2步：EA = (150H) = 200H
```

### 例题 9：访存次数对比分析

| 寻址方式 | 访存次数 | 分析 |
|----------|----------|------|
| 立即寻址 | **0次** | 操作数在指令中 |
| 直接寻址 | **1次** | EA = A |
| 间接寻址 | **2次** | 先取地址再取操作数 |
| 寄存器寻址 | **0次** | 操作数在寄存器中 |
| 寄存器间接 | **1次** | EA = (R) |
| 相对寻址 | **1次** | EA = (PC)+D |

---

### 例题 10：寻址方式对比分析

| 寻址方式 | 访存次数 | 寻址范围 | 速度 |
|----------|----------|----------|------|
| 立即寻址 | 0 | 受立即数位数限制 | 最快 |
| 直接寻址 | 1 | 受地址码位数限制 | 快 |
| 间接寻址 | 2 | 可扩大 | 慢 |
| 寄存器寻址 | 0 | 受寄存器数限制 | 最快 |
| 寄存器间接 | 1 | 较大 | 快 |
| 基址寻址 | 1 | 很大 | 快 |

> [!tip] 快速判断规则
> 1. 操作数在指令中 → 0次
> 2. 操作数在寄存器中 → 0次
> 3. 需计算EA后访存 → 1次
> 4. 有间址标志 → 基础次数 + 1次
