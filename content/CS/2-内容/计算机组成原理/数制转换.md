# 数制转换

> [!important] 概述
> 数制转换是计算机基础概念，考试中常作为IEEE 754转换等大题的第一步。

## 常用数制

| 数制 | 基数 | 数码 | 后缀 |
|------|------|------|------|
| 二进制 | 2 | 0, 1 | B |
| 八进制 | 8 | 0-7 | O/Q |
| 十进制 | 10 | 0-9 | D |
| 十六进制 | 16 | 0-9, A-F | H |

## 进制转换方法

### 二进制与十进制转换

**二进制转十进制**：按权展开求和
```
例：1011.01₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻²
              = 8 + 0 + 2 + 1 + 0 + 0.25
              = 11.25₁₀
```

**十进制转二进制**：
- 整数部分：除2取余（从低位到高位）
- 小数部分：乘2取整（从高位到低位）

```
例：将20.59375转换为二进制

整数部分20：
20 ÷ 2 = 10 余 0
10 ÷ 2 = 5  余 0
5  ÷ 2 = 2  余 1
2  ÷ 2 = 1  余 0
1  ÷ 2 = 0  余 1
结果：10100（从下往上读）

小数部分0.59375：
0.59375 × 2 = 1.1875 → 取1，剩0.1875
0.1875  × 2 = 0.375  → 取0，剩0.375
0.375   × 2 = 0.75   → 取0，剩0.75
0.75    × 2 = 1.5    → 取1，剩0.5
0.5     × 2 = 1.0    → 取1，剩0
结果：10011（从上往下读）

合并：20.59375 = 10100.10011₂
```

### 二进制与八进制/十六进制转换

**二进制转八进制**：3位二进制 = 1位八进制（小数点为界，分别分组）

```
例：10110.11₂ → 八进制
整数部分：010 110 = 2 6
小数部分：110 = 6
结果：26.6₈
```

**二进制转十六进制**：4位二进制 = 1位十六进制

```
例：1011010.11₂ → 十六进制
整数部分：0101 1010 = 5 A
小数部分：1100 = C
结果：5A.C₁₆
```

> [!tip] 转换技巧
> 八进制和十六进制可以作为二进制的"缩写"，便于书写和阅读。

## 十进制数的二进制编码（BCD码）

| 类型 | 编码方式 | 特点 |
|------|---------|------|
| 8421码 | 每位十进制用4位二进制表示 | 最常用，权重8-4-2-1 |
| 余3码 | 8421码 + 0011 | 对9的自补码 |
| 格雷码 | 相邻数只有一位不同 | 抗干扰能力强 |

```
例：十进制数59的BCD码表示

8421码：5 = 0101, 9 = 1001 → 0101 1001
余3码：5 = 0101+0011 = 1000, 9 = 1001+0011 = 1100 → 1000 1100
```

## 字符编码

### ASCII码

- 7位编码，共128个字符
- 包括控制字符（0-31）和可打印字符（32-127）
- 常用字符：
  - '0'-'9'：48-57（00110000-00111001）
  - 'A'-'Z'：65-90（01000001-01011010）
  - 'a'-'z'：97-122（01100001-01111010）

> [!tip] ASCII码规律
> - 数字字符：高3位001，低4位为数字值
> - 大写字母：高2位01，比小写字母小32
> - 小写字母：高2位01，第3位为1

### Unicode

- 统一字符编码标准，覆盖全球所有文字
- UTF-8：变长编码（1-4字节），兼容ASCII
- UTF-16：2或4字节编码
- UTF-32：固定4字节编码

## 汉字编码

### 三种汉字编码

| 编码类型 | 用途 | 特点 |
|----------|------|------|
| 输入码 | 键盘输入 | 拼音码、五笔字型、区位码 |
| 汉字内码 | 机内存储和交换 | 两字节，最高位都为1（区别ASCII） |
| 字模码 | 输出显示和打印 | 点阵表示，如16×16点阵 |

### 国标码（GB2312）

- 一级汉字：3755个（按拼音排序），区位码16~55区
- 二级汉字：3008个（按部首排序），区位码56~87区
- 图形符号：682个，区位码1~9区

> [!tip] 汉字内码与国标码转换
> 汉字内码 = 国标码 + 8080H（两字节最高位置1）

```
例：汉字"中"的编码转换
国标码区位码：55-53 → 国标码：5753H
汉字内码：5753H + 8080H = D7D3H
```

> 整数部分20 = 10100₂，小数部分0.59375 = 0.10011₂。结果：10100.10011₂
