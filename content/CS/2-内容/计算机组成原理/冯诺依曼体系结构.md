# 冯诺依曼体系结构

## 核心思想：存储程序概念

**冯·诺依曼型计算机**的核心思想是**存储程序（Stored Program）**：
> 程序和数据都以二进制形式存储在存储器中，计算机在工作时自动从存储器中按地址取出指令并执行。

**约翰·冯·诺依曼**（1903-1957）被誉为"现代电子计算机之父"；**阿兰·图灵**（1912-1954）被誉为"计算机科学之父"。

---

## 二、指令的形式与存储程序概念

### 指令的基本形式

每条指令由两部分组成：

```
┌─────────────┬─────────────┐
│   操作码    │   地址码    │
└─────────────┴─────────────┘
```

- **操作码**：指出指令所进行的操作性质（如加、减、乘、除、取数、存数等）
- **地址码**：表示参加运算的数据应从存储器的哪个单元中取来，或运算结果应存到哪个单元中去

> [!tip]
> 假定只有8种基本指令，操作码可用3位二进制代码来定义：加法(001)、减法(010)、乘法(011)、除法(100)、取数(101)、存数(110)、打印(111)、停机(000)。

### 存储程序概念详解

**存储程序**是冯诺依曼体系结构的核心思想：

1. **程序和数据都以二进制形式存储在存储器中**
2. **指令和数据放在同一个存储器**中（冯诺依曼结构）
   - 如果指令和数据分别放在两个存储器，称为**哈佛结构**（速度更快）
3. **程序中的指令通常按顺序执行**，所以指令顺次放在存储器里
4. **控制器依据存储的程序来控制全机协调地完成计算任务**，这叫做程序控制

> [!warning]
> **存储程序并按地址顺序执行**，这就是冯诺依曼型计算机的设计思想，也是机器自动化工作的关键！

### 指令系统的重要性

一台计算机通常有几十种基本指令，构成了该计算机的**指令系统（ISA）**。

- 指令系统不仅是**硬件设计的依据**
- 也是**软件设计的基础**
- 因此，指令系统是**衡量计算机性能的一个重要标志**

## 冯诺依曼型计算机的五大部件

```
        ┌─────────────┐
        │   输入设备    │
        └──────┬──────┘
               │ 数据信号
               ▼
┌─────────────────────────────────────┐
│  ┌────────┐      ┌────────┐        │
│  │  运算器  │◄────►│  控制器  │        │
│  │ (ALU)  │      │(CU)    │        │
│  └───┬────┘      └────┬───┘        │
│      │                │            │
│  ┌───┴────────────────┴───┐        │
│  │        存储器           │        │
│  │      (Memory)          │        │
│  └────────────────────────┘        │
└─────────────────────────────────────┘
               ▲
               │ 数据信号 / 地址信号 / 控制信号
        ┌──────┴──────┐
        │   输出设备    │
        └─────────────┘
```

> [!warning]
> **必背五大部件**：运算器、控制器、存储器、输入设备、输出设备。缺一不可！

### 1. 运算器（ALU）
- 执行**算术运算**和**逻辑运算**
- 在计算机中参与运算的数是**二进制的**
- 运算器的长度一般是**8、16、32或64位**

### 2. 控制器（Control Unit）
- **控制器的基本任务**：按照一定的顺序一条接着一条**取指令、指令译码、执行指令**
- 分为**取指周期**和**执行周期**
- 控制器能区分指令字和数据字：
  - **取指周期**：从内存读出的信息流是**指令流**，流向控制器
  - **执行周期**：从内存读出的信息流是**数据流**，由内存流向运算器

### 3. 存储器（Memory）
- 存储**数据**和**程序（指令）**
- 基本单位：
  - 1KB = 2¹⁰B
  - 1MB = 2²⁰B
  - 1GB = 2³⁰B
  - 1TB = 2⁴⁰B
- 分类：**内存（ROM、RAM）** 和 **外存**

### 4. 输入设备（Input Devices）
- 把人们所熟悉的某种信息形式变换为机器内部所能接收和识别的**二进制信息形式**
- 例如：键盘、鼠标、扫描仪

### 5. 输出设备（Output Devices）
- 把计算机处理的结果变换为**人或其他机器设备所能接收和识别的信息形式**
- 例如：显示器、打印机

### 6. 适配器与总线（现代计算机扩展）
- **适配器**：使外围设备通过系统总线与主机联系，让主机和外围设备并行协调工作
- **总线**：构成计算机系统的骨架，是多个系统部件之间进行数据传送的**公共通路**

> [!tip]
> 现代电子计算机由**运算器、存储器、控制器、适配器、总线和输入/输出设备**组成，这就是常说的**计算机硬件**。

## 冯·诺依曼型计算机的主要特点

1. **存储程序**：程序和数据存放在同一存储器中
2. **按地址自动执行**：指令按地址顺序自动取出执行
3. **五大部件组成**：运算器、控制器、存储器、输入设备、输出设备
4. **以运算器为中心**（⚠️ 这是传统冯诺依曼机的特点）

> [!warning]
> **考试陷阱**："以运算器为中心"是**早期冯诺依曼机**的特点，**现代计算机是以存储器为中心**的！

---

## 早期冯诺依曼架构 vs 现代计算机架构

| 特征 | 早期冯诺依曼机 | 现代计算机 |
|------|---------------|-----------|
| **中心部件** | 运算器 | 存储器 |
| **数据通路** | 数据必须经过运算器中转 | 存储器直接与I/O设备交换数据 |
| **瓶颈** | 运算器成为系统瓶颈 | 缓解了运算器压力 |

```
现代计算机结构（以存储器为中心）：

    输入设备 ──────┐
                  │
    输出设备 ─────┼──► 存储器 ◄──► CPU（运算器+控制器）
                  │
    外设适配器 ────┘
```

## 图灵完备性（了解）

**图灵机**：一个抽象的机器，用来模仿人对现实中一切问题思考的过程。

**图灵完备性**：一台机器如果能利用一系列既定规则（指令集）模拟图灵机，则该机器是图灵完备的（即通用计算机）。

## 六、课后习题重点与考试常考题型

### 简答题：冯诺依曼计算机的主要特点（必背！）

标准答案要点：
1. **存储程序**：程序和数据以二进制形式存储在存储器中
2. **按地址顺序执行**：指令按地址顺序自动取出执行
3. **五大部件组成**：运算器、控制器、存储器、输入设备、输出设备
4. **以运算器为中心**（注意：这是传统冯诺依曼机的特点，现代计算机已改为以存储器为中心）

### 判断题常见考点

| 判断 | 题目 | 答案 |
|------|------|------|
| ✅ | 冯诺依曼计算机的核心思想是存储程序 | 正确 |
| ✅ | 现代计算机以存储器为中心 | 正确 |
| ❌ | 冯诺依曼计算机以存储器为中心 | 错误（传统冯诺依曼机以运算器为中心） |
| ✅ | 指令和数据都以二进制形式存储 | 正确 |
| ❌ | 指令和数据存放在不同的存储器中 | 错误（冯诺依曼机是统一存储） |
| ✅ | 控制器能区分指令字和数据字 | 正确 |

### 填空题常见考点

1. 冯诺依曼计算机由五大部件组成：**运算器、控制器、存储器、输入设备、输出设备**。
2. 冯诺依曼计算机的核心思想是**存储程序**。
3. 控制器的基本任务是**取指令、指令译码、执行指令**。
4. 运算器执行**算术运算**和**逻辑运算**。

## 考试常考题型

> [!faq] 冯诺依曼型计算机的五大基本部件包括？</br>A. 运算器、控制器、存储器、输入设备、输出设备</br>B. CPU、内存、硬盘、键盘、显示器</br>C. 运算器、控制器、存储器、I/O接口、总线</br>D. CPU、存储器、输入设备、输出设备、电源
> A。冯诺依曼体系结构规定计算机由运算器、控制器、存储器、输入设备和输出设备五大部件组成。注意B选项中的硬盘和显示器属于具体设备而非基本部件分类，D选项的电源不属于五大部件，C选项的I/O接口和总线是现代计算机的扩展概念。

> [!faq] 什么是存储程序概念？它对计算机体系结构有什么影响？
> 存储程序概念是冯诺依曼体系结构的核心思想，指将程序（指令序列）和数据预先存入存储器中，计算机在工作时自动按顺序从存储器中取出指令并执行。其影响包括：(1)确立了"程序和数据同等地位"的原则；(2)使计算机能够自动、连续地工作；(3)奠定了现代计算机的基本结构——存储程序式计算机（冯诺依曼机）。

> [!faq] 冯诺依曼计算机的主要特点是什么？（简答题）
> 冯诺依曼计算机的主要特点包括：(1)存储程序：程序和数据以二进制形式存储在存储器中；(2)按地址顺序执行：指令按地址顺序自动取出执行；(3)五大部件组成：运算器、控制器、存储器、输入设备、输出设备；(4)以运算器为中心（注意：这是传统冯诺依曼机的特点，现代计算机已改为以存储器为中心）。

> [!faq] 控制器如何区分指令字和数据字？
> 控制器完全可以区分指令字和数据字。一般来讲，在取指周期中从内存读出的信息流是**指令流**，它流向控制器；而在执行周期中从内存读出的信息流是**数据流**，它由内存流向运算器。虽然指令和数据都以二进制形式存储，形态上没有区别，但控制器根据所处的工作周期（取指周期或执行周期）来区分它们。

> [!faq] 关于冯诺依曼计算机的判断题：</br>（1）冯诺依曼计算机的核心思想是存储程序。</br>（2）现代计算机以运算器为中心。</br>（3）指令和数据都存放在存储器中。</br>（4）指令和数据存放在不同的存储器中。
> (1)正确——存储程序是冯诺依曼结构的核心；(2)错误——现代计算机以存储器为中心，传统冯诺依曼机以运算器为中心；(3)正确——指令和数据都以二进制形式存储在同一存储器；(4)错误——冯诺依曼结构是统一存储，哈佛结构才是分开存储。

> [!faq] 指令的基本形式是什么？各部分的作用是什么？
> 指令由操作码和地址码两部分组成。操作码指出指令所进行的操作性质（如加、减、乘、除、取数、存数等），地址码表示参加运算的数据应从存储器的哪个单元中取来，或运算结果应存到哪个单元中去。指令的操作码和地址码都用二进制代码表示。

> [!faq] 运算器的主要功能是什么？运算器长度有哪些常见值？
> 运算器的主要功能是进行算术运算（加、减、乘、除）和逻辑运算，因此通常称为ALU（算术逻辑运算部件）。在计算机中参与运算的数是二进制的。运算器的长度一般是8位、16位、32位或64位，长度越长表示计算精度越高。
