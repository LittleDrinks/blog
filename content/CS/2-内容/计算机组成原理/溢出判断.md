# 溢出判断

> [!important] 概述
> 溢出判断是补码加减运算的关键考点，约占3-5分。必须掌握三种判断方法。

## 溢出概念

**溢出**：运算结果超出机器所能表示的范围。

### 溢出类型

- **正溢**：两正数相加，结果变为负数（超过最大正数）
- **负溢**：两负数相加，结果变为正数（小于最小负数）

> [!note] 注意
> 只有**同符号数相加**才可能溢出。异符号数相加不可能溢出。

---

## 三种溢出判断方法

### 方法一：单符号位判断法

**判断规则**：
- 正 + 正 = 负 → 正溢出
- 负 + 负 = 正 → 负溢出

**表达式**：
```
V = Xs · Ys · Ss' + Xs' · Ys' · Ss
```
其中Xs、Ys为操作数符号位，Ss为结果符号位，'表示取反。

> [!tip] 简单记忆
> "同号相加结果变号"即为溢出。

### 方法二：双符号位判断法（变形补码）⭐推荐方法

**变形补码格式**：
- 正数：**00**.xxxx...
- 负数：**11**.xxxx...

**判断规则**：

| 双符号位 | 状态 | 说明 |
|----------|------|------|
| 00 | 正数，无溢出 | 结果为正数 |
| 01 | **正溢出** | 两正数相加结果超出范围 |
| 10 | **负溢出** | 两负数相加结果超出范围 |
| 11 | 负数，无溢出 | 结果为负数 |

**溢出判断表达式**：
```
V = Sf1 ⊕ Sf2（异或门实现）
```

> [!tip] 记忆技巧
> 双符号位**相同**（00或11）表示无溢出，**不同**（01或10）表示溢出。

### 方法三：进位判断法

**定义**：
- Cf：符号位产生的进位
- C0：最高数值位产生的进位

**判断规则**：

| Cf | C0 | 状态 | 说明 |
|----|----|----|------|
| 0 | 0 | 正数，正确 | 无溢出 |
| 0 | 1 | **正溢** | 正数相加产生进位到符号位 |
| 1 | 0 | **负溢** | 负数相加进位丢失 |
| 1 | 1 | 负数，正确 | 无溢出 |

**溢出判断表达式**：
```
V = Cf ⊕ C0
```

> [!tip] 记忆技巧
> Cf和C0**相同**表示无溢出，**不同**表示溢出。

## 溢出判断例题

### 例题1：正溢出判断

**已知**：x = +1101，y = +1001，求 x + y 并判断溢出

**解**：
- [x]补 = **001101**（双符号位）
- [y]补 = **001001**
- 计算：
```
    001101   [x]补
  + 001001   [y]补
  ──────────
    010110   [x+y]补
```
- 双符号位为 **01**，发生**正溢出**！

> [!note] 分析
> 两正数相加，结果符号位变成01（表示负数），这就是正溢出。实际结果 +1101 + +1001 = +10110（22），超出了5位补码的表示范围 -16~+15。

### 例题2：负溢出判断

**已知**：x = -1101，y = -1011，求 x + y 并判断溢出

**解**：
- [x]补 = **110011**（双符号位）
- [y]补 = **110101**
- 计算：
```
    110011   [x]补
  + 110101   [y]补
  ──────────
   1101000   [x+y]补
```
- 抛弃最高进位后得：**101000**
- 双符号位为 **10**，发生**负溢出**！

### 例题3：无溢出情况

**已知**：x = +1011，y = +0101，求 x + y 并判断溢出

**解**：
- [x]补 = **001011**（双符号位）
- [y]补 = **000101**
- 计算：
```
    001011   [x]补
  + 000101   [y]补
  ──────────
    001110   [x+y]补
```
- 双符号位为 **00**，无溢出

## 进位判断法详解

### 进位分析例题

**已知**：用进位判断法分析x + y的溢出情况

**例：正溢出**
- x = +1101，y = +1001
- 计算：
```
    001101   [x]补
  + 001001   [y]补
  ──────────
    010110
```
- 最高数值位相加：1 + 1 = 10 → C0 = 1（有进位）
- 符号位相加：0 + 0 + 1(来自C0) = 01 → Cf = 0（无进位）
- V = Cf ⊕ C0 = 0 ⊕ 1 = **1** → 溢出！

**例：负溢出**
- x = -1101，y = -1011
- 计算：
```
    110011   [x]补
  + 110101   [y]补
  ──────────
   1101000
```
- 最高数值位相加：0 + 0 = 0 → C0 = 0（无进位）
- 符号位相加：1 + 1 = 10 → Cf = 1（有进位）
- V = Cf ⊕ C0 = 1 ⊕ 0 = **1** → 溢出！

## CF与OF的区别

在标志寄存器中：

| 标志 | 名称 | 含义 |
|------|------|------|
| CF | 进位标志 | 无符号数运算的进位/借位 |
| OF | 溢出标志 | 有符号数运算溢出 |

> [!warning] 易错点
> 同一个运算结果，CF和OF可能不同！

**例题**：8位运算 127 + 1 = 128

```
01111111 + 00000001 = 10000000
```
- CF = 0（无符号位进位，无符号数结果128正确）
- OF = 1（有符号数：127 + 1 = -128，溢出！）

## 考试真题精选

> [!faq] 标志寄存器中CF和OF的区别是什么？
> CF（进位标志）：表示无符号数运算的最高位进位/借位，用于判断无符号数溢出。OF（溢出标志）：表示有符号数运算的溢出（结果超出有符号数表示范围），可通过V=Cf⊕C0判断。同一个运算结果，CF和OF可能不同：如8位运算127+1=128，CF=0（无进位），OF=1（有符号溢出）。

> [!faq] 溢出判断的三种方法是什么？哪种最常用？
> 三种方法：①单符号位判断法（同号相加结果变号）②双符号位判断法（变形补码，V=Sf1⊕Sf2）③进位判断法（V=Cf⊕C0）。最常用的是双符号位判断法，因为容易实现且判断直观。

> [!faq] 用双符号位补码计算x+y并判断溢出，其中x=-1100，y=-1000。
> [x]补=110100，[y]补=111000。计算：110100+111000=101100。双符号位为10，发生负溢出。
