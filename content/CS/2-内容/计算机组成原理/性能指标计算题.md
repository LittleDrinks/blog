# 性能指标计算题（第1章重点）

> [!tip]
> **期末提示**：第1章性能指标计算是必考题型，请重点掌握 Amdahl 定律和 CPI 计算。

---

## 核心公式（必背）

```
时钟周期 T = 1 / 主频 f

CPU执行时间 = 指令数(IC) × CPI × 时钟周期(T)
           = IC × CPI / 主频(f)

CPI = 总时钟周期数 / 指令数(IC)
    = Σ(CPI_i × I_i) / IC    （按指令类加权）

MIPS = 主频(f) / (CPI × 10⁶)
     = 指令数(IC) / (执行时间 × 10⁶)

MFLOPS = 浮点操作次数 / (执行时间 × 10⁶)
```

## Amdahl定律公式

```
系统加速比 Sp = 1 / [(1 - Fe) + (Fe / Se)]

Fe = 可改进部分占原执行时间的比例
Se = 可改进部分的加速倍数
```

> [!warning]
> **关键理解**：Fe是"**执行时间占比**"，不是指令数占比！如果题目给指令比例和CPI，需要先算执行时间比例。

---

### 例题1：Amdahl定律基础应用（必考类型）

**题目：**
> 设系统中某部件的处理时间占整个运行时间的40%，如果将该部件的处理速度加快到10倍，则采用加快措施后能使整个系统的性能提高多少？

**解答：**

已知：
- Fe = 0.4（可改进部分占原执行时间40%）
- Se = 10（部件加速10倍）

代入 Amdahl 定律：
```
          1                    1              1
Sp = ───────────── = ───────────────── = ─────── ≈ 1.56
     (1-0.4)+(0.4/10)   0.6 + 0.04        0.64
```

**答**：整个系统性能提高约 **1.56倍**（即56%）

> [!tip]
> **核心启示**：即使部件加速10倍，但因只占40%时间，整体仅加速约1.56倍。这就是Amdahl定律的残酷！

---

### 例题2：Amdahl定律方案比较（常考类型）

**题目：**
> 设浮点开平方根FPSQR操作占整个测试程序执行时间的20%。
> - 方案A：用硬件实现FPSQR，使其速度加快到10倍
> - 方案B：使所有浮点数指令FP速度加快到2倍，FP指令占整个程序执行时间50%
> 比较两种方案优劣。

**解答：**

**方案A（仅优化FPSQR）**：
```
Fe = 0.2, Se = 10

Sp_A = 1 / [(1-0.2) + (0.2/10)]
     = 1 / [0.8 + 0.02]
     = 1 / 0.82
     ≈ 1.22
```

**方案B（优化所有FP指令）**：
```
Fe = 0.5, Se = 2

Sp_B = 1 / [(1-0.5) + (0.5/2)]
     = 1 / [0.5 + 0.25]
     = 1 / 0.75
     ≈ 1.33
```

**比较**：Sp_B (1.33) > Sp_A (1.22)

**答**：**方案B更优**。虽然FPSQR加速倍数高（10倍），但只占20%时间；FP指令只加速2倍但占50%时间，整体效果更好。

> [!warning]
> **核心结论**：Amdahl定律中，**Fe（占比）往往比Se（加速倍数）更重要**！优先优化占比大的部分。

### 例题3：CPI综合计算

**题目：**
> 某程序中浮点操作FP的比例为25%，FP的CPI为4；其他指令的CPI为1.33。
> 浮点开平方根FPSQR比例为2%，FPSQR的CPI为20。
> 两种方案：
> - 方案1：把FPSQR的CPI减至2
> - 方案2：把所有FP操作的CPI均减至2
> 分析两种方案优劣。

**解答：**

**原CPI计算**：
```
FPSQR属于FP的一部分，拆分计算：
- FPSQR: 2%, CPI=20 → 贡献 0.02×20 = 0.4
- 其他FP: 23%, CPI=4 → 贡献 0.23×4 = 0.92
- 非FP: 75%, CPI=1.33 → 贡献 0.75×1.33 = 0.9975

CPI_原 = 0.4 + 0.92 + 0.9975 = 2.3175
```

**方案1（FPSQR CPI降至2）**：
```
CPI_1 = 0.02×2 + 0.23×4 + 0.75×1.33
      = 0.04 + 0.92 + 0.9975
      = 1.9575

改进比例 = (2.3175 - 1.9575) / 2.3175 ≈ 15.5%
```

**方案2（所有FP CPI降至2）**：
```
CPI_2 = 0.25×2 + 0.75×1.33
      = 0.5 + 0.9975
      = 1.4975

改进比例 = (2.3175 - 1.4975) / 2.3175 ≈ 35.3%
```

**答**：**方案2更优**，CPI降幅更大（35.3% vs 15.5%）。

### 例题4：两台机器性能对比

**题目：**
> 两台机器A和B执行同一程序：
> - 机器A：指令数10⁸条，CPI=2，主频800MHz
> - 机器B：指令数8×10⁷条，CPI=3，主频1GHz
> 哪台更快？

**解答：**

```
机器A执行时间：
t_A = IC_A × CPI_A / f_A
    = 10⁸ × 2 / (800×10⁶)
    = 10⁸ × 2 / 8×10⁸
    = 0.25秒

机器B执行时间：
t_B = IC_B × CPI_B / f_B
    = 8×10⁷ × 3 / (1×10⁹)
    = 2.4×10⁸ / 10⁹
    = 0.24秒
```

**答**：机器B更快（0.24秒 < 0.25秒），虽然机器A指令数多但CPI低。

### 例题5：MIPS计算

**题目：**
> 计算Pentium IV 2GHz处理机的指令执行速度。已知IPC=4（或CPI=0.25）。

**解答：**

```
f = 2GHz = 2000MHz

方法一：MIPS = f × IPC = 2000 × 4 = 8000 MIPS = 8 GIPS

方法二：MIPS = f / CPI = 2000 / 0.25 = 8000 MIPS
```

**答**：指令执行速度为 **8000 MIPS** 或 **8 GIPS**。
