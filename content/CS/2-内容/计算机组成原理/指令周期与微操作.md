# 指令周期与微操作

## 指令周期基本概念

### 时间单位层级

| 概念 | 定义 | 说明 |
|------|------|------|
| **指令周期** | CPU从存储器取出一条指令并执行完毕所需的**全部时间** | 不同指令周期可能不同 |
| **CPU周期（机器周期）** | 通常以主存存取周期为基础，完成一个基本操作的时间 | 一个指令周期包含若干CPU周期 |
| **时钟周期（T周期/节拍脉冲）** | 一个CPU周期内细分的更小时间段，是机器主频的倒数 | 最小时间单位 |

**包含关系**：
```
指令周期 > CPU周期（机器周期）> 节拍周期（T周期）> 时钟周期
```

> [!tip]
> 不同指令的指令周期**不一定相同**！因为复杂指令可能需要更多CPU周期。

---

## 指令周期的四种类型（简答题考点！）

| 周期类型 | 功能 | 所有指令是否必经 |
|----------|------|------------------|
| **取指周期** | 从存储器取出指令 | **必经**（所有指令） |
| **间址周期** | 操作数地址需间接寻址时 | **可选**（需访存指令） |
| **执行周期** | 执行指令功能 | **必经**（所有指令） |
| **中断周期** | 响应中断请求 | **可选**（有中断时） |

> [!warning]
> 考试常考：**取指周期和执行周期是所有指令必经阶段**！

## 方框图语言

用于描述指令周期的图形化表示方法。

| 符号 | 含义 | 示例 |
|------|------|------|
| **方框** | 一个CPU周期（机器周期） | 代表取指、执行等阶段 |
| **方框内文字** | 数据通路操作或控制操作 | PC→AR、MDR→IR等 |
| **菱形符号** | 判别或测试（条件分支） | 判断指令类型、是否中断 |
| **~ 波浪线** | 公操作 | 取指等公共操作 |
| **→ 箭头** | 数据传输方向 | 表示数据流向 |

## 取指周期的公共微操作（必背！）

所有指令的取指周期基本相同：

| 步骤 | 微操作 | 说明 |
|------|--------|------|
| 1 | `PC → ABUS(I)` | PC内容送指令地址总线 |
| 2 | 启动读命令 | 从内存读指令 |
| 3 | `IBUS → IR` | 指令通过指令总线装入IR |
| 4 | `PC + 1 → PC` | PC自动加1，为取下条指令做准备 |
| 5 | `IR(OP) → ID` | 操作码送译码器译码 |
| 6 | CPU识别指令类型 | 取指周期结束 |

> [!tip]
> 取指周期是**公共操作**，所有指令都必须经过这个阶段。

## 典型指令的微操作序列

> [!warning]
> 微操作序列是**简答题和综合题高频考点**，需要能够完整写出各指令的微操作流程！

### MOV 指令（R1 → R0）

**取指周期**：同上公共操作。

**执行周期**：
1. 选择 R1 为源寄存器，R0 为目标寄存器
2. ALU 做传送操作
3. 打开 ALU 输出三态门，结果送 DBUS
4. `DBUS → DR`
5. `DR → R0`

### LAD 指令（从内存取数 → R1）

**取指周期**：同上。

**执行周期**：
1. 从指令中取出地址码送 AR
2. 启动读命令，从数据存储器读数据
3. `DBUS → DR`
4. `DR → R1`

### ADD 指令（R1 + R2 → R1）

- **第1个CPU周期**：取ADD指令
- **第2个CPU周期**：执行加法运算

**执行周期**：
1. 选择 R1、R2 送 ALU
2. ALU 执行加法运算
3. 运算结果经 ALU 输出门送 DBUS
4. `DBUS → DR`
5. `DR → R1`，并更新 PSW

### STO 指令（R2 → 内存（R3））

1. 选择 R3 送 AR（R3中存放的是内存地址）
2. 选择 R2 送 DR（R2中存放的是要写入的数据）
3. 启动写命令，`DR → 数存`

### JMP 指令（跳转）

1. 从指令地址码字段取出转移目标地址
2. 目标地址 → PC
3. 程序跳转执行

> [!tip]
> **记忆技巧**：
> - MOV：寄存器之间搬数据
> - LAD：从内存 Load 数据到寄存器
> - ADD：ALU 运算后写回寄存器
> - STO：从寄存器 Store 数据到内存
> - JMP：修改 PC 实现跳转

## 微操作序列完整例题（必考计算题！）

### 例题：写出ADD R1, R2指令的完整微操作序列

**题目**：假设模型机采用双总线结构，写出ADD R1, R2指令（将R1和R2内容相加，结果存入R1）的完整微操作序列。

**解答**：

#### 取指周期（M1，公共操作）

| 节拍 | 微操作 | 控制信号 |
|------|--------|----------|
| T1 | `PC → AR` | PCout, ARin |
| T2 | `AR → ABUS, Read` | ARout, MemRead |
| T3 | `MDR → IR` | MDRout, IRin |
| T4 | `PC + 1 → PC` | PC+1, PCin |
| T5 | `IR(OP) → ID` | 指令译码 |

#### 执行周期（M2）

| 节拍 | 微操作 | 控制信号 |
|------|--------|----------|
| T1 | `R1 → Y`（暂存器） | R1out, Yin |
| T2 | `R2 → ALU.X` | R2out, ALU操作：ADD |
| T3 | `ALU → Z`（暂存结果） | ALUout, Zin |
| T4 | `Z → R1` | Zout, R1in |
| T5 | 更新PSW标志位 | PSW更新 |

### 例题：写出STA (R3), R2指令的完整微操作序列

**题目**：写出将R2内容存入R3所指内存单元的微操作序列。

**解答**：

#### 取指周期（M1）

与ADD指令相同，为公共操作。

#### 执行周期（M2）

| 节拍 | 微操作 | 控制信号 |
|------|--------|----------|
| T1 | `R3 → AR` | R3out, ARin |
| T2 | `AR → ABUS` | ARout, 地址准备 |
| T3 | `R2 → MDR` | R2out, MDRin |
| T4 | `Write Memory` | MemWrite, MDR→存储器 |
| T5 | 写操作完成 | 等待写完成信号 |

### 例题：写出JMP 200指令的微操作序列

**解答**：

#### 取指周期（M1）

与上述取指周期相同。

#### 执行周期（M2）

| 节拍 | 微操作 | 控制信号 |
|------|--------|----------|
| T1 | `IR(Addr) → PC` | IR地址字段直接送PC |
| T2 | 取指周期准备 | 进入下一条指令取指 |

> [!tip]
> **关键点**：JMP指令**不需要访问存储器**，直接将指令中的地址码送入PC即可。

## 本章考试常见题型

### 一、选择题

> [!faq] 一个指令周期最少包含多少个CPU周期？</br>A. 1个</br>B. 2个</br>C. 3个</br>D. 4个
> B。一条指令的取出阶段（取指周期）需要一个CPU周期，执行阶段最少也需要一个CPU周期。所以**最少需要2个CPU周期**。复杂指令可能需要更多CPU周期。

> [!faq] 指令周期的四种类型中，哪些是所有指令必经的？</br>A. 取指周期和间址周期</br>B. 取指周期和执行周期</br>C. 执行周期和中断周期</br>D. 间址周期和中断周期
> B。**取指周期和执行周期**是所有指令必经阶段。间址周期只有需要间接寻址的指令才经过；中断周期只有响应中断时才经过。

### 二、简答题

> [!faq] 说明指令周期、机器周期（CPU周期）、时钟周期之间的关系。
> **指令周期**是CPU取出并执行一条指令的全部时间。**机器周期（CPU周期）**是完成一个基本操作的时间，通常以主存存取周期为基准。**时钟周期**是机器主频的倒数，是最小时间单位。关系：指令周期 >= 机器周期 >= 时钟周期。不同指令的指令周期可能不同。

> [!faq] 写出取指周期的公共微操作序列。
> 取指周期公共微操作：(1)PC→ABUS(I)，将PC内容送指令地址总线；(2)启动读命令，从存储器读指令；(3)IBUS→IR，指令送入指令寄存器；(4)PC+1→PC，程序计数器加1；(5)IR(OP)→ID，操作码送译码器译码；(6)CPU识别指令类型，取指周期结束。

> [!faq] 方框图语言中各符号的含义是什么？
> 方框图语言符号含义：(1)**方框**代表一个CPU周期（机器周期）；(2)**方框内文字**表示数据通路操作或控制操作；(3)**菱形符号**表示判别或测试（条件分支）；(4)**~波浪线**表示公操作（如取指等公共操作）；(5)**→箭头**表示数据传输方向。

### 三、综合题

> [!faq] 写出执行指令"SUB R1, R2"（R1-R2→R1）的完整微操作序列，包括取指周期和执行周期。
> **取指周期(M1)**：T1: PC→AR；T2: AR→ABUS, Read；T3: MDR→IR；T4: PC+1；T5: IR(OP)→ID译码。**执行周期(M2)**：T1: R1→ALU.X（暂存器）；T2: R2→ALU.Y，ALU执行减法；T3: ALU→Z（暂存结果）；T4: Z→R1，更新PSW标志位。执行完成后回到取指周期取下一条指令。
