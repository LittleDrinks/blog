# CISC与RISC对比

## CISC（Complex Instruction Set Computer）

### 特点
- **指令系统庞大**：数百条指令
- **指令长度可变**：复杂编码，1~12字节不等
- **寻址方式多样**：多种复杂的寻址方式
- **微程序控制**：大多数指令采用微程序实现
- **专用寄存器**：功能各异的专用寄存器

### 代表
- Intel x86系列
- IBM System/360

### 优点
- 代码密度高，节省存储空间
- 编译器设计相对简单
- 向后兼容性好

### 缺点
- 硬件复杂度高
- 研制周期长
- 部分复杂指令使用频率低

## RISC（Reduced Instruction Set Computer）

### 特点
- **指令数量精简**：通常几十条基本指令
- **指令长度固定**：简化译码
- **寻址方式简单**：少量常用寻址方式
- **硬布线控制**：大多数指令单周期执行
- **通用寄存器**：大量通用寄存器
- **Load/Store结构**：只有Load/Store指令访问内存

### 代表
- ARM
- MIPS
- RISC-V
- PowerPC

### 优点
- 硬件设计简单
- 执行速度快
- 功耗低
- 便于流水线实现

### 缺点
- 代码密度相对较低
- 编译器优化要求高

## 80/20 规律

CISC 指令系统中存在一个非常重要的统计规律：

> **约 20% 的指令使用频率很高，占据了 80% 的处理机时间；而有 80% 的不常用指令只占用处理机的 20% 时间。**

**这个规律直接催生了 RISC 的诞生**：
- 既然 80% 的时间只执行 20% 的指令，那何不把这 20% 的常用指令优化到极致？
- 去掉那些复杂但不常用的指令，用简单指令的组合来实现它们的功能
- 这样可以使硬件设计大大简化，同时提高整体执行效率

## RISC 的七大特点（背诵重点）

1. **简单而统一格式的指令译码**
   - 指令长度固定，格式规整，译码电路简单

2. **大部分指令可以单周期执行**
   - 指令简单，配合硬布线控制，绝大多数指令在一个时钟周期内完成

3. **只有 LOAD/STORE 可以访问存储器**
   - 运算类指令的操作数只能来自寄存器，结果也只能送回寄存器

4. **简单的寻址方式**
   - 只保留最常用的几种寻址方式，减少地址计算时间

5. **采用延迟转移技术**
   - 在转移指令后面插入一条必然执行的指令，避免流水线断流

6. **采用 LOAD 延迟技术**
   - LOAD 指令取数需要一定时间，后面插入不相关指令避免数据冒险

7. **三地址指令格式 + 较多的通用寄存器 + 对称的指令格式**
   - 寄存器数量多（通常 32 个以上），减少访存次数
   - 三地址格式不破坏源操作数

> [!tip] 七大特点记忆口诀
> **"译码简、单周期、LoadStore访存、寻址简、延迟转、延迟取、三地址多寄存器"**

## CISC vs RISC 详细对比表（必背）

| 特性 | CISC | RISC |
|------|------|------|
| **英文全称** | Complex Instruction Set Computer | Reduced Instruction Set Computer |
| **中文名称** | 复杂指令系统计算机 | 精简指令系统计算机 |
| **核心思想** | 用复杂硬件实现复杂功能 | 用简单指令的高频组合替代复杂指令 |
| **指令数量** | 200~300 条，甚至更多 | 几十条基本指令 |
| **指令长度** | 可变（如 x86：1~12 字节） | 固定（如 MIPS：32 位） |
| **执行周期** | 多变，复杂指令需多个周期 | 单周期为主 |
| **寻址方式** | 复杂多样（十几种） | 简单少量（3~5 种） |
| **控制方式** | 微程序控制（控制存储器） | 硬布线控制（组合逻辑） |
| **寄存器数量** | 较少（多为专用寄存器） | 较多（大量通用寄存器，32+） |
| **访存指令** | 多种指令都可访问内存 | 只有 Load/Store 访问内存 |
| **流水线实现** | 较难 | 容易 |
| **代码密度** | 高 | 相对较低 |
| **功耗** | 较高 | 较低 |
| **设计周期** | 长 | 短 |
| **VLSI 友好度** | 不友好（控制逻辑不规整） | 友好（结构规整） |
| **典型应用** | 桌面 PC、服务器（x86） | 嵌入式、移动设备（ARM、MIPS） |

> [!warning] 考试高频考点
> 以下对比项是选择题和简答题的必考内容：
> - **指令长度**：CISC 可变，RISC 固定
> - **访存指令**：RISC 只有 Load/Store
> - **控制方式**：CISC 微程序，RISC 硬布线
> - **寄存器**：RISC 通用寄存器数量多

## 现代发展趋势

### CISC向RISC借鉴
- Intel处理器内部将x86指令翻译成类RISC微操作（微操作技术）
- 采用超标量、超流水线技术
- 引入大量通用寄存器
- 简化部分复杂指令

### RISC向CISC借鉴
- 增加一些常用复杂指令（如乘法、浮点运算）
- 提高代码密度（如ARM Thumb指令集、RISC-V压缩指令集）
- 增强功能多样性

### 现代CPU的实际架构

> [!tip] 核心趋势：外部CISC、内部RISC
> 现代 CPU 设计呈现 "**外部 CISC、内部 RISC**" 的趋势：
> - **外部**：保持x86等CISC指令集的软件兼容性
> - **内部**：将复杂指令翻译成简单微操作，用RISC方式执行
>
> 这样兼顾了软件兼容性和硬件执行效率。

**Intel x86的内部实现**：
```
x86指令（CISC）
    ↓ 翻译器
微操作（类RISC）
    ↓ 执行单元
RISC式执行
```

### 代表性架构对比

| 架构 | 类型 | 应用领域 | 特点 |
|------|------|----------|------|
| x86-64 | CISC | 桌面PC、服务器 | 软件兼容性好，内部微操作 |
| ARM | RISC | 移动设备、嵌入式 | 功耗低，市场占有率最高 |
| MIPS | RISC | 嵌入式、路由器 | 结构简单，学术研究常用 |
| RISC-V | RISC | 各领域（开源） | 开源免费，可扩展性强 |
| PowerPC | RISC | 嵌入式、游戏机 | IBM架构，工业应用 |

## 实际指令系统对比实例

### Pentium（CISC）指令系统

- **指令数量**：191条指令
- **寻址方式**：9种
- **指令长度**：可变，1-12字节
- **特点**：
  - 操作码长度固定，但指令整体长度可变
  - 支持复杂寻址方式组合
  - 典型CISC结构

**Pentium寻址方式示例**：
| 序号 | 寻址方式 | 有效地址算法 |
|------|----------|--------------|
| 1 | 立即寻址 | 操作数=A |
| 2 | 寄存器寻址 | EA=R |
| 3 | 偏移量寻址 | EA=A |
| 4 | 基址寻址 | EA=(B) |
| 5 | 基址+偏移量 | EA=(B)+A |
| 6 | 比例变址+偏移量 | EA=(I)×S+A |
| 7 | 基址+变址+偏移 | EA=(B)+(I)+A |
| 8 | 基址+比例变址+偏移量 | EA=(B)+(I)×S+A |
| 9 | 相对寻址 | EA=(PC)+A |

### MIPS R4000（RISC）指令系统

- **指令数量**：55条基本指令
- **寻址方式**：3种
- **指令长度**：固定32位
- **通用寄存器**：32个
- **特点**：
  - 指令格式规整（R型、I型、J型）
  - 只有Load/Store访问内存
  - 典型RISC结构

**MIPS指令格式**：
| 类型 | 格式 | 字段说明 |
|------|------|----------|
| R型 | OP rs rt rd shamt funct | 寄存器运算 |
| I型 | OP rs rt address | 立即数/访存 |
| J型 | OP target | 跳转 |

**MIPS汇编示例**：
```
add $s1, $s2, $s3    ; $s1 = $s2 + $s3
lw $s1, 100($s2)     ; $s1 = Memory[$s2+100]
sw $s1, 100($s2)     ; Memory[$s2+100] = $s1
```

### ARM（RISC）指令系统

- **字长**：32位
- **寄存器**：16个（r0-r12, sp, lr, pc）
- **特点**：
  - 支持条件执行（每条指令可带条件码）
  - 三地址指令格式
  - Thumb指令集（16位压缩指令）

**ARM汇编示例**：
| 指令类别 | 指令 | 示例 | 含义 |
|----------|------|------|------|
| 算术运算 | ADD | ADD r1,r2,r3 | r1=r2+r3 |
| 数据传送 | LDR | LDR r5,[r3,#120] | r5=Memory[r3+120] |
| 条件转移 | BEQ | BEQ 25 | 若相等则转移 |

## RISC性能优势的理论分析

### 程序执行时间公式

计算机执行程序的时间 P 可表示为：
$$P = I \times C \times T$$

其中：
- **I**：机器指令数（程序编译后的指令总数）
- **C**：每条指令的平均机器周期数（CPI）
- **T**：每个机器周期的执行时间

### RISC与CISC性能对比

| 参数 | RISC | CISC |
|------|------|------|
| I（指令数） | 1.2-1.4倍 | 1倍（基准） |
| C（CPI） | 1.3-1.7周期 | 4-6周期 |
| T（周期时间） | <1倍（更短） | 1倍（基准） |

**分析**：
- RISC的I较大（简单指令需要更多条）
- RISC的C很小（单周期执行）
- RISC的T很小（周期时间短）

综合计算：
$$P_{RISC} = (1.2 \sim 1.4) \times (1.3 \sim 1.7) \times (<1) \approx 1.5 \sim 2.4$$
$$P_{CISC} = 1 \times (4 \sim 6) \times 1 = 4 \sim 6$$

> [!tip] 结论
> 虽然RISC程序指令数更多，但由于CPI小、周期时间短，整体执行时间反而更短。这就是RISC性能优势的理论基础。
