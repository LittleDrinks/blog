# 时序产生器

## 时序产生器的作用

时序产生器是 CPU 控制器的重要组成部分，主要作用有：

1. **指挥机器工作**：CPU 中的控制器用时序信号指挥机器工作
2. **约束 CPU 动作**：一个 CPU 周期中，时钟脉冲对 CPU 的动作有严格约束
3. **区分指令和数据**：CPU 用时序信号/周期信息来辨认从内存中取出的是**指令**（取指周期）还是**数据**（执行周期）
4. **时空函数**：操作控制器发出的各种信号是**时间**（时序信号）和**空间**（部件操作信号）的函数

---

## 电位-脉冲制

计算机硬件的器件特性决定了时序信号的基本体制是 **电位—脉冲制**。

以 D 触发器为例：
- **D 端**：电位输入端
- **CP（Clock Pulse）端**：脉冲输入端

**特性方程**：
- `D = 0` 时，CP 上升沿到来，触发器状态置 0
- `D = 1` 时，CP 上升沿到来，触发器状态置 1

也就是说，**电位信号决定状态，脉冲信号决定状态翻转的时刻**。

> [!tip]
> 简单记：**电位定"做什么"，脉冲定"什么时候做"**。

### D 触发器示例详解

```
        ┌────────────┐
   D ───┤            │
        │   D触发器   ├─── Q（输出）
  CP ───┤            │
        └────────────┘
```

**工作过程**：

| D 端状态 | CP 信号 | 结果 |
|----------|---------|------|
| D = 0 | CP 上升沿到来 | Q = 0（触发器置 0） |
| D = 1 | CP 上升沿到来 | Q = 1（触发器置 1） |
| D = 0 或 1 | CP 未到来 | Q 保持原状态 |

**关键要求**：
- 电位信号（D 端）必须在脉冲信号（CP 端）到来**之前**稳定建立
- 否则打入寄存器的数据可能不可靠

### 应用场景

| 应用场景 | 电位信号 | 脉冲信号 |
|----------|----------|----------|
| 寄存器数据传送 | 数据本身 | 打入控制信号 |
| ALU 运算结果写入 | 运算结果 | 写入脉冲 |
| 存储器读/写 | 地址/数据 | 读/写命令脉冲 |

> [!tip]
> ALU 本身只用电位信号工作，但运算结果最终要送入寄存器，所以还是需要脉冲信号配合。

## 时序信号产生器的四大组成部分

时序信号产生器由以下四部分构成：

### 1. 时钟源（Clock Source）

**功能**：提供频率稳定且电平匹配的方波时钟脉冲信号。

**组成**：通常由**石英晶体振荡器**和与非门组成的正反馈振荡电路构成。

**特点**：
- 频率稳定（石英晶体的物理特性决定）
- 输出为方波信号，电平匹配 TTL/CMOS 标准
- 输出送至环形脉冲发生器

> [!tip]
> 时钟源的频率决定了机器的**主频**，例如 10MHz 的时钟源意味着机器主频为 10MHz。

### 2. 环形脉冲发生器（Ring Pulse Generator）

**功能**：产生一组有序的、间隔相等或不等的脉冲序列。

**实现方式**：

| 实现方式 | 说明 |
|----------|------|
| **移位寄存器型** | 使用移位寄存器循环移位产生环形脉冲 |
| **计数器+译码器型** | 计数器计数，译码器输出对应脉冲信号 |

**工作原理**：
- 输入：时钟源的方波信号
- 输出：一组环形脉冲信号（如 1T°～4T°）
- 特点：脉冲按固定顺序循环出现

> [!warning]
> 环形脉冲发生器的输出是**原始脉冲信号**，需要经过启停控制逻辑才能成为 CPU 使用的有效时序信号。

### 3. 节拍脉冲和读写时序译码逻辑

**功能**：将环形脉冲译码为各种时序信号，包括节拍脉冲和存储器读/写时序。

**输出信号**：

| 信号类型 | 符号 | 功能 |
|----------|------|------|
| **节拍脉冲** | T1～T4 | 划分一个 CPU 周期内的各个时间段 |
| **读命令时序** | RD° | 存储器读操作定时 |
| **写命令时序** | WE° | 存储器写操作定时 |

**节拍脉冲时序关系**（假设一个 CPU 周期为 800ns）：

```
时间轴: 0ns    200ns   400ns   600ns   800ns
        ├───────┼───────┼───────┼───────┤
T1:     ├───────┤
T2:             ├───────┤
T3:                     ├───────┤
T4:                             ├───────┤
        ↑       ↑       ↑       ↑
        上升沿   上升沿   上升沿   上升沿
```

> [!tip]
> 每个节拍脉冲宽度为 200ns，一个 CPU 周期包含 4 个节拍脉冲，共 800ns。

### 4. 启停控制逻辑（Start/Stop Control Logic）

**功能**：控制时序电路的启动和停止，确保发出的脉冲都是完整的。

**核心部件**：**运行标志触发器 Cr**

| 状态 | 效果 |
|------|------|
| **Cr = 1** | 原始脉冲 1T°～4T° 通过门电路输出为 T1～T4 |
| **Cr = 0** | 关闭时序产生器，无输出 |

**设计要点**：

1. **启动要求**：必须从第 1 个节拍脉冲（T1）的**前沿**开始工作
2. **停机要求**：必须在第 4 个节拍脉冲（T4）的**后沿**结束之后关闭
3. **目的**：确保发送出去的脉冲都是完整的脉冲

**实现方法**：
- 使用 4T° 信号作为 Cr 触发器的时钟控制端
- 这样可以保证在 T1 前沿开启，在 T4 后沿关闭

> [!warning]
> 启动和停机是随机的，但必须保证脉冲完整性！如果不满足这个要求，可能导致数据丢失或控制错误。

## 三级时序体制 vs 二级时序体制（必背！）

### 硬布线控制器：三级时序体制

**组成**：主状态周期 — 节拍电位 — 节拍脉冲

```
主状态周期（最大时间单位）
    │
    ├── 节拍电位 1（CPU 周期）
    │       │
    │       ├── 节拍脉冲 T1
    │       ├── 节拍脉冲 T2
    │       ├── 节拍脉冲 T3
    │       ├── 节拍脉冲 T4
    │
    ├── 节拍电位 2（CPU 周期）
    │       │
    │       ├── ...
    │
    ├── ...
```

**各层级含义**：

| 层级 | 含义 | 时间单位大小 |
|------|------|-------------|
| **主状态周期** | 包含若干节拍电位，可用触发器状态持续时间表示 | 最大 |
| **节拍电位** | 表示一个 CPU 周期时间 | 较大 |
| **节拍脉冲** | 划分 CPU 周期为若干小时间段 | 最小 |

### 微程序控制器：二级时序体制

**组成**：节拍电位 — 节拍脉冲

```
节拍电位（CPU 周期 = 微指令周期）
    │
    ├── 节拍脉冲 T1
    ├── 节拍脉冲 T2
    ├── 节拍脉冲 T3
    ├── 节拍脉冲 T4
```

**特点**：
- 只有一个节拍电位层级
- 节拍电位时间 = 一个 CPU 周期 = 一个微指令周期
- 节拍脉冲把 CPU 周期划分成几个时间间隔

### 两种体制对比表（考试重点！）

| 对比项 | 硬布线控制器（三级） | 微程序控制器（二级） |
|--------|---------------------|---------------------|
| **层级数** | 3 层 | 2 层 |
| **组成** | 主状态周期-节拍电位-节拍脉冲 | 节拍电位-节拍脉冲 |
| **节拍电位来源** | 时序产生器硬件产生 | 微程序控制器提供 |
| **复杂度** | 较复杂 | 较简单 |
| **灵活性** | 固定 | 可由微指令控制 |
| **设计难度** | 需设计多级时序电路 | 只需设计基本时序 |

> [!warning]
> 考试常考：**硬布线控制器是三级体制，微程序控制器是二级体制**！

## 节拍电位与节拍脉冲的时序关系图

```
节拍电位 M1:
├──────────────────────────────────────────────┤  (800ns)
    │                │                │                │
    T1               T2               T3               T4
    ├──────┤         ├──────┤         ├──────┤         ├──────┤
    200ns            200ns            200ns            200ns
    
读命令 RD°:
├──────────────────────────────────────────────┤  (电位信号，持续整个周期)

写命令 WE°:
                    ├──────┤                          (脉冲信号，T3时刻)
```

> [!tip]
> **电位信号**持续整个节拍电位周期；**脉冲信号**只在特定节拍脉冲时刻有效

## 本章考试常见题型

### 一、选择题

> [!faq] 硬布线控制器中，时序信号采用什么体制？</br>A. 一级体制</br>B. 二级体制</br>C. 三级体制</br>D. 四级体制
> C。硬布线控制器采用**主状态周期-节拍电位-节拍脉冲三级体制**。微程序控制器采用二级体制（节拍电位-节拍脉冲）。这是考试常考的区别点。

> [!faq] 微程序控制器中，节拍电位信号由谁提供？</br>A. 时序产生器</br>B. 微程序控制器</br>C. 主时钟</br>D. 指令译码器
> B。在微程序控制器中，节拍电位信号由**微程序控制器**提供（微指令中包含）。而在硬布线控制器中，节拍电位由时序产生器本身通过逻辑电路产生。

> [!faq] 电位-脉冲制中，电位信号和脉冲信号的关系是？</br>A. 电位信号决定数据，脉冲信号决定时间</br>B. 电位信号决定时间，脉冲信号决定数据</br>C. 两者都决定数据</br>D. 两者都决定时间
> A。**电位信号决定"做什么"（数据内容），脉冲信号决定"什么时候做"（操作时刻）**。例如D触发器中，D端电位决定数据，CP端脉冲决定打入时刻。

### 二、简答题

> [!faq] 简述时序产生器的四大组成部分及其功能。
> 时序产生器由四部分组成：**(1)时钟源**：提供频率稳定的方波时钟信号；(2)**环形脉冲发生器**：产生有序的脉冲序列；(3)**节拍脉冲和读写时序译码逻辑**：将脉冲译码为各种时序信号；(4)**启停控制逻辑**：控制时序电路的启动和停止，确保发出的脉冲完整。

> [!faq] 为什么启动时序产生器必须从T1前沿开始，停机必须在T4后沿结束？
> 这是为了**保证发出的脉冲都是完整的脉冲**。如果启动不是从T1前沿开始，可能产生不完整的T1脉冲；如果停机不是在T4后沿结束后关闭，可能产生不完整的T4脉冲。不完整的脉冲可能导致数据丢失或控制错误。

> [!faq] 比较硬布线控制器和微程序控制器的时序体制。
> 硬布线控制器采用**三级时序体制**（主状态周期-节拍电位-节拍脉冲），节拍电位由时序产生器硬件产生，复杂度高。微程序控制器采用**二级时序体制**（节拍电位-节拍脉冲），节拍电位可由微程序控制器提供（微指令中包含），设计简单。三级体制能处理更复杂的时序需求，二级体制更适合规整的微程序设计。
