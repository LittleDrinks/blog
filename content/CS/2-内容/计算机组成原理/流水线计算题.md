# 流水线计算题

## 核心公式

```
流水线执行n条指令，m个阶段：
- 总时间 = (m + n - 1) × Δt
- 吞吐率 = n / ((m + n - 1) × Δt)
- 加速比 = (n × m × Δt) / ((m + n - 1) × Δt) = n×m / (m+n-1)
- 效率 = 加速比 / m = n / (m + n - 1)
```

---

### 例题1：流水线性能

**题目：**
> 5段流水线，各段时间均为100ns。
> 连续执行100条指令，计算：
> (1) 总时间 (2) 实际吞吐率 (3) 加速比

**解答：**
```
(1) 总时间 = (5 + 100 - 1) × 100ns
          = 104 × 100ns
          = 10400ns
          = 10.4μs

(2) 实际吞吐率 = 100 / 10.4μs
             = 100 / (10.4 × 10⁻⁶)
             ≈ 9.62 × 10⁶ 指令/秒
             ≈ 9.62 MIPS

(3) 加速比 = (100 × 5 × 100ns) / 10400ns
          = 50000 / 10400
          ≈ 4.81
```

---

### 例题2：带阻塞的流水线

**题目：**
> 5段流水线执行10条指令，其中有3条需要停顿2个时钟周期。
> 时钟周期100ns，计算总执行时间。

**解答：**
```
无阻塞时总时间 = (5 + 10 - 1) × 100ns = 1400ns

3条指令各停顿2周期 = 3 × 2 × 100ns = 600ns

总时间 = 1400ns + 600ns = 2000ns = 2μs
```

### 例题3：流水线效率计算

**题目：**
> 某4段流水线，各段时间分别为：100ns、150ns、200ns、100ns。
> 连续执行50条指令，计算：
> (1) 流水线时钟周期 (2) 总执行时间 (3) 流水线效率

**解答：**
```
(1) 流水线时钟周期
    流水线时钟周期 = max(100, 150, 200, 100) = 200ns
    （取最慢段作为时钟周期，保证所有段能完成）

(2) 总执行时间
    总时间 = (m + n - 1) × Δt
          = (4 + 50 - 1) × 200ns
          = 53 × 200ns
          = 10600ns
          = 10.6μs

(3) 流水线效率
    效率 = n × Σ段时间 / (m × n × Δt)
         = 50 × (100+150+200+100) / (4 × 50 × 200)
         = 50 × 550 / (4 × 50 × 200)
         = 27500 / 40000
         = 0.6875 = 68.75%

    或用公式：效率 = 加速比 / m
    加速比 = (50 × 4 × 200) / 10600 = 40000/10600 ≈ 3.77
    效率 = 3.77 / 4 ≈ 0.94 ← 注意：此公式假设各段时间相等！

    正确效率计算（各段时间不等）：
    实际完成工作量 = n × (100+150+200+100) = 27500ns
    总时空 = m × n × Δt = 4 × 50 × 200 = 40000ns
    效率 = 27500 / 40000 = 68.75%
```

> [!warning] 效率计算注意
> - **各段时间相等时**：效率 = n / (m + n - 1)
> - **各段时间不等时**：效率 = n × Σ段时间 / (m × n × Δt)
> - 效率总小于1，因为流水线有"气泡"（空闲时间）
