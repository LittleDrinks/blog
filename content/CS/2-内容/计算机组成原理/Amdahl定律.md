# Amdahl定律

> [!warning]
> Amdahl定律是**期末考试计算题重灾区**，必须熟练掌握公式的推导和计算！

---

## 一、定义

**Amdahl定律**：系统中某部件因采用更快执行方法后，整个系统性能的提高与这种执行方式的使用频率或占总执行时间的比例有关。

---

## 二、公式

```
                1
Sp = ─────────────────────────────
     (1 - Fe) + (Fe / Se)
```

其中：
- **Sp**：系统加速比（Speedup）
- **Fe**：可改进部分占原执行时间的比例（Fraction enhanced）
- **Se**：可改进部分的加速比（部件改进后的速度倍数）

> [!warning]
> **关键理解**：Fe 是"可改进部分占**原执行时间**的比例"，不是指令比例！不是指令类型比例！

---

## 三、核心结论

> **Fe往往比Se更重要**

即使部件加速倍数很高（Se大），如果它只占总执行时间的很小比例（Fe小），整体性能提升也很有限。

这就是Amdahl定律的残酷之处！

---

## 四、经典计算例题

### 例题 1：Amdahl定律基础应用

**题目**：假设某服务器用于Web服务，新CPU在计算部分比原CPU快10倍。原CPU忙计算的时间占40%，等待I/O占60%。求整体加速比。

**解答**：

已知：
- Fe = 0.4（计算部分占原执行时间的40%）
- Se = 10（计算部分加速10倍）

代入 Amdahl 定律：
```
          1                    1              1
Sp = ───────────── = ───────────────── = ─────── ≈ 1.56
     (1-0.4)+(0.4/10)   0.6 + 0.04        0.64
```

**答**：整体加速比约为 **1.56**。

> [!tip]
> 即使CPU计算快了10倍，由于只有40%时间花在计算上，整体只快了约1.56倍。

---

### 例题 2：Amdahl定律方案比较

**题目**：设浮点开平方根FPSQR操作占整个测试程序执行时间的20%。方案A用硬件实现FPSQR，速度加快到10倍。方案B使所有浮点数指令FP速度加快到2倍，FP指令占整个程序执行时间50%。比较两种方案优劣。

**解答**：

**方案A（优化FPSQR）**：
- Fe = 20% = 0.2
- Se = 10
```
           1                 1
Sp_A = ──────────── = ─────────── ≈ 1.22
       (1-0.2)+(0.2/10)   0.8+0.02
```

**方案B（优化所有FP指令）**：
- Fe = 50% = 0.5
- Se = 2
```
           1                 1
Sp_B = ──────────── = ─────────── ≈ 1.33
       (1-0.5)+(0.5/2)    0.5+0.25
```

**比较**：Sp_B (1.33) > Sp_A (1.22)

**答**：**方案B更优**。虽然FPSQR加速倍数高（10倍），但它只占20%时间；而FP指令只加速2倍，但占50%时间，对整体性能提升更大。

> [!warning]
> **核心结论**：Amdahl定律中，**Fe（可改进比例）往往比 Se（部件加速比）更重要**！

---

### 例题 3：CPU性能公式与Amdahl定律结合

**题目**：某程序中浮点操作FP的比例为25%，FP的CPI为4，其他指令的CPI为1.33。浮点开平方根FPSQR比例为2%，FPSQR的CPI为20。两种方案：
- 方案1：把FPSQR的CPI减至2
- 方案2：把所有FP操作的CPI均减至2

利用CPU性能公式分析两种方案优劣。

**解答**：

**原CPI计算**：
```
CPI_原 = 0.02×20 + 0.23×4 + 0.75×1.33
       = 0.4 + 0.92 + 0.9975
       = 2.3175
```

**方案1（FPSQR的CPI降至2）**：
```
CPI_1 = 0.02×2 + 0.23×4 + 0.75×1.33
      = 0.04 + 0.92 + 0.9975
      = 1.9575
```

**方案2（所有FP的CPI降至2）**：
```
CPI_2 = 0.25×2 + 0.75×1.33
      = 0.5 + 0.9975
      = 1.4975
```

**比较**：CPI_2 (1.4975) < CPI_1 (1.9575)

**答**：**方案2更优**。优化所有FP指令影响的面更广（25%的指令），而仅优化FPSQR只占2%。

## 五、极限情况分析

### 当 Se → ∞ 时

```
           1
Sp → ────────
     (1-Fe)
```

即：Sp_max = 1 / (1 - Fe)

> [!tip]
> 当部件改进速度无限快时，整体加速比的最大值为 1/(1-Fe)。这说明改进比例决定了上限！

---

## 六、理论基础

Amdahl定律是"**加快经常性事件**"原则的数学表达：

> Make the common case fast（加快经常性事件的速度）

原因：
- 经常性事件出现频率高（Fe大）
- 优化它能带来更大的整体性能提升
- 不经常发生的事件即使优化效果也不明显

## 考试常考题型

> [!faq] Amdahl定律中Fe的含义是什么？为什么说"Fe往往比Se更重要"？
> Fe是"可改进部分占原执行时间的比例"，不是指令条数比例或指令类型比例。Fe比Se（部件加速比）更重要，是因为Amdahl定律强调：改进的部分占比越大，整体加速效果越好。即使部件加速倍数很高（Se大），如果它只占总执行时间的很小比例（Fe小），整体性能提升也很有限。

> [!faq] 设某系统中某部件的处理时间占整个运行时间的40%，如果将该部件的处理速度加快到10倍，整个系统的性能提高多少？
> 根据Amdahl定律：Fe=0.4，Se=10。Sp = 1 / ((1-Fe) + Fe/Se) = 1 / (0.6 + 0.04) = 1 / 0.64 ≈ 1.56。整个系统的性能提高约1.56倍。这说明即使CPU计算快了10倍，由于只有40%时间花在计算上，整体只快了约1.56倍。

> [!faq] 设浮点开平方根FPSQR操作占整个程序执行时间的20%，方案A使FPSQR速度加快10倍，方案B使所有浮点指令FP速度加快2倍（FP指令占50%执行时间）。比较两方案优劣。
> 方案A：Fe=0.2，Se=10，Sp = 1/(0.8+0.02) ≈ 1.22。方案B：Fe=0.5，Se=2，Sp = 1/(0.5+0.25) ≈ 1.33。方案B更优。虽然FPSQR加速倍数高（10倍），但只占20%时间；而FP指令只加速2倍，但占50%时间，对整体性能提升更大。体现了"Fe比Se更重要"的原则。

> [!faq] Amdahl定律的公式是什么？各参数的含义是什么？
> 公式：Sp = 1 / ((1-Fe) + Fe/Se)。参数含义：Sp是系统加速比（改进后性能/改进前性能）；Fe是可改进部分占原执行时间的比例；Se是可改进部分的加速比（部件改进后的速度倍数）。注意Fe是时间比例而非指令比例！

> [!faq] 当Se趋向无穷大时，整体加速比的极限是多少？说明了什么？
> 当Se→∞时，Sp → 1/(1-Fe)。这说明即使某个部件改进速度无限快，整体加速比的上限也由改进比例Fe决定。例如Fe=0.4时，最大加速比只有1/0.6≈1.67。这印证了Amdahl定律的核心结论：改进比例决定了性能提升的上限。
