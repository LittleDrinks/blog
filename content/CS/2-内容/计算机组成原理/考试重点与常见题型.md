## 易错点清单

### 数据表示
- [ ] 补码求负数时，符号位保持不变
- [ ] 移码只用于浮点数的阶码表示
- [ ] IEEE 754尾数隐含最高位1

### 运算方法
- [ ] Booth算法中，部分积右移时符号位扩展
- [ ] 浮点对阶时，小阶向大阶看齐
- [ ] 规格化时，尾数左规/右规的判断

### 指令系统
- [ ] 一地址指令可能是单操作数或隐含ACC
- [ ] 相对寻址的偏移量是补码表示

### CPU
- [ ] 指令周期 ≠ 机器周期 ≠ 时钟周期
- [ ] 微指令的格式：水平型 vs 垂直型
- [ ] 流水线阻塞时序的计算

## 复习建议

1. **重点章节**：第2章(运算方法)和第5章(CPU)是重中之重
2. **计算题型**：多做几遍历年试卷的计算题
3. **概念理解**：控制器部分要理解微程序的工作原理
4. **画图题**：指令流程图、流水线时空图
5. **时间分配**：计算题占40%，概念题占60%
