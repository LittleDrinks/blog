# 寻址方式计算题（第4章重点！）

> [!warning] 考试重点
> 寻址方式计算是**第4章必考题型**，务必掌握各种寻址方式的EA计算！

## 核心公式（必背）

```
立即寻址：操作数 = A（无EA）
直接寻址：EA = A，操作数 = (A)
间接寻址：EA = (A)，操作数 = ((A))
寄存器寻址：操作数 = (R)（无EA）
寄存器间接：EA = (R)，操作数 = ((R))
基址寻址：EA = (BR) + A（用于程序重定位）
变址寻址：EA = (IX) + A（用于数组访问）
相对寻址：EA = (PC) + D（用于转移指令）
```

### 三种偏移寻址的区别（易错！）

| 寻址方式 | 公式 | 基准 | 可变部分 | 谁修改 | 用途 |
|----------|------|------|----------|--------|------|
| 相对寻址 | EA=(PC)+D | PC（下条指令地址） | D | D固定 | 转移指令 |
| 基址寻址 | EA=(BR)+A | BR（系统设定） | A | BR系统设定 | 程序重定位 |
| 变址寻址 | EA=A+(IX) | A（数组基地址） | IX | IX用户修改 | 数组遍历 |

> [!tip] 记忆口诀：**相对跳、基址定、变址循**

### 访存次数对比（选择题高频）

| 寻址方式 | 访存次数 | 原因 |
|----------|----------|------|
| 立即寻址 | **0次** | 操作数在指令中 |
| 寄存器寻址 | **0次** | 操作数在寄存器中 |
| 直接寻址 | **1次** | EA=A，访问A单元 |
| 寄存器间接 | **1次** | EA=(R)，访问EA单元 |
| 间接寻址 | **2次** | 先访问A取地址，再访问EA取操作数 |
| 相对寻址 | **1次** | EA=(PC)+D，访问EA单元 |
| 基址/变址 | **1次** | EA计算后访问EA单元 |

### 例题1：有效地址计算（基础）

**题目：**
> 某计算机字长16位，存储器按字节编址。
> 当前PC=2000H，变址寄存器IX=1000H，基址寄存器BR=2000H。
> 指令地址码部分 A=30H，计算以下寻址方式的有效地址：

**解答：**
```
(1) 直接寻址：EA = 30H

(2) 间接寻址：EA = (30H)
    (需要查存储器内容，假设(30H)=4000H)
    EA = 4000H

(3) 变址寻址：EA = (IX) + A = 1000H + 30H = 1030H

(4) 基址寻址：EA = (BR) + A = 2000H + 30H = 2030H

(5) 相对寻址：EA = (PC) + A = 2000H + 30H = 2030H
    (假设PC尚未更新，实际应为取指后的PC值)
```

### 例题2：相对寻址转移目标计算（考试高频）

**题目：**
> 某计算机采用相对寻址的两字节转移指令。
> 转移指令所在地址为 1000H，指令中的偏移量 D = 06H（补码）。
> 问：转移后的目标地址是多少？

**解答：**
```
关键点：取指后PC指向下一条指令

第1步：确定PC值
  指令占2字节，取指后 PC = 1000H + 2H = 1002H

第2步：计算有效地址
  EA = (PC) + D = 1002H + 06H = 1008H

答：转移目标地址为 1008H
```

> [!warning] 易错点
> **PC不是当前指令地址，而是下一条指令地址！**
> 计算时务必考虑指令长度对PC的影响。

### 例题3：相对寻址负偏移量

**题目：**
> 转移指令地址为 2000H，指令长度2字节，偏移量 D = F8H（补码）。
> 计算转移目标地址。

**解答：**
```
第1步：PC值
  PC = 2000H + 2H = 2002H

第2步：解析偏移量
  F8H是补码，真值为 -8（因为 256-248=8）

第3步：计算EA
  EA = 2002H - 8H = 1FFAH

答：转移目标地址为 1FFAH（向后跳转）
```

### 例题4：基址寻址程序重定位

**题目：**
> 程序逻辑地址从0开始，装入物理内存起始地址4000H。
> 基址寄存器 BR = 4000H。
> 程序中指令访问逻辑地址 A = 100H 的数据。
> 问：物理地址是多少？

**解答：**
```
EA = (BR) + A = 4000H + 100H = 4100H

答：数据物理地址为 4100H
```

> [!tip] 理解要点
> 基址寻址实现程序重定位：逻辑地址 → 物理地址转换

---

### 例题5：变址寻址数组访问

**题目：**
> 数组A起始地址1000H，元素占4字节。
> 变址寄存器 IX = 5（下标值）。
> 访问A[5]的有效地址是多少？

**解答：**
```
EA = A + (IX) × 元素大小
   = 1000H + 5 × 4
   = 1000H + 20 = 1020H

答：A[5]的有效地址为 1020H
```

### 例题6：组合寻址方式（先变址后间接）

**题目：**
> 某指令格式：|OP|I|X|D|，I为间址标志。
> D=200H，PC=500H，IX=100H，BR=400H。
> 计算 (1) X=10变址寻址，I=0
>       (2) X=10变址寻址，I=1（先变址后间接）

**解答：**
```
(1) 变址寻址，I=0：
    EA = D + (IX) = 200H + 100H = 300H
    访存次数：1次

(2) 先变址后间接，I=1：
    先计算变址地址：300H
    再间接寻址：EA = (300H)
    假设(300H)=600H，则EA=600H
    访存次数：2次
```

> [!tip] 组合寻址规则
> **严格按照字面顺序执行**："先变址后间接" = 先算变址，再间址
