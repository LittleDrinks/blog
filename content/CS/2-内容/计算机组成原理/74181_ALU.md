# 74181 ALU 与先行进位

## 多功能ALU（74181）

### 74181芯片概述

**74181**是一种4位多功能ALU芯片，可以实现：
- **16种算术运算**
- **16种逻辑运算**

### 基本原理

**一位全加器(FA)逻辑表达式**：
```
Si = Ai ⊕ Bi ⊕ Ci
Ci+1 = Ai·Bi + (Ai ⊕ Bi)·Ci
```

**函数发生器设计**：将输入Ai和Bi通过函数发生器得到Xi和Yi：
- Xi = 进位传递函数
- Yi = 进位生成函数

> [!note] 创新点
> 74181的创新在于：(1)实现并行进位（先行进位）(2)通过控制参数实现多种运算

### 先行进位（CLA）原理

**目的**：加快加法运算速度，避免进位逐位传递

**进位生成与传播**：
```
Gi = Ai · Bi      （本位生成进位）
Pi = Ai ⊕ Bi      （本位传播进位）
Ci+1 = Gi + Pi · Ci
```

**4位先行进位公式**：
```
C1 = G0 + P0·C0
C2 = G1 + P1·G0 + P1·P0·C0
C3 = G2 + P2·G1 + P2·P1·G0 + P2·P1·P0·C0
C4 = G3 + P3·G2 + P3·P2·G1 + P3·P2·P1·G0 + P3·P2·P1·P0·C0
```

**简化表示**：
```
C4 = G + P·C0
```
其中：
- **G** = G3 + P3·G2 + P3·P2·G1 + P3·P2·P1·G0（成组进位生成）
- **P** = P0·P1·P2·P3（成组进位传播）

### 74182先行进位发生器

**作用**：实现多片74181之间的先行进位

**原理**：
- 将4片74181的G和P信号送入74182
- 74182产生组间进位信号，实现二级先行进位

**16位ALU构成**：
- 4片74181 + 1片74182
- 片内先行进位 + 片间先行进位 = 全先行进位

### 控制信号说明

| 控制端 | 功能 |
|--------|------|
| M | 模式选择：M=H逻辑运算，M=L算术运算 |
| S3-S0 | 运算选择：16种算术运算或16种逻辑运算 |
| Cn | 进位输入 |
| Cn+4 | 进位输出（最高位进位） |
| G | 成组进位生成输出 |
| P | 成组进位传播输出 |
| A=B | 比较结果输出（两数相等时为高） |

### 例题：16位ALU设计

**问题**：某机字长16位，使用四片74181组成算术/逻辑运算单元，设最低位序号标注为第0位。

1. 写出第5位的进位信号C6的逻辑表达式
2. 估算产生C6所需的最长时间
3. 估算最长求和时间

**解**：

**(1) C6的逻辑表达式**
- C4 = G + P·C0（最低4位芯片的进位输出）
- C5 = Y4 + X4·C4
- C6 = Y5 + X5·C5 = Y5 + X5·Y4 + X5·X4·C4

**(2) 产生C6的最长时间**
- 从C0产生C4需要：1个反相器 + 2级"与或非"门 = 3T
- C4传到C6需要：再经过2级"与或非"门 = 2T
- **总时间：5T**

**(3) 最长求和时间**
- 产生控制参数X、Y：3级"与或非"门
- 最低位芯片产生C4：4级逻辑门
- 后续3片各需3级传递进位
- 最后加法运算：3级逻辑门
- **总时间：16T**

> [!tip] 性能对比
> - 行波进位加法器：需要逐位传递，n位需要n级延迟
> - 先行进位加法器：进位并行计算，时间恒定

### 74181功能表（部分）

| S3 S2 S1 S0 | M=H（逻辑运算） | M=L（算术运算）Cn=0 |
|-------------|----------------|---------------------|
| 0000 | NOT A | A |
| 0001 | A OR B | A OR B |
| 0010 | A AND (NOT B) | A OR (NOT B) |
| 0110 | A XOR B | A减B减1 |
| 1001 | A XOR B | A加B |
| 1100 | 逻辑1 | A加A（2A） |

> [!note] 算术运算说明
> - 算术运算使用补码表示
> - "A减B减1"需要配合末位进位Cn=1才能得到正确结果"A减B"

## 考试真题精选

> [!faq] 74181 ALU芯片中，M控制端的作用是什么？
> M为模式控制端：M=H（高电平）时进行逻辑运算，封锁进位信号；M=L（低电平）时进行算术运算，进位信号正常传递。通过M和S0-S3四个控制端，可实现16种算术运算和16种逻辑运算。

> [!faq] 先行进位加法器相比行波进位加法器有什么优势？
> 行波进位加法器进位需逐位传递，n位加法器最坏情况下需要n级延迟时间。先行进位加法器将进位并行计算，所有进位同时产生，时间恒定。对于16位ALU用4片74181加1片74182，可实现全先行进位。

> [!faq] 已知74181芯片的G和P输出端，解释其含义和作用。
> G为成组进位生成输出（Group Generate），P为成组进位传播输出（Group Propagate）。G表示本4位组内部是否产生进位，P表示本组是否向高位传播进位。作用：将多片74181的G和P送入74182先行进位部件，实现组间先行进位，构成全先行进位的ALU。公式：Cn+4=G+P·Cn。
