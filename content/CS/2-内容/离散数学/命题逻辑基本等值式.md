| 基本等值式          |                                                                          |
| -------------- | ------------------------------------------------------------------------ |
| 双重否定律          | $\lnot\lnot A \Leftrightarrow A$                                         |
| 幂等律            | $A\lor A\Leftrightarrow A$，$A\land A\Leftrightarrow A$                   |
| 交换律、分配律、结合律    |                                                                          |
| 德摩根律           |                                                                          |
| 吸收率            | $A\lor(A\land B)\Leftrightarrow A$<br>$A\land(A\lor B)\Leftrightarrow A$ |
| 零律             | $A\lor 1\Leftrightarrow 1$<br>$A\land 0\Leftrightarrow A$                |
| 同一律            | $A\lor 0\Leftrightarrow A$<br>$A\land1\Leftrightarrow A$                 |
| 排中律            | $A\lor \lnot A\Leftrightarrow 1$                                         |
| 矛盾律            | $A\land \lnot A\Leftrightarrow 0$                                        |
| 蕴含等值式          | $A\to B\Leftrightarrow \lnot A\lor B$                                    |
| 等价等值式<br>      | $A\leftrightarrow B\Leftrightarrow (A\to B)\land (B\to A)$               |
| 假言易位（逆否命题）<br> | $A\to B\Leftrightarrow \lnot B\to\lnot A$                                |
| 等价否定等值式<br>    | $A\leftrightarrow B\Leftrightarrow \lnot A\leftrightarrow \lnot B$       |
| 归谬律            | $(A\to B)\land (A\to \lnot B)\Leftrightarrow \lnot A$                    |
